# doc changelist

Round topic: `202609241729_topic.capture-what-op-says.md`, the only open topic;
this changelist consumes it whole.

## Current state

The workspace's capture store is written by a dispatched sub-agent, briefed with
the words the coordinator pasted. homma has no command reading a session
transcript, and `mock/DESIGN.md.tmpl` lists no such command under "The command
surface".

## Changes proposed

`mock/DESIGN.md.tmpl`, "The command surface": a `homma capture` row in the
command list, and four paragraphs saying what it reads, how it tells the
person's words from everything else in a transcript, why only those words are
blockquotes, how the watermark is derived from the store, what one run writes,
and that committing is the caller's.

Every decision in the topic lands there. Nothing in the topic is left for a
later round except the model half, the summary through muisti's `answer`, which
the design names as the replacement for the verbatim context and which waits on
muisti building on the machine homma runs on.

## What is not changed

No crate design. The command lives in `homma-engine` beside the other command
bodies and adds no type another crate reads, so the crate documents stay as they
are. The root `README.md` gains the command's row in the source changelist, since
its table is checked against the binary.

## Reopened for where a first run starts

Two decisions the topic did not reach, found reading real transcripts before any
source was written. The source changelist opened before them was empty and is
deprecated as it stood. Both land in the same "The command surface" paragraphs.

The watermark says where a session's next capture starts once one capture from
it exists, and nothing for a session none has come from. Taking everything there
is wrong: the sessions this replaces the archivist in have run for weeks, the
archivist already captured most of what was said in them, and a first run would
write one enormous capture repeating hundreds of remarks the voice tool already
reads. So `--since` sets the floor by hand, as an RFC 3339 instant, the form the
transcript and a capture's `through` both use, and the later of it and the
watermark wins. With neither the run takes the whole session, which is right for
a session that started after the command existed.

An answer is one of three things and the file says which. The harness writes
`(notes only)` when the person picked nothing and wrote notes; that string is the
harness's and is dropped, leaving the notes. An answer equal to one option's
label, or to several labels joined by `, ` as a multi-select returns them, is a
choice, named in plain text since the labels are the agent's words. Anything else
is typed text and is quoted. Notes are always the person's and always quoted.
