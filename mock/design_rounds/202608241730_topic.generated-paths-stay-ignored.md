# The generated paths stay ignored, and a test says so

The repository's generated agent instructions were untracked and unignored for
long enough that nobody noticed, and the state was found by a workspace sweep
rather than by anything here. The ignore entries now exist. Nothing pins them.

An ignore list is a configuration file, so it is edited by hand, and the edits
that break it do not look like breakage. Somebody consolidating a long
`.gitignore`, or replacing seven per-path lines with one blanket, restores the
old state with a diff that reads as tidying.

## What the check has to reach

Not the text of the file. A test matching strings in `.gitignore` passes when
the entries are present and spelled the way it expects, which is a test of the
spelling rather than of the effect, and it goes green against a file that has
been rewritten into an equivalent form and red against one that has been
rewritten into a better one.

The effect is what `git check-ignore` reports, so that is what the check asks.
It is the same mechanism git itself consults, so an entry written any way that
works passes, and an entry that has stopped working fails however it is spelled.

## The negative half, which is the point

Every generated path being ignored is half the property and the easy half: a
blanket `.claude/` and `.github/` satisfies it completely. What the per-path
form buys is that a hand-written workflow beside the generated directories
stays visible, and that is the half a blanket silently loses.

So the check plants one. A file under `.github/workflows/` must not be ignored,
and a blanket entry fails there while the current list passes. Without that arm
the test cannot tell the two shapes apart and certifies the weaker one.

## Where it does not reach

Only this repository. Every mockspace consumer generates the same paths and the
same defect is available to all of them, and one of the three cloned here still
has it. A check that covered the class would live where the generator does,
because that is the only place that knows what it writes. That is worth doing
and is not this.
