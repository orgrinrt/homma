# src changelist

Answers the doc changelist `202610271310_changelist.doc.lock.md` of this round, topic `git-shook-consent-is-scoped-and-the-design-states-the-coexistence`.

## Current state before the round

`homma hook install` ran `git shook install --yes`, which registers every manifest in the clone. The entrypoint it wrote into git's own hooks directory before a move to git-shook stayed there. `Reach::Direct` was returned from the absence of a hooks path alone. A layer's error kept the file and dropped the reason, and `doctor` listed such a file as read and as an error.

## Changes

- `homma-core`: `hooks/shook.rs` passes `--only homma` and removes the entrypoint at git's own hooks directory when it is exactly the text this tool writes. `hooks/install.rs` adds `Reach::NotInstalled` for no hooks path and no file, and `install_on`, the routing taking a `PATH` so a test reaches it. `layers.rs` adds `LayerError::report`, which keeps the reader's reason, and `config.rs` stores that.
- `homma-engine`: `cmd/hook.rs` lists a file that cannot be read once.
