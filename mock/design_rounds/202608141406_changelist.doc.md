# DOC changelist: absolute is not contained

**Round:** the containment round
**Phase:** DOC

## CHANGE: mock/crates/homma-org/DESIGN.md.tmpl

State the invariant a workspace actually has to satisfy: not inside any other
repository, and not under a path the deny list forbids. Not "under the root",
which is false, since a workspace legitimately lives outside the content
repository.

## CHANGE: mock/crates/homma-api/DESIGN.md.tmpl

The `AbsPath` paragraph claims more than the type delivers. Say what it carries
(absoluteness) and what it does not (containment), and that the second is a
runtime check because it is a question about the filesystem rather than about
the value.
