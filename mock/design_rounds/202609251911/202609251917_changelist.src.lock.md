## Tests

`aggregate_settings_tests.rs` reads and seeds the local file, and gains arms
for: a shared file with nothing of homma's is not written; a shared file with
no hooks is not given any; an absent shared file stays absent; homma's
registrations are swept from the shared file and the rest kept; the local
file's other keys are kept; a second regen is identical; an unparseable shared
file is an error and the local file is not written. The chain, declared and
aggregate tests and `tests/regen_writes_smoke.rs` read the local file.

Negative control, on a throwaway branch through the normal hooks: making the
shared write unconditional failed exactly
`the_shared_file_is_not_written_when_nothing_in_it_is_hommas` and
`a_shared_file_with_no_hooks_is_not_given_any`, and nothing else.

`homma-org/tests/agents_corpus.rs`, 13 arms: byte for byte with a nested host
field; name and description read off the top level; a template renders against
its own name; a name that is not the filename is refused; a nested `name` does
not stand in for the top-level one; an empty description is refused; no
frontmatter and an unclosed one are refused; quotes are taken off; a template
that does not render is refused and nothing is written; a file without the
suffix is not a persona; an unclaimed generated persona is named and left
alone; a hand edit is rewritten; an absent corpus is unreadable and an empty
one renders nothing.
