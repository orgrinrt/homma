The intent: what homma generates for one clone is that clone's, is never
tracked in the content repository, and is generated rather than fetched. What
every clone shares stays in the tracked file and nothing generated goes into
it. The vehicle he sketched, the registrations in `settings.local.json`, is the
one the host already reads for exactly this: a file per checkout, merged over
`settings.json`, hooks included.

## Current state

`homma agent regen` writes its wrappers into `.claude/hooks/` and merges its
registrations into `.claude/settings.json`. In the content repository both are
tracked. A clone holds some subset of the members, and the regen writes the
subset it has, so:

- a clone without a member drops that member's registrations from the tracked
  `settings.json`, measured in the kenno clone on 2026-09-24, where nine
  `muisti--*` lines went, and a commit of it would drop them for every clone;
- a clone with a member nobody else has gets wrappers nobody tracked, showing
  as untracked in `git status`, which op saw;
- the two cannot both be right, and the agenda row
  `regen-writes-one-clones-members-into-the-tracked-hooks` names the two ways
  out: the union of every member, or the output per clone.

Rules and skills already went the second way: `.claude/rules` and
`.claude/skills` are generated from `.shared/` and ignored.

## Where it goes

The output per clone. The regen merges its registrations into
`.claude/settings.local.json` under the same rule it uses today (what homma
wrote is what carries the mark, anything else is kept as it is), and sweeps
its own registrations out of `.claude/settings.json`, leaving the hand-written
ones there. The wrappers stay under `.claude/hooks/`, which the content
repository ignores. Nothing else in `settings.local.json` is touched: it also
holds what the person at that clone allowed and prefers.

Not homma's, and done in the content repository beside it: ignoring
`.claude/hooks/` and `.claude/agents`, moving the workspace personas to a
source under `.shared/`, and declaring in the manifest the one hand-written
hook that was only ever tracked.
