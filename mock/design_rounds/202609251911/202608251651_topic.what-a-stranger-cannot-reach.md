# What a stranger cannot reach

A full read of the repository, run against the state a person who is not the
author would land in. Everything below was reproduced rather than inferred.

## The launcher cannot fetch its own engine

`launcher/src/lib.rs` names the engine repository over `ssh://`. That string is
what `git ls-remote` and `cargo install --git` receive on every machine the
launcher is installed on, and the repository is public, so the scheme buys
nothing and costs everything: without a key registered on the forge the tool
fails on its first run, before it has done anything.

Reproduced with the key path shut off, which is the state a stranger's machine
is in:

```
homma: git ls-remote ssh://git@github.com/orgrinrt/homma.git refs/heads/dev failed:
git@github.com: Permission denied (publickey).
```

The same ref over https, with no credentials at all, resolves.

There is a second half. The repository carries one tag and it is an archive
marker, so a version pin resolves to nothing either: the version path tries the
registry, where the engine is unpublished, then the bare string as a tag, where
there is none. The release has to cut the tag as well as fix the scheme.

## The manifest stopped accepting a table and four messages still ask for it

Membership is detected from the directories under the workspace root. The table
that used to declare it is refused outright, and correctly so: a manifest
carrying one has an idea of membership that is no longer held, and reading it as
far as the first unknown key would leave an operator with a workspace that looks
configured and is not.

Four commands still answer an unknown repository name by telling the operator to
declare it in that table. Following the advice produces a parse failure, so the
tool sends the reader into a state it then refuses. Thirteen further mentions
survive in argument help text.

The honest answer names what was actually found, so it now does, from one place
rather than four.

## The tier-one surfaces speak the vocabulary of the workspace they grew up in

Argument help, module documentation and the rendered documents under `docs/`
name the design tool, its template directory and its round ceremony. A reader
arriving from a crate listing has no way to reach any of it.

## A pin does not determine the engine

The engine depends on two crates from another repository by branch. `cargo
install` ignores the committed lockfile, measured rather than assumed, and the
build cache is keyed on the engine's own revision, so two operators on one pin
can run different code and nothing notices. The fix is to pin those two by
revision, which is the tool's own to do rather than the launcher's.

## Smaller

The published manifest set both a licence expression and a licence file, and the
warning that provokes survives into the tarball, so every install prints it.
The readme names a flag that does not exist, and contradicts itself about
whether the manifest names the repositories.
