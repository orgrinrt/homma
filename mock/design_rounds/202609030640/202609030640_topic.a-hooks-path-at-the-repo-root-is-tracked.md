# A hooks path at the repo root is tracked

**Date:** 2026-09-03
**Phase:** TOPIC
**Scope:** `homma-core/src/release/hook.rs`, `homma-engine/tests/cli_release.rs`
**Source topics:** the fourth review of pull request 49, and `202609030625/202609030625_topic.the-three-refusals-are-asserted-through-the-binary.md`

## The findings

A `core.hooksPath` of `.` resolves to the repo root, the path relative to the root is empty, and git refuses an empty pathspec, so the install fell out as an error rather than the refusal it is: the root holds tracked files. The empty path is asked about as `.`, and the smoke test plants the case.

The design.
