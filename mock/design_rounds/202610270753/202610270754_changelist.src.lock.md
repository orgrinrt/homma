# src changelist

Answers the topic filed in this round, `the-gate-counts-only-the-launcher-pin-and-its-tests-move-aside`.

## Changes

- `crates/homma-engine/src/cmd/gates.rs`: the gate asks `homma agent status --repo <name> --output json` for `mockspace_toml`, `mock_dir_name`, `mock_dir` and `launcher_pin`, and the two awk readers of the toml are deleted. It refuses where homma is not on the PATH, and where homma gives no readable answer, and skips the drift arm where there is no workspace manifest. It counts the launcher pin and no longer the legacy `cargo mock` alias, and a missing pin is answered by adding the pin, with `homma agent regen` named only for the other surfaces. The hooks path is still read from git here.
- `crates/homma-engine/src/cmd/gates/tests.rs`: the gate's tests move out of `gates.rs`, as the agent tests did. They run the gate in a workspace beside one shared stub `homma` that answers `agent status` from a fixture the real probe wrote for the tree the test built. New tests: an alias is not the pin; a pin under an indented table is not the pin; a nested array before `mock_dir` does not hide it; homma giving no answer is a refusal, with the allowed control. The test of an alias under another section goes, with the fixture shape it used.
- `crates/homma-engine/src/cmd/agent.rs`: `Surfaces` gains `launcher_pin`, read from the toml as a toml, and the toml is read in one helper for the mock dir and the pin. `probe` is visible to the gate's tests. The `run_with` rustdoc gives the stages in the order the code runs them, and the comment that said stage 3 for the post-loop step no longer does.
- `crates/homma-engine/src/cmd/agent/status/tests.rs`, `status.rs`: tests of the pin as a top-level key only, of a nested array before the mock dir, and of the root toml winning over the one under `mock/`; the fixture gains the field.

Shown red by mutation: the pin probe returning false failed the pin tests and the gate's full adoption; the lookup order swapped failed the root-wins tests of the status and the gate; the fix text always naming regen failed the alias and partial adoption tests. The suite is green, 601 tests.

`gates/tests.rs` is about 1090 lines and is left whole this round.

The three flat topics from earlier rounds stay open and are named in the doc changelist.
