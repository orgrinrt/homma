# Doc changelist: the description follows the tagline

**Date:** 2026-09-03
**Phase:** DOC
**Source topics:** `202609032021_topic.the-description-follows-the-tagline.md`

## Current state

The gate is six steps, each a list of programs run per repository kind, and
none reads the checkout's readme or its manifest's description. A package's
registry line and its readme's first line have no tie, and the readme pass
that rewrote every tagline left every description as published.

No other flat topic is open on this branch.

## Changes proposed

### `homma-core/DEEPDIVE_release.md.tmpl` (modify)

The step table gains `description`, blocking: the `Cargo.toml` description
against the readme's tagline for a `cargo` repository, the `deno.json`
description against the same for a `deno` one. A paragraph after the table
says the step runs no program, what the tagline is and where it is read from,
that the comparison trims the ends and nothing else, that a missing
description fails, that a readme with no title or tagline skips and says so,
and that the log names both strings.
