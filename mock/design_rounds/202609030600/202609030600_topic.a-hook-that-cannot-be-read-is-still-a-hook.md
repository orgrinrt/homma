# A hook that cannot be read is still a hook

**Date:** 2026-09-03
**Phase:** TOPIC
**Scope:** `homma-core/src/release/hook.rs`, one paragraph of `homma-core/DEEPDIVE_release.md.tmpl`
**Source topics:** the review of pull request 49, and `202609030545/202609030545_topic.the-hook-install-refuses-a-hook-that-is-not-its-own.md`

## The findings

The refusal of a foreign `pre-push` read the file as text and fell through on any read error, so a compiled hook, or one the user cannot read, was overwritten, which is the exact case the refusal exists for. Anything at that path that is not this tool's text refuses, whatever the read returned. The tracked-directory check skipped itself where `git ls-files` failed; a failed git call is an error, as it is elsewhere in the file.

The design named one refusal and the last round added two without saying so. The paragraph names all three.

## What does not change

The mockspace refusal.
