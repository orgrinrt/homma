# Source changelist: a hook that cannot be read is still a hook

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609030600_changelist.doc.lock.md`

## `homma-core`

### `src/release/hook.rs` (modify)

CHANGE: `install` refuses with `HookExists` where anything sits at the `pre-push` path whose text is not this tool's, including a file that does not read as text or cannot be read at all; only an absent file falls through to the write. A failed `git ls-files` is `GitError::Failed`, as elsewhere in the file. Tests plant a binary hook and an unreadable one and assert both refuse and survive untouched.
