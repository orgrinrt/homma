# Source changelist: the configs stage has to fit the repo it lands in

## CHANGE: crates/homma-org/src/configs.rs

ADD `Applies::NightlyRustRepo`, and map `rustfmt.toml` to it. `deny.toml` and
`clippy.toml` stay on `RustRepo`; nothing about them needs nightly.

ADD `is_a_rust_repo` and `is_pinned_to_nightly`, the latter reading
`rust-toolchain.toml` at the root and under `mock/`. Either naming a nightly
channel is enough. No pin means not nightly: an unpinned repo builds on
whatever the machine defaults to, which is a fact about the machine.

ADD `names_a_nightly_channel`, a line scan rather than a toml parse, skipping
commented lines so a pin somebody thought better of does not still count.

ADD `Finding::NoVariantFits(name, why)`, reported when a repo wants a config of
that name and the shared copy does not fit it. `needs_a_human` is true, because
what closes it is somebody writing the variant.

MODIFY `ensure` to emit that finding rather than passing over a Rust repo on
stable in silence.

## CHANGE: crates/homma-core/src/config.rs

MODIFY `Config::from_path` to resolve a relative `workspace.path` against the
directory holding the config. `Config::parse` is unchanged and leaves the path
alone: it has no file to anchor on, and inventing the working directory as one
is the guess this removes.

ADD `normalise`, lexical rather than `canonicalize`, because it must answer for
a workspace that does not exist yet.

## CHANGE: crates/homma/src/cmd/agent.rs

MODIFY the per-repo loop so a repo whose `local_path` is absent is skipped as
"not cloned here" rather than failed. A workspace clones the repos its work
touches; the rest are simply not on disk.

SPLIT `run_with` into `regen`, which returns the report, and `run_with`, which
emits it and maps it to an exit code. The pipeline was untestable because its
results only ever reached stdout.

## CHANGE: tests

The hand check that measured the shared rustfmt config becomes
`the_shared_rustfmt_config_is_the_reason_this_predicate_exists`, which re-runs
`rustfmt +stable --check` rather than recording the number. It skips where no
stable toolchain is installed.

The fixtures that used `rustfmt.toml` as a stand-in for "a Rust config" move to
`deny.toml`, which is what they always meant. `rustfmt.toml` now appears only in
the tests that are about the nightly predicate.
