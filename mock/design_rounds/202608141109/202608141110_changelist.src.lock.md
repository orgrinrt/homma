# SRC changelist: the root is not the cwd

**Round:** the root round
**Phase:** IMPL

## CHANGE: mock/crates/homma/src/cmd/mod.rs

The workspace root defaults to **the configuration file's own directory**, not the
current one.

## CHANGE: mock/crates/homma/src/cmd/stand.rs (new)

Move `stand_up`, `append_entry` and their tests out of `org.rs`, which reached 603
lines taking the split that took `workspace.rs` under the limit.

Verify the root's `origin` names `content_repo`, refusing with both values when it
does not.

Read the identity back after setting it, so the design's claim that a stood-up
clone reports its own email is asserted rather than stated. `Git::identity` had no
caller outside tests while its doc said it existed for exactly this.

## CHANGE: mock/crates/homma-org/src/provision.rs

Check an existing workspace's `origin` against the intended URL before skipping
the clone. A workspace cloned from the wrong repository is otherwise permanent.

Read the identity back after writing it and refuse when it does not match.

## CHANGE: mock/crates/homma-core/src/repo/git_impl.rs

`global_config_paths` honours `GIT_CONFIG_GLOBAL` and `/etc/gitconfig`, and the
test asserts the list is **non-empty** before comparing, since an empty comparison
passes and reported ok under `env -u HOME -u XDG_CONFIG_HOME`.

## CHANGE: mock/crates/homma-api/src/config.rs

Comments still saying "standing" where the type is `Staffing`.

A test that fails when `workspace`, `session` or `repos` are dropped from the
control-character check. Deleting all three left the suite green.

Replace the serde-default test, which now duplicates its neighbour on the same
fixture entry, with one over an entry that omits `staffed` and is covered nowhere
else.

## CHANGE: mock/crates/homma/tests/cli_smoke.rs

A test that fails when the registry's re-validation or its write-and-rename is
removed. Both deletions left the suite green.

Assert at the CLI level that no global git configuration changed, which is the
half of the roadmap's exit test the integration test omitted.

A test standing up from a directory that is not the workspace, asserting the
wrong repository is not cloned and nothing is written where the operator stood.
