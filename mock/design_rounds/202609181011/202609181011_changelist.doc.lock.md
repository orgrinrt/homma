# doc changelist: a shell call lands where its paths point

## Current state

`mock/DESIGN.md.tmpl`, section `## The agent hooks`, says a shell call is
narrowed by "the directory the host says the session is in, then any path the
call carries, and the hook process's own working directory last". The source
reads that as a chain and stops at the first link, so the paths a shell call
carries are never read, and a call typed at the workspace root that names a
repository by path reaches none of that repository's hooks. The section is also
silent on three things the source does or should do: a registration that runs
its hook through a program, a hidden file under `.claude/hooks/`, and a
registration whose managed file is gone.

## Changes proposed

### `mock/DESIGN.md.tmpl`, `## The agent hooks`

- The narrowing paragraph becomes a union: a hook sees a call when any place it
  lands is under the hook's repository, and for a shell call those places are
  the host's directory and every path the command names, read relative to it.
  The hook process's directory stands in only where the host names none.
- A new paragraph says how a wrapper reads a command, and what it cannot see:
  split on everything that cannot be part of a path, the absolute root searched
  for as a substring, a piece climbing with `..` landing everywhere, and the
  three blind spots named (a relative path with a space, a path through a
  variable, what a script does next).
- A new paragraph says a registration names its hook by the first word reaching
  into `.claude/hooks/`, with what precedes it the program and what follows its
  arguments, that such a hook need not be executable, and that one run through
  two different programs is reported and not carried.
- The executable sentence narrows to a file no registration runs through a
  program.
- A new paragraph states the hidden-file skip and the sweep of a registration
  whose managed file is gone.

### What this round does not change

- The `[agent.hooks]` table and its rows.
- Ownership by the managed line, and the refusal of a collision.
- The git hooks.
