# src changelist: a shell call lands where its paths point

Implements `202609181011_changelist.doc.lock.md`.

## CHANGE: `TARGET_JQ` FROM a jq chain taking the first of file, `cwd` and tool `cwd` TO `LANDS_IN_SH`, a bash `lands_in <dir>` over the file, the directory and every path the command names
File: `mock/crates/homma-engine/src/cmd/aggregate_wrapper.rs`
Verification: `grep -rn TARGET_JQ mock/crates` returns nothing; the wrapper tests run the emitted script on a shell call typed at the workspace root naming the repository by `--manifest-path`, `--manifest-path=`, `git -C`, `cd`, `~/`, an absolute path with a space in it and a `..` climb, each with a control that does not fire.

## CHANGE: `wrapper_script` FROM `(repo_name, repo_rel_path, hook_rel_path)` TO `(repo_name, repo_rel_path, hook_rel_path, runner)`
File: `mock/crates/homma-engine/src/cmd/aggregate_wrapper.rs`
Verification: a hook registered as `bash .claude/hooks/check.sh`, not executable, is carried and runs through `bash` when the wrapper fires.

## CHANGE: `hook_file_named` FROM reading the command's first word TO the name of `hook_call`, which reads the first word reaching into `.claude/hooks/` and keeps the words before it as the runner and the rest as arguments
File: `mock/crates/homma-engine/src/cmd/aggregate_wrapper.rs`
Verification: the spelling test covers a runner, a multi-word runner, and arguments whose spacing is kept.

## CHANGE: `Registration` FROM `{ event, matcher, args }` TO `{ event, matcher, args, runner }`, and `aggregate_hooks` FROM requiring every hook executable TO requiring it only where no registration runs it through a program, reporting a hook two registrations run two different ways
File: `mock/crates/homma-engine/src/cmd/aggregate.rs`
Verification: the chains tests for a runner-carried hook, for two runners reported, and the existing non-executable test as the control.

## CHANGE: the declared wrapper FROM a `case` on one target TO `lands_in` per declared repository
File: `mock/crates/homma-engine/src/cmd/declared.rs`
Verification: a declared row narrowed to a repository fires for a shell call at the workspace root naming that repository by path, and not for one naming another.

## CHANGE: the file split
Files: `aggregate.rs` keeps the pass; `aggregate_wrapper.rs` takes `HookCall`, `hook_call`, `hook_file_named`, `sh_single_quote_escape`, `LANDS_IN_SH` and `wrapper_script`, with its tests in `aggregate_wrapper_tests.rs`; the pass's own tests move to `aggregate_tests.rs`, the settings merge tests to `aggregate_settings_tests.rs`, and the tests of how a registration names and runs its hook to `aggregate_registration_tests.rs`, which borrows the chains tests' planting helpers.
Verification: `wc -l` on each is under 500, and the suite count is the old count plus the new tests.
