# The design document still names a central clone

**Phase:** TOPIC
**Scope:** `mock/crates/homma-org/DESIGN.md.tmpl`

The containment reasoning is recorded in two places: the code that performs it,
and the crate's design document. The round before this corrected the code, the
generated agent text and the refusal an operator reads, because there is no
central clone. There is op's own workspace, denied to everyone else for the
reason every participant's workspace is denied to everyone else.

Two sentences in the design document were not corrected, because a source round
may not edit a doc template. They say the record forbids writes under the
central clone and then explain what the central clone is.

The reasoning they record is unchanged and stays. What changes is the name of
the thing: a workspace has an owner, deny item one is that owner's, and the
exclusion that makes the rule workable rather than paralysing is that nobody is
denied their own.

Worth its own round rather than left for whenever somebody next opens that file,
because a design document is what a later reader reasons from, and this one
would have them reasoning about a thing the project does not have.
