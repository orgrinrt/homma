# Source changelist: an empty declaration builds nothing and turns green

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609030815_changelist.doc.lock.md`

## `homma-core`

### `src/release/gate.rs` (modify)

CHANGE: `parse_sets` refuses an empty list as `GateError::Manifest`, beside the malformed cases. `cargo_runs` takes whether the root is virtual, read off the root manifest having no `[package]`, and adds `--workspace --exclude <member>` to the all-features and no-features runs only on a virtual root; a root package keeps its bare runs.

### `src/release/gate_tests.rs` (modify)

CHANGE: `feature_sets = []` on a root and on a member is a manifest error and no step runs. A non-virtual root with a declaring member keeps its bare runs and the member gets `-p` runs. The trailing loop in the per-set test runs the tests step alone, the lint and docs arms being pinned above it.
