# src changelist

Source for the doc changelist `202611031246_changelist.doc.lock.md`, round `202611031244_topic.review-findings-on-the-release-roots-and-clones.md`. The findings of the first review of the branch: the scan that keeps agents in one module is an allow-list that sees every way to make one, the request test says what it found when no root could be read, the lookup a verb makes after the load is tested and not only the load, and the fixture the two crates test the load with is written once. The mutation record for the round is `mock/research/202611031244_release-roots-mutants/`, a script and the log of its last run.

CHANGE mock/crates/homma-core/src/tls.rs: `roots` writes `no_roots` to standard error once when the store ends up with no root in it, and `no_roots` is a new private function that builds the text from what the loader reported and the values of `SSL_CERT_FILE` and `SSL_CERT_DIR` where they are set
CHANGE mock/crates/homma-core/src/tls_tests.rs: `no_agent_is_made_outside_the_module_that_sets_the_roots` replaces the scan for `AgentBuilder::new`; it reports a file outside `src/tls.rs` (exempt by its path, not its name) that takes anything from `ureq` that is not on the allow-list, a glob, an alias of the crate or a path through `Agent::`, skipping comment lines and test files; the control `the_check_names_each_way_to_make_an_agent_and_leaves_the_rest` plants one file for each such way and three that must be left alone, and expects exactly the planted ones named
CHANGE mock/crates/homma-core/src/release/registry_tls_tests.rs: the test is renamed `ssl_cert_file_sets_the_roots_and_a_missing_file_is_said_on_stderr` and asks the child a third time with `SSL_CERT_FILE` naming a file that is not there, expecting the request refused and standard error to carry the heading of `no_roots` and the path; the first ask expects standard error to lack the heading; the refusal without the variable is asserted as `invalid peer certificate` and the module doc says why
CHANGE mock/crates/homma-core/src/testing.rs: `two_clones_and_a_scope_of_one` is a new public function that writes the manifest, a local file whose `repos` names only `inside`, and the two clone directories
CHANGE mock/crates/homma-core/src/config/tests.rs: the fixture of `whole_load_tests` is a call to `testing::two_clones_and_a_scope_of_one`
CHANGE mock/crates/homma-engine/src/cmd/util.rs: `resolve_repo` becomes a call to the new `resolve_repo_from`, which takes the directory to look in; the body moved unchanged except that it canonicalises the directory it is given
CHANGE mock/crates/homma-engine/src/cmd/release/config_tests.rs: the fixture is `homma_core::testing::two_clones_and_a_scope_of_one`; `config_of` is the config a release command line loads and `found_by` reads the repository names from it; `a_clone_outside_the_scope_resolves_by_name_and_from_inside_it` asks `resolve_repo_from` for the clone outside the scope by name and from a directory inside it, and the control `the_sweeps_config_refuses_the_same_lookups` expects both asks refused under the sweep's config, the first as outside the scope and the second as a directory in no repository
