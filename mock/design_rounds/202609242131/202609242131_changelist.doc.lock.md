## Current state

The capture paragraphs of `mock/DESIGN.md.tmpl` take the human-origin marker as
the only test of whose a line is, read a round nobody answered as an answered
one, say `--since` replaces a watermark, write `--bears-on` raw, and never check

## Changes proposed

- A tool that types into the terminal records each line beside the transcript,
  as `<session>.typed-by-tools.ndjson` with `at` and `text`, and a capture drops
  one human line per record: words equal to the text, bare or in one pasted
  wrapper, stamped at or after `at`, first that fits.
- A round with no answer and no note on any question is not an event.
- `--since` applies as well as a watermark, and is for the first run only.
- A `--bears-on` holding a line break is refused.
- The store is checked against the places homma never writes before anything
  is written, and a run with no `HOME` is refused there.
