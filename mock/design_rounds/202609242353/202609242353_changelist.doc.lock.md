## Current state

The capture paragraph of `mock/DESIGN.md.tmpl` spells the project directory as
every character outside `[A-Za-z0-9]` turned into `-`, per UTF-16 unit, and
stops there, so a path whose spelling runs past two hundred units is named a
directory the harness never makes.

## Changes proposed

- A spelling longer than two hundred units is cut at two hundred and gets `-`
  and a hash of the whole path: the 32-bit string hash, each UTF-16 unit added
  to thirty-one times the running value and wrapped, its absolute value written
  in base 36.
- The paragraph says the spelling was read out of the harness and is checked
  against it when the harness changes. The lines read are in
  `mock/research/202609242353_harness-project-directory/extracted.txt`, which
  the rendered document does not name.
