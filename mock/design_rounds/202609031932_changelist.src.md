# Source changelist: one entrypoint per git event, from a hooks table

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609031916_changelist.doc.lock.md`

## Comparison to deprecated changelist

`202609031919_changelist.src.deprecated.md` is this changelist as first
written, refused by its own tests on two points the doc changelist's own
comparison section names: git's arguments now reach an entry through
`{args}` rather than being appended to every command, and the refusal on a
tracked hooks directory is gone since the install writes into git's own
directory. Everything else below is what the deprecated changelist said.

## `homma-api`

### `src/hooks.rs` (add)

CHANGE: `Hooks` holds one array of `HookEntry` per git event, the release gate
`GATE` on `GATE_EVENT` first whether or not a table was written, then the
declared entries in the order written, a declared copy of the gate folded
into the one in front; `Hooks::new` refuses an event outside `EVENTS`, a glob
that does not parse and an entry with nothing to run, each as `InvalidHooks`
naming the row, and the `Deserialize` impl surfaces that as the manifest's
parse error. `HookEntry::matching` is the touched paths its globs match,
every touched path where it has none; `runs_for` says whether it runs;
`command` expands `PATHS` to the matches and `ARGS` to git's arguments,
each quoted for the shell. Tests pin the default table, the gate staying in
front of a written table and a serialised one, the three refusals, and the
matching and expansion with a quote in a path.

### `Cargo.toml` (modify)

CHANGE: `glob = "0.3"` is a dependency, already in the tree through cargo.

### `src/lib.rs` (modify)

CHANGE: `hooks` is a module and `HookEntry`, `Hooks`, `InvalidHooks` are
exported.

## `homma-core`

### `src/config.rs` (modify)

CHANGE: `Config` gains `hooks: homma_api::Hooks` under `[hooks]`, defaulted,
so a manifest without the table parses and a table with a bad row refuses
the load naming it.

### `src/hooks/mod.rs`, `src/hooks/install.rs`, `src/hooks/run.rs` (add)

CHANGE: `hooks::install` writes `script(event)` for every event the table
names into `hooks_dir`, the common git directory's `hooks/`, whatever
`core.hooksPath` says, refusing a foreign hook as `HookError::HookExists`
before writing anything, and reports `Reach`: `Direct` with no hooks path,
`Chained` where the path is mockspace's, `Unreached` otherwise.
`hooks::touched` is the staged paths for the commit-side events and, for
`pre-push`, the union over the refs on stdin of what each tip adds over its
remote, widened to the tip's whole tree where the remote is zeros or unknown.
`hooks::run` runs the entries whose globs match in order through `sh -c`
with `{paths}` and `{args}` expanded and stdin replayed, stops at the first
non-zero exit and returns `Ran`. Tests run both against real repositories, a
linked worktree included, with entries that record what reached them, and
one that would fail on appended arguments.

### `src/release/hook.rs` (delete), `src/release/mod.rs`, `src/lib.rs` (modify)

CHANGE: `release::hook` goes with `HookError::HooksPathOutside` and
`HookError::HooksPathTracked`; `hooks` is a module of the crate.

## `homma-engine`

### `src/cli.rs` (modify)

CHANGE: `Command::Hook { op: HookOp }` with `HookOp::Install { repo }` and
`HookOp::Run { event, args }`, the args trailing and hidden since only an
entrypoint passes them; `ReleaseOp::Hook` goes.

### `src/cmd/hook.rs` (add), `src/cmd/mod.rs`, `src/cmd/release/mod.rs` (modify)

CHANGE: `homma hook install <repo>` reports every path written and how git
reaches them, non-zero where it does not; `homma hook run <event>` reads stdin
where it is not a terminal, runs the event's entries against the repository
the working directory is in, and exits with the first refusal. `hook_cmd`
leaves the release module, whose `Report`, `finish` and `resolve_repo` are
`pub(crate)` for the hook module to share.

### `tests/cli_release.rs` (modify)

CHANGE: the two hook tests drive `homma hook install` and `homma hook run`
through the binary: one entrypoint per event with entries, the run verb
skipping an entry nothing staged matches and passing an event with no
entries, a manifest naming a non-event refused, and the install under a
foreign hooks path writing into git's own directory and exiting non-zero
with the reach line, under mockspace's path succeeding, and refusing a
foreign hook as before.
