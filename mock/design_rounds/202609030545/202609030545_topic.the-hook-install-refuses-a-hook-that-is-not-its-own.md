# The hook install refuses a hook that is not its own

**Date:** 2026-09-03
**Phase:** TOPIC
**Scope:** `homma-core/src/release/hook.rs`
**Source topics:** running `homma release hook install` across the workspace on 2026-09-03, and `202609030520/202609030520_topic.forgejo-writes-are-tested-on-the-wire-too.md`

## The findings

The install writes its `pre-push` wherever the hooks path resolves inside the repo, and across the workspace that overwrote eight repos' own pre-push hooks and planted eleven files in tracked `.githooks/` directories, where a hook ships with the repo and would demand homma of every contributor. The design says the install writes the hook or refuses and says why; these are two cases to refuse. A hooks directory with any tracked file is refused as the repo's own. A `pre-push` already there that is not this tool's is refused, naming it, and the tool's own is rewritten as before.

## What does not change

The design, and the mockspace refusal.
