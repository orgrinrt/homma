# nut-release-review-fixes

Review of round 202611231633 (workspace ticket 58f3f840efa4).

## What the review found

- No test covers the two places a nut release writes or reads `nut.toml` beyond the version module: the bump
  commit naming the manifest, and the check's walk over bumps on `main`. Put back the bump commit's old
  `deno.json` line and a nut release tags a commit whose `nut.toml` still carries the old version, with the
  suite green.
- `RepoKind::has_nut` has no caller and the design names none.

## Decision

- Tests only, and the unused accessor out. The design already says the bump commit carries the manifest and
  the check walks the kind's manifest; nothing in it changes.
