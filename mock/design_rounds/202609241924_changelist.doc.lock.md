# doc changelist

Round topic: `202609241918_topic.capture-watermark-by-line.md`, the only open
topic; this changelist consumes it whole.

## Current state

`mock/DESIGN.md.tmpl`, "The command surface", says a capture's `through` is the
timestamp of its last event and a run takes what is stamped after it, that an
answer is either a choice or typed text, and that the transcript directory is
named for the workspace path as given.

## Changes proposed

All in the `homma capture` paragraphs of "The command surface".

- `through` is the `uuid` of the last complete line read, the next run starts
  after that line, and the latest capture is the one latest in the transcript.
  A `through` the transcript does not hold is refused. `--since` filters by the
  event's stamp and no longer competes with the watermark for the floor.
- A queued message written twice, attachment and typed line tied by
  `source_uuid`, is read once, the earlier of the two.
- An answer is read as labels first, quoted where a label holds `, `, longest
  first, and the rest is the typed part; only that and the notes are quoted.
- The projects directory is named for the real path, symlinks resolved.
- A last line with no newline is not read.
- The file is created new and never replaces one.

## What is not changed

The store and projects paths stay fixed in the source. No crate design; the
command still adds no type another crate reads. `--session` taken as a path
without `HOME` and the README wording are source changes with nothing in the
design to move.
