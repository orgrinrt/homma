## CHANGE: `homma agent nudge <event>` FROM nothing TO the verb running the rows
File: `mock/crates/homma-engine/src/cmd/nudge/mod.rs`, `mock/crates/homma-engine/src/cmd/nudge/record.rs`, `mock/crates/homma-engine/src/cmd/nudge/tests.rs`, `mock/crates/homma-engine/src/cli.rs`, `mock/crates/homma-engine/src/cmd/mod.rs`
`AgentOp::Nudge` reads the payload on stdin and prints the decision. A shell call carrying a `once` row's marker as a word answers that row's stop while it waits, after `evidence` where set; the stopped command with the marker and reason after it is the stopped call and passes. The rows of the event then run in order: `once` passes a call answered within `ttl`, takes the same call made again as the answer for a row without a marker, and otherwise stops the call where `when` says it applies; `refuse` stops it every time; `inform` rows that are due are said as one notice, and a stop says none of them. The record per session and the log are under `homma/nudges` in the workspace's git directory. A manifest that does not load is said as added context.
Verification: eighteen tests in `nudge/tests.rs`. Taking the word boundary off the marker and the text comparison off a taken answer fails `the_marker_is_found_only_as_a_word`, `the_stopped_command_carrying_the_marker_is_the_answer_and_runs_at_once` and `without_a_marker_the_same_call_made_again_is_the_answer`.
