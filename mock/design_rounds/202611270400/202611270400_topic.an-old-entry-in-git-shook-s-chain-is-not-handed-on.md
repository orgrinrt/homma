# an-old-entry-in-git-shook-s-chain-is-not-handed-on

A review of round 202611270330 found a double run. An older homma registered a clone-local manifest `homma`
whose entries run `homma hook run <event>`. On the first event under the new engine, git-shook's dispatcher runs
that entry, which installs and hands the event to the dispatcher again; the inner dispatcher runs the member's
other entries, and then the outer one runs them as well. An entry with side effects, such as a commit-msg
rewriter, runs twice.

## Who calls the verb, told apart by the hooks path

`homma hook run` is called two ways, and the hooks path says which:

- Where git-shook holds `core.hooksPath`, git runs git-shook's dispatcher and never git's own hooks directory,
  so the verb was called by an entry of git-shook's chain: an older homma's clone-local manifest, or an older
  homma's entrypoint git-shook adopted as `00-existing`.
- Where it does not, the verb was called by an older homma's entrypoint in git's own hooks directory. There the
  install refuses, and the verb fails closed, as round 202611270330 decided.

## Decision

- Called from git-shook's chain, the verb installs and does not hand the event on. The chain that called it goes
  on to its other entries itself: the base lists a chain's entries once when it starts and reads each entry's
  file when it reaches it, so the entries it listed run once, each as the install left it.
- What the hand-on gave there that the chain cannot is the gate at `pre-push`, since the entry running is the
  one that was the gate's. So at the gate's event the verb runs the release gate itself, with git's arguments and
  stdin, and exits as it does.
- An entry the install registers for the first time, the workspace's manifest copied in, is not in the list the
  running chain made, so it runs from the next event on. That is one event, the first after the upgrade, and it
  is said in the line the verb prints.
- Where the install refuses, the verb fails closed with the install's words, as before.
- The hand-on to the dispatcher goes: with the path held it doubles the chain, and without it the install has
  already refused.
