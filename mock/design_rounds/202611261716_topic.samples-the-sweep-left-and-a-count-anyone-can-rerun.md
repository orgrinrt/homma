# samples-the-sweep-left-and-a-count-anyone-can-rerun

Follows the closed rounds 202611261602 and 202611261626.

## Samples the sweep did not reach

Round 202611261602 decided that a real name used only as a sample is replaced by an invented one.
A review found tests that still use real names as samples: a clone path under a real working
directory, a real repository as a sample member and in a capture's `bears_on`, a real hook's file
name, a real tracker tool as the sample of an injected tool and of an answer's kind, and the
maintainer's responses directory as a sample goal path. Decision: each is replaced the same way,
by an invented name; the tests that read a real dependency's own configuration (the search
command's corpus configuration and index) keep it, since there the name is the thing under test.
Two doc comments in live code name the same tracker; they are reworded to say what they mean
without it.

## A count anyone can rerun

Round 202611261602 stated a count of lines before and after the sweep without the pattern it
counted, so the count cannot be checked. Decision: this round's changelist carries the exact
command, its count on the trunk the branch starts from and at the round's end, and what each
remaining hit is.

## Review traces in the earlier topics

Round 202611261602 wrote, as a decision, that its earlier topics would be reworded when the
repository is rehoused. That is not a design decision of this crate. It is a deferral: a closed
round is frozen and the edit hook refuses any change under its directory, so no round can reword
it. The rewording is tracked by ticket `homma_round_topic_and_a_commit_subject_carry_traces_of_the_r`,
which stays open. Decision: none.
