# Source changelist: a declared feature set replaces all-features

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609030755_changelist.doc.lock.md`

## `homma-core`

### `src/release/gate.rs` (modify)

CHANGE: `calls_for` reads the declared sets once and builds lint, tests and docs from them. Where the root package declares sets, each of the three runs once per set with `--no-default-features --features <set>` and no `--all-features` run is made. Where it declares none, lint and docs run with all features as before, tests run with all and with none, and where a member declares sets those workspace-wide runs carry `--workspace --exclude <member>` for each declaring member. A member's sets run against that member with `-p` on all three steps, not only tests.

### `src/release/gate_tests.rs` (modify)

CHANGE: the tests expecting `cargo test --all-features` beside declared sets expect its absence. Added: a root declaring sets gets clippy and doc once per set and no all-features call on any step; a workspace with a declaring member excludes it from the workspace-wide runs and gives it `-p` runs on lint and docs too; a mutually exclusive pair of sets never appears joined in one call.
