# Src changelist: the exit code is the contract

## crates/homma-engine/tests/config_exit_code_smoke.rs

New. Walks the whole loop through the built binary, because the exit code is
the interface between the command and the gate and no test had ever produced
one.

- CHANGE: `a_repo_missing_a_required_config_exits_non_zero`, asserting the
  code rather than the wording, and that the repo and the config are named so
  the refusal a person sees is not empty.
- CHANGE: `init_places_it_and_the_check_then_passes`, the other half of the
  same loop, asserting the file arrives with the shared copy's bytes. Reading
  it back rather than trusting the report, because a placement stage that
  reported success and wrote nothing would satisfy an assertion about its own
  output.
- CHANGE: `a_workspace_whose_configs_are_in_order_exits_zero` as the control.
  Without it the first case would pass against a command that exited non-zero
  unconditionally, which is the failure that would refuse every commit in
  every repo.
- CHANGE: `an_untagged_template_does_not_block`, which is the state the
  workspace is actually in until its templates move into tag directories. It
  has to not block, or landing this refuses every commit everywhere for a
  reason no repo can fix.
