# agent-reexport-replaces-the-text-scan


## The text scan lets two spellings of an alias through

The reviewer's second pass planted `pub type Plain = ureq::Agent;` and `type Plain=ureq::Agent;` in files outside `tls.rs`, and the scan in `tls_tests.rs` did not report either, since it matches a line that starts with `type ` and holds `= ureq::Agent`. Every further spelling of an alias (a `pub(crate) type`, a `use` in a nested module, a macro) is one more line for the scan to learn.

## Decision

`tls.rs` re-exports the type, `pub(crate) use ureq::Agent;`, and the crate names it as `crate::tls::Agent` everywhere. `Agent` leaves the list of what outside code may take from `ureq`, so any `ureq::Agent` written outside `tls.rs` is reported in whatever form it takes, and the checks for `Agent::`, for a rename and for a type alias go, since the list now covers them. The design sentence says so.
