# src changelist

This changelist comes from `202611270400_topic.an-old-entry-in-git-shook-s-chain-is-not-handed-on.md`, the round's one topic, and carries out the locked doc changelist `202611270400_changelist.doc.lock.md`.

## CHANGE: `homma hook run` FROM handing the event to git-shook's dispatcher TO installing, then running only the gate at `pre-push`
File: `mock/crates/homma-engine/src/cmd/hook.rs`
Verification: `run_cmd` installs as before and fails closed on a refusal. After the install it runs nothing at any event but `GATE_EVENT`, and there `GATE` with git's arguments and its inherited stdin, exiting as that does. The line it prints says entries new to the clone run from the next event. `cli.rs` documents the verb the same way.

## CHANGE: the tests of an old entry FROM the hand-on TO the chain running each entry once
File: `mock/crates/homma-engine/tests/hook_smoke.rs`
Verification: `an_older_chain_entry_installs_and_runs_the_gate_and_hands_nothing_on` asserts the workspace's entry new to the clone does not run in the event that registered it and the gate runs with git's arguments and stdin at `pre-push`. `the_first_commit_after_the_upgrade_runs_each_entry_once` commits a member with its own entry beside an older homma's clone-local `homma` entry calling `homma hook run pre-commit`, and the member's entry runs once. Both need `GIT_SHOOK`; putting the hand-on back fails both.
