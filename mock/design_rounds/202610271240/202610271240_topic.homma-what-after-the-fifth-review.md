# homma-what-after-the-fifth-review

A fifth review left the design with three gaps, and the tests with two that pass with their rule taken out.

- A catalogue suite, kept red on purpose and run apart from the suites, was offered as a script. The design's list of test names gains `_catalogue`.
- The code drops a word of one letter, which the design did not say. The design now says it.
- Listing a mockspace repository runs `cargo mock`, which refreshes that repository's hooks. The design now says so as the one side effect of the source.
- The tests: the name and tag weights and the best-way-wins rule are tested with fixtures where a tie would not give the expected answer, the factor for the share of the query matched has a test, and the two waits after a listing exits share one deadline. A query made of a listing left running by Ctrl-C is not changed: the listing is in its own process group so an overrun can be ended whole, and the report names it.

No other topic filed earlier remains open for this work.
