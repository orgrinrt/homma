# Source changelist: the tagline is the blockquote in the badge block

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609032119_changelist.doc.lock.md`

## `homma-core`

### `src/release/tagline.rs` (modify)

CHANGE: `tagline(readme)` FROM the first paragraph of prose after the title
TO the first line beginning `>` after the first heading, atx or setext, with
the marker stripped and `>` continuation lines and lazy continuations joined
by a space; the opening prose is never returned.
Verification: the test `the_tagline_is_the_blockquote_under_the_title_inside_the_badge_block`
runs notko's, homma's and beech's readme heads verbatim through it.

CHANGE: `cargo_description(root)` and `deno_description(root)` FROM readers
of the root manifest TO private readers of one manifest each, answering
`None` for a virtual root, a `publish = false` package or an unnamed deno
config; `published(root)` (add) walks the tree past `target/`, `node_modules/`
and `.git/` and returns every `Published { manifest, description, readme }`,
the readme being the one beside the manifest or the root's.
Verification: `grep -c "pub fn published" mock/crates/homma-core/src/release/tagline.rs` is 1.

CHANGE: `check(root, kind)` FROM one manifest per kind TO `check(root)`, every
published manifest against its readme's tagline, a manifest without a
tagline logged and skipped, all of them skipped making the step skipped, no
manifest a plain skip, and the log naming the manifest of every pair.
Verification: `grep -c "pub fn check(root: &Path) -> StepOutcome" mock/crates/homma-core/src/release/tagline.rs` is 1.

### `src/release/gate.rs` (modify)

CHANGE: `run_step` calls `tagline::check(root)`; the kind no longer reaches it.

### `src/release/gate_tests.rs` (modify)

CHANGE: `the_description_step_runs_in_the_gate_and_a_drifted_description_turns_the_run_red`
(add) runs the whole gate over a git repository with a readme and a package,
green when the description is the tagline and red when it is not, through
`run_gate` rather than through the module.
