## Current state

The description step reads the tagline as the first paragraph of prose after
the title, past the badge block, which on every readme in the estate is the
opening prose rather than the tagline; the tagline is the blockquote inside
the badge block. It reads the root `Cargo.toml` alone, which on a virtual
root declares nothing while the published crate sits in a member. No gate
test names the step.
