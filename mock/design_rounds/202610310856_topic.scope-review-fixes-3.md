# Scope review fixes 3

## What the third review found, and what is settled

`archive` and `migrate` each wrote their own "no repository named" error, so naming a clone outside the scope to either gave the wrong lead. Both now call the one function that builds it. After this round `no repository named` is written once in the engine's commands, and a test per command shows it.

The design said the manifest's loader reads one thing from the local file. It also reads the `hooks` and `agent.hooks` tables, through the layers, and `hook run` depends on that. The sentence names them.
