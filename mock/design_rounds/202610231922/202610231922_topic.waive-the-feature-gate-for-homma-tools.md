# waive-the-feature-gate-for-homma-tools

On 23 October 2026 op was asked whether PR #74 should gate homma's tools behind a cargo feature as well as the unix target. The options were: "No feature, waive it: tools are always there wherever renki builds; the design line stays, citing your answer", and "Default-off feature: add a `tools` cargo feature off by default; workspace builds turn it on". Op chose "No feature, waive it".

The design records that as a waiver of the feature half of the workspace's gate-per-target-and-per-feature rule for homma's tools, and names the set-aside option, a default-off `tools` feature, so a later reader sees both.
