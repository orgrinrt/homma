# homma-what-after-the-sixth-review

A sixth review found one wrong answer from the filler check and gaps in the tests of the weight orders.

- The filler was checked against the fully stemmed word, so `note` stemmed to `not` and went with the filler. The check is now against the word with its plural off, so `note`, `notes`, `noted` and `note taking` keep their subject. The design says so.
- The design's example of a bare tool named verbs the tool does not have. It now gives the real ones.
- The tests of the field weights and the match grades covered some adjacent pairs only. Each adjacent pair now has a case where a tie picks the wrong winner.
- The readme row listed fewer places than the code searches. It now lists them.
- Not changed, and said in the hand-over: which verb a bare tool prints when a verb matched through a synonym and lost to another field is left as the design has it; the process group of an overrun listing is ended with the `kill` command, since no library for it is among the dependencies; the `-check.sh` convention of control scripts is not among the test names.
