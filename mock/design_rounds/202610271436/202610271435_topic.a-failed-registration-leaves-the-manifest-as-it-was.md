# a-failed-registration-leaves-the-manifest-as-it-was

A sixth review of the shook branches found that `homma hook install` writes `homma.toml` into `shook/manifests/` before it asks git-shook to register it, and leaves that file where it is when git-shook refuses or cannot run. A file left behind by a failure is read by every later `git shook install` and `doctor` in the clone, so one refusal can keep failing for reasons unrelated to what the operator does next.

The install gives the manifest back as it was before the call: the text it had where it had one, and no file where it had none. The same is done by mockspace for its own manifest.

## Left as they are

A test that returns early on a machine where git-shook is installed (`git_without_the_subcommand_says_git_shook_is_not_installed`) stays as a recorded weakness: the install puts the supplied directory in front of `PATH` and cannot take git-shook out of the rest of it, and changing that would add a parameter to the verb for the sake of one test.
