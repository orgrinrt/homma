# Source changelist: a failed push of main leaves no merge behind

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609030350_changelist.doc.lock.md`

## `homma-core`

### `src/release/run.rs`, `run_tests.rs` (modify)

CHANGE: `step_merge_and_tag` records the release line's commit before merging and, where the merge lands and the push is refused, resets the release line to it after aborting whatever merge is still open, so the local `main` holds nothing the remote does not. The refused-push test asserts `main` is back at its pre-merge commit and that a plan made afterwards sees the same commits as before.

### `src/release/git.rs` (modify)

CHANGE: `remote_tags` runs `ls-remote` with `GIT_HTTP_LOW_SPEED_LIMIT` and `GIT_HTTP_LOW_SPEED_TIME` in its environment, so a remote that stops answering is given up on in the same order of time the registry client allows.
