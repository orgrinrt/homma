# the-gate-follows-the-toml


Sent back by the first read of the branch by a fresh reviewer. The round that
made adoption the toml said the commit gate follows it, and only the mock
directory it reads was changed. The gate still scores three surfaces, so a
repository with `mock/` and no toml is refused with an instruction to run
`homma agent regen`, which skips exactly that repository. The gate now leaves a
repository without a toml alone, the design paragraph on the gate says so, and
the test that held the old refusal is inverted.

Taken in the same round: the gate reads a toml string in single quotes as well
as double, as the status probe does; a repository that is not on disk is not
told to run `homma agent regen`; every surface of `roll_up` is held by a test
of its own; and the rustdoc names the declared mock directory where it said
`mock/agent/`, with the toml lookup's reach stated.
