# What the third review found on the release

**Date:** 2026-09-02
**Phase:** TOPIC
**Scope:** `homma-core/src/release/check.rs` and `publish.rs`, `homma-engine/src/cmd/release/mod.rs`, the tests beside them, and one sentence of `homma-core/DEEPDIVE_release.md.tmpl`
**Source topics:** the third review of pull request 46, and `202609022140/202609022115_topic.a-release-is-a-gated-merge-off-main.md`

## The findings

The deep dive lists `tag.bump.tagged` among the blocking checks and the check never implemented it. Every commit on the release line's first-parent walk that changes the manifest version is a bump, and a bump with no versioned tag pointing at it is the half-done release the check exists to name. It is implemented, walking `main` by first parent so a bump merged in from the trunk is found at the merge commit.

The workspace-wide run releases repos in name order while the deep dive asks for dependency order, and the ignored red test records that. What the review added is that the path still runs, and a dependent released ahead of what it depends on gets its tag and forge release pushed before the publish fails, which nobody can take back. So the run without a repo refuses when any candidate's manifest names a sibling member, until the order is built, and the refusal names the pair and the order to release them in by hand.

The npm user config's path went to the tool as `to_str().unwrap_or_default()`, so a temp path that is not UTF-8 would have handed npm an empty config name and let it read the ambient one. It is an error now.

`main.unreleased` is an id the earlier catalogue did not carry, and the deep dive said every id was the catalogue's. The deep dive says which one is new.

The FIXME on `release_order` said nothing reads the cross-repo graph; the refusal above reads the sibling edges out of the manifests, so what is left to build is the ordering, and the comment says that. The catalogued gap is tracked in the workspace agenda as `homma-release-orders-repos-by-dependency`, and the ignore marker names it.

## What does not change

The design, except for naming `main.unreleased` as an id of its own.
