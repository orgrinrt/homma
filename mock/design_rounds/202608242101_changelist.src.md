# Src changelist: aggregated hooks find their own workspace

**Date:** 2026-08-24
**Phase:** IMPL
**Source topic:** `202608242101_topic.aggregated-hooks-are-inert-outside-the-workspace-that-made-them.md`
**Doc changelist:** `202608242101_changelist.doc.lock.md`

## CHANGE: `homma-core/src/config.rs`, `Config::from_path` anchors on an absolute config path

MODIFY `Config::from_path`: resolve `path` against the working directory before
taking its parent, so a relative `workspace.path` beside a relative config path
lands absolute. A relative path handed to a command means "relative to where I
am", so the working directory is the correct base rather than an invented one.

ADD test `a_relative_config_path_still_yields_an_absolute_workspace_path`: the
case the existing sibling test does not reach.

ADD test `an_absolute_config_path_is_unaffected_by_the_working_directory`: the
control, so the change is visible as a widening rather than a replacement.

## CHANGE: `homma/src/cmd/aggregate.rs`, a wrapper locates its own workspace

MODIFY `wrapper_script`: takes the repo's workspace-relative path and the hook's
repo-relative path in place of two absolute paths. The emitted script derives
the workspace from `${BASH_SOURCE[0]}`, which sits at a fixed depth under it,
and declines when the hook it fronts is not executable.

MODIFY `aggregate_hooks`: derives the workspace-relative repo path by stripping
the workspace root, falling back to the absolute path for a repo declared
outside the workspace, which remains correct for the workspace that generated
it and is the only shape available there.

MODIFY `merge_settings`: takes the repos this run actually visited alongside the
full known set. A managed entry is stripped when it names a visited repo, and
preserved when it names a known repo this workspace has not cloned.

ADD test `a_wrapper_carries_no_absolute_path_and_finds_its_workspace_from_its_own_location`.

ADD test `a_wrapper_matches_a_path_under_its_repo_and_declines_one_outside`: runs
the emitted script against a real temporary workspace, both arms.

ADD test `a_wrapper_declines_when_the_repo_is_not_cloned_here`.

ADD test `a_relative_repo_root_never_matches_the_absolute_path_the_host_supplies`:
pins the reason the old shape was inert, against the old shape's own comparison.

ADD test `merge_settings_keeps_entries_for_a_known_repo_this_run_did_not_visit`.

ADD test `merge_settings_still_replaces_entries_for_a_repo_it_did_visit`: the
control on the line above, so preservation is not mistaken for never sweeping.

## CHANGE: `homma/src/cmd/agent.rs`, regen reports which repos it visited

MODIFY the aggregation loop: collects the repos whose hooks were aggregated and
passes that set to `merge_settings`.
