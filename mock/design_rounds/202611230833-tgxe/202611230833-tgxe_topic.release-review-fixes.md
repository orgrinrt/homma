# release-review-fixes

The review of round `202611230755-j2eh` (the release port, closed at `05df211`) returned three blockers and six
follow-ups, filed as this flat topic after that round's close.

## What the design says

`DEEPDIVE_release.md.tmpl`, Credentials: the store off macOS is the variable `token_env` names, "read and never
written, with no expiry, and a write refused by a reason that names the variable". "A store that cannot be read ...
is a reason on that credential's line: the status still prints every line and exits non-zero".

## Where the source diverges

- `flow::fix_token` asks for a paste, proves it, and only then calls `put`. Off macOS `put` always refuses, the
  refusal becomes `State::Unreachable`, `needs_work()` is false for it, so `flow::all` prints "all are good now."
  and `auth fix <name>` exits zero. The reviewer's probe: `Environment { vars: [("jsr", "UNSET")] }`, a pasting
  prompt and a probe answering 200 gave `all() == true`.
- Twelve of the 26 warn rows of the catalogue never fire in any test, and the clean fixture has no remote and no
  `dev`, so no branch row can fire there.
- The root README row for `release` names only the gate and the release merge.
- `Stored` derives `Debug` over its secret field.
- `versions tag` names a first tag `v0.1.0` where the python named it `0.1.0`; the repos of this workspace tag bare
  (`0.0.1` on homma, `0.0.0-dNN` in the cadence).
- `estate --json <path>` runs before the `jumps` and `missing` selectors and ignores them silently.
- `auth/tests.rs` is over 600 lines.
- `tls::tests::no_agent_is_made_outside_the_module_that_sets_the_roots` fails with ENOENT in a full run.

## Decisions (from the brief, op away)

- A store that refuses writes is found out before a paste is asked for: the walk stops for that entry, names the
  refusal, which names the variable, and the entry counts as needing work. A failed `put` after a proven paste is
  needs work too. `auth`, `auth fix` and `auth status` all exit non-zero then.
- The catalogue's warn rows each get a test that fires it and one that keeps it quiet, the branch rows over a
  fixture with a bare remote and a `dev` branch.
- The README row names the four things: the gate, the release merge, the publish credentials and the version and
  estate reports.
- `Stored`'s `Debug` is written by hand with the secret redacted.
- A repo with no tags gets a bare tag, the workspace's own style; where tags exist the repo's style still wins.
- `estate --json` refuses a `jumps` or `missing` selector beside it, with a reason, and writes nothing.
- `auth/tests.rs` splits by concern into a directory of modules.
- The ENOENT is a source-reading test racing a test that makes and removes a directory under `src/`; the
  offender moves to a temp directory.
