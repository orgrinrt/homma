# doc changelist

Round topic: `202609241953_topic.capture-blocks-and-twins.md`, the only open
topic; this changelist consumes it whole.

## Current state

`mock/DESIGN.md.tmpl`, "The command surface", reads a queued message's words as
a string only, ties duplicates only as an attachment and a typed line, says
nothing of content blocks, and splits every answer labels-first whether the
question took one answer or several.

## Changes proposed

All in the `homma capture` paragraphs.

- Every human line whose `uuid` or `source_uuid` another has named is one
  message, read where the first of them was written.
- Words that are content blocks are read as their text blocks in order, joined
  by a blank line; an image alone is nothing said. Said once, for typed lines
  and queued messages alike.
- A single-select answer is a label when it equals one, and typed text whole
  otherwise; the labels-first split is for multi-select only.

## What is not changed

The voice tool's context line, which the topic leaves to the voice tool. The
`--since` help text and the test fixes have nothing in the design to move.
