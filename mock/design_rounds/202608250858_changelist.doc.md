# Doc changelist: what a stranger gets, and what it tells them

**Date:** 2026-08-25
**Round:** 202608250858
**Source topic:** `202608250858_topic.what-a-stranger-gets.md`

Three documents. The readme is authored directly; the other two are templates.

## CHANGE: `README.md`

The command table gains a row for `agent`, and its `docs` row becomes
`homma docs status`, which is the command that runs. Both rows are named in the
runnable form rather than the parent, since the table is what a reader types.

The paragraph on tokens gains the second half of the answer. It says today that
tokens come out of the environment and that nothing secret goes into the
manifest, which is true and is not all of it: a manifest may carry `token_cmd`,
an argument list homma runs to obtain a credential. The paragraph names the key,
says what it is for, and says plainly that a manifest from someone else runs
whatever it names.

## CHANGE: `mock/crates/homma-org/DESIGN.md.tmpl`

Seven places appeal to "the record" for a rule, or name a particular operator's
directories. Each states the rule instead.

The deny list becomes what it is: the agent harness's settings directory under
the operator's home, every other participant's workspace as the registry gives
them, and whatever the manifest's own `deny` names. The list of seven items and
which three are locations goes; a reader cannot see that list and does not need
to, since the three are stated here in full.

The case-folding paragraph loses its worked example built on one operator's
directory names and uses a neutral pair. The workspace-layout paragraph loses
the particular path it cites as the ordinary case and describes the shape.

## CHANGE: `mock/crates/homma-store/DESIGN.md.tmpl`

One sentence has the immutability refusal "name the record". It names the rule
it enforces.
