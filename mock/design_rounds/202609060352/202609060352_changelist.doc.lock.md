# Doc changelist: the rules half is behind the skills half

## `mock/DESIGN.md.tmpl` (update)

The two corpus sections are where the generation pass is described, and neither
says what happens to a generated file the pass no longer writes. That silence
is what let the two halves diverge without either looking wrong.

- "The rule corpus": one paragraph saying that the destination is the
  always-loaded set, so a card whose rule is gone is not a stale file sitting
  in a directory, it is a document injected into every session. And that the
  pass reports such a card rather than deleting it, on the ground the skill
  corpus already gives for a directory nothing claims: the pass cannot tell a
  card it wrote last time from a document somebody put there on purpose, and
  the two look identical on disk.
- "The rule corpus": one sentence on the inline list form, saying an element
  may carry a comma inside quotes and that the split respects them. That is a
  statement about the format rather than about the parser, and a reader writing
  a `paths` glob needs it, since a brace group is the ordinary way to write one
  and is unexpressible if the comma splits.
- "The skill corpus": nothing added. What it says about an unclaimed directory
  is what the rule corpus now says about an unclaimed card, and saying it twice
  is how the two start disagreeing. The rule paragraph points at it instead.

The additions carry no inline emphasis. The surrounding paragraphs use it and
the file renders into `docs/`, where the writing rules forbid it; that is a
cleanup of its own rather than something to extend in passing.

## `mock/crates/homma-org/DESIGN.md.tmpl` and `mock/crates/homma-api/DESIGN.md.tmpl` (no change)

Stated so the absence is a decision. Neither describes the corpora at all: the
org design covers the registry, the workspace lifecycle, the shared tool
configs and agent generation, and the api design covers configuration and
paths. The corpus is described once, at the workspace level, and putting a
second account of it in a crate document would be the drift this round is
about, one tier down.

## The generated pages (regenerate, no hand edit)

`docs/DESIGN.md` renders from the template above. Nothing is authored there.

## What this changelist does not touch

The rule and skill corpora themselves. Nothing about which rules exist or what
they say changes in this round; what changes is what the pass does with the
files it generates from them.
