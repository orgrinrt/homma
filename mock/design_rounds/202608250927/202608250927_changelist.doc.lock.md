## CHANGE: `README.md`

`deny` gets a paragraph and a block of its own below the manifest example,
showing both spellings it takes: a bare path, and a table carrying the reason
the refusal will show. The paragraph says what the key is for and what is
denied without being named, so the list an operator is adding to is visible
rather than implied. It also says the key sits above the first `[table]`, since
a bare key written below one belongs to that table instead and nothing about
the example would say so.

A second block rather than a line inside the first, because the manifest
example is already long enough that a reader looking for the workspace stanza
should not meet an unrelated key first.
