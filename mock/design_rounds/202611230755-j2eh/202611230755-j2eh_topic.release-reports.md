# release-reports

The versions and estate halves of the release python, from the same tickets as the auth topic.

## versions

`.shared/scripts/release/versions` and `history.py`: a repo's version timeline read off the trunks' commits that
touch the manifest (`dev`, `main`, `master` and their `origin/` copies, never `HEAD`); each step judged sensible
(one legal increment, the `0.0.0-dNN` design phase advancing by one and leaving at `0.0.1` only); a tag counts
for the last version change it can reach, by ancestry; `plan` lists untagged releasable steps (not `0.0.0`, not at
or before a backwards step), unclean steps and what crates.io holds per publishable crate; `tag` writes the
missing tags at the bumps; `retag` finds tags off every trunk and moves them to a trunk commit with the same tree,
or the same author date and subject, refusing where more than one matches and journalling the undo line in
`.git/retag-journal.txt` first. A virtual workspace's version is its one versioned member's, several is a
refusal, `--manifest` names one.

## estate

`.shared/scripts/release/estate`: every package under the workspace root, cargo crates not `publish = false` and
the scoped jsr package, against its tags (jsr reads `v`-prefixed, cargo bare), what the manifest said at each tag,
what the registry holds, the missing and the jumps. Subcommands `jumps` and `missing`, and `--json <path>`.

## Decisions

- `homma release versions [<repo>] | --all`, `homma release versions plan <repo>`, `tag <repo>`, `retag [<repo>]
  [--apply]`; `homma release estate [jumps|missing] [--json <path>]`.
- No push from either: the python's `--push` pushed tags by hand, which the workspace routes through
  `forge_route`. The verbs write local tags and say what to push.
- Step legality is `Version::is_one_step` on plain releases, shared with `semver.gaps`, rather than a third copy.
- The registry is asked through the existing registry layer (index, jsr meta, npm document); a jsr package counts
  for the estate when its scope is `[registries.jsr] scope`, or any where none is set.
