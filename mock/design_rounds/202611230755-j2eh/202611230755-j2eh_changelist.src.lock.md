# src changelist

Doc changelist: `202611230755-j2eh_changelist.doc.lock.md`.

## mock/crates/homma-core

- `src/release/sequence.rs` (new): `releases`, `gaps`, `bridge` (an empty list for no gap, `None` for a gap
  nothing closes), `first_descent` and `sandwiched`, a legal step being `Version::is_one_step`. Tests in
  `sequence_tests.rs`, the python's `test_semver` and `test_sequence` cases with their values.
- `src/release/day.rs` (new): `Day`, days since the epoch, `parse` of an ISO date at a string's head,
  `civil_from_days` and `days_from_civil`; the engine's clock calls it rather than carrying its own copy.
- `src/release/registry.rs`: `Holding`, the live and the yanked versions, `holding` and `parse_holding`; jsr's
  yanked versions are kept apart, `published_versions` and `parse` read the live ones as before; the agent is
  crate-visible for the auth probe.
- `src/release/packages.rs`: `Published.yanked`, filled by `fetch_published`; `Crate`, `crates` (every crate not
  `publish = false`, an inherited version read from the root) and `member_manifests`.
- `src/release/check.rs`: `reg.unpublished` counts a yanked version as published; the warn rows of
  `hygiene` are appended.
- `src/release/hygiene.rs` (new): the warn rows the doc names, `Seen`, `masked`, `has_conflict`. Tests in
  `hygiene_tests.rs` against real repositories, each row with its failing case.
- `src/release/history.rs` (new): `Step`, `design_round`, `sensible`, `mainlines`, `version_in`, `timeline`,
  `releasable`, `Tag`, `all_tags`, `tags_by_commit`, `released_at`, `Orphan`, `Matched`, `orphans`,
  `retarget` with `JOURNAL`, `Refused`, `manifest_for`, `versioned_members`. Tests in `history_tests.rs`, the
  python's `history_test` and `versions_test` cases, the real `filter-branch` rewrite included.
- `src/release/estate.rs` (new): `Package`, `jsr_packages`, `cargo_packages`, `packages_under`, `tag_versions`,
  `declared_at`, `jumps`, `TagRow`, `Row`, `measure`, `measure_all`, `EstateError`. Tests in `estate_tests.rs`,
  the python's `estate_test` cases.
- `src/release/auth/` (new): `mod.rs` with `State`, `Status`, `grade`, `Token`, `Cli`, `Kind`, `Entry`,
  `ENTRIES`, `entry`, `Probe`, `Live`, `request`, `judge`, `judge_cli`, `check`, `line`, `masked`; `store.rs`
  with `Stored`, `Unavailable`, `Store`, `Keychain` (through `security`, the program named so a test names
  one that is not there), `comment_date`, `Environment` (the registry's `token_env`, read-only) and
  `default_store`, the keychain chosen on macOS only; `flow.rs` with `Prompt`, `fix_token` (judged before
  stored), `fix`, `status`, `all`, `token`, `expiry`, `diagnose`, `write_npmrc` and `env_lines`. Tests in
  `tests.rs`: the python's `auth_test` and `registries_test` cases, the npm control rewritten for npm 10,
  which lists an unknown key as it lists a known one, and the traceback's case, a keychain program that is
  not there.
- `src/release/publish.rs`: `NPM_REGISTRY` and `npmrc_line`, shared by the publish and the auth npmrc.
- `src/release/git.rs`: `trimmed` crate-visible.
- `src/release/mod.rs`: the new modules.
- `src/config.rs`: `RegistryConfig.scope` and `AuthConfig.npmrc`.
- `src/release/check_tests.rs`, `src/release/workspace_tests.rs`: the fixtures track a README and a licence,
  so the new warn rows stay quiet where the tests read every finding.
- `src/forge/token_tests.rs`: the literal gains `scope`.

## mock/crates/homma-engine

- `src/cli.rs`: `ReleaseOp::Auth`, `Versions`, `Estate`, and `AuthOp`, `VersionsOp`, `EstateOp`.
- `src/cmd/release/auth.rs` (new): the terminal behind `Prompt`, prompts on standard error, echo off through
  `stty` for a secret; the store from each registry's `token_env`; `npmrc_path`; `token` and `npmrc` print
  bare. Tests: the npmrc path and every verb's command line.
- `src/cmd/release/versions.rs`, `src/cmd/release/estate.rs` (new): the views and repairs, nothing pushed.
- `src/cmd/release/mod.rs`: the three dispatched.
- `src/cmd/release/clock.rs`: `civil_from_days` calls the core's.
