# the-load-counts-what-a-session-loads-at-its-start

A second review of the branch that renders rule cards by session role and place found that `homma rules load` counts every card the session admits, and a card with a `paths:` scope is not loaded when a session starts: the host reads that scope and injects the card only against matching files. The figure the first round quoted, 118 cards and 107,785 bytes, is the always-loaded set, the cards with no scope. A load report that includes the gated cards overstates every row against that figure, and the smoke test never saw it because its fixture had no gated rule.

## What changes

The cards and bytes of a row count the cards the session loads at its start, those with no `paths:` scope. The cards a session admits and loads only against matching files are reported beside them, as their own count and bytes, so the table says both and neither is hidden inside the other. The design states which is which.

Three smaller things from the same review. The design said a session with no role file is a local one, which reads as fixing the place, while the place is read from the cloud variable whether or not there is a role file; the sentence is corrected to say a session with no role file takes every role, and the place is its own reading. A home directory that is not set means there is no role file to read, so the session takes every role, and the design says that. The option naming a session and the option asking for every session are exclusive on `rules load`, so a role given with `--all` is refused instead of silently ignored.

## Tests

The smoke fixture gains a gated rule, and the table is asserted to count it in the scoped columns and not the loaded ones. Four tests of the admission test are strict subsets of the literal table that covers every cell and are deleted as redundant. One assertion in the corpus tests, that the admitted and withheld rules add up to all rules, cannot fail since the second is defined as the complement of the first, and is deleted with the test's name corrected to say what remains. The comment on the order of a named session's cards is made true by asserting the order.

## Left alone

Two commit subjects on the branch were flagged. One is written by the unlock command with parentheses and its template belongs to mockspace; the other names how the change came about. History is not rewritten for either: a forward commit cannot change a subject already pushed, and the landing is a merge that keeps them.
