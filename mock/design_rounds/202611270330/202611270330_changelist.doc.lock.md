## CHANGE: `homma hook run` FROM running nothing and passing at every event but `pre-push` TO installing, then handing the event to git-shook, failing closed where it cannot
File: `mock/crates/homma-core/DEEPDIVE_release.md.tmpl`
Verification: The "Hooks" section says the verb installs for the clone git ran the hook in, then hands the event to `<common git dir>/shook/hooks/<event>` with git's arguments and stdin and exits as that does, passing where git-shook has no dispatcher for the event. Where the install refuses it fails with the install's words and says the hook did not run. Landing step 3 and the surface row for `homma hook run` say the same.

## CHANGE: the parse of a manifest FROM two probes with no order TO the retired tables first, then the probe for unread entries
File: `mock/DESIGN.md.tmpl`
Verification: The section on entries an engine does not read says a retired table comes out before the probe: its lines are blanked, it is named in `retired`, and the probe reads what is left, so `[hooks]` is never an unread entry nor a misspelling of one.
