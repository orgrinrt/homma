# Src changelist: the generated paths stay ignored

## CHANGE: add mock/crates/homma/tests/generated_paths_are_ignored.rs

Adds an integration test asserting the repository's ignore configuration has
the effect it is there for.

It asks `git check-ignore`, not the text of `.gitignore`, so an entry written
any way that works passes and an entry that has stopped working fails however
it is spelled. Two arms:

- every path `mock` generates under `.claude/` and `.github/` is ignored.
- a file under `.github/workflows/` is **not** ignored. This is the arm that
  distinguishes the per-path list from a blanket, and without it the test
  certifies the weaker shape as readily as the stronger one. It plants the
  file, asks, and removes it.

The test skips rather than fails where `git` is absent or the tree is not a
work tree, since neither says anything about the property.

No source file changes. No public surface changes.
