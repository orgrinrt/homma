# Src changelist: move the racy test out of the shared process

## CHANGE: the merged-view test becomes its own integration binary

It sets `GIT_CONFIG_GLOBAL`, which `testing.rs` reads and every `git` child
inherits, in a binary running seventy-two tests concurrently. An integration test
is its own process, so the variable races with nothing and the `unsafe` block's
invariant becomes true rather than asserted.

The guard is load-bearing: it is the only thing catching `identity` reading git's
merged view instead of the clone's own configuration, so it moves rather than
going.

## CHANGE: the compile-time enumeration returns, beside the literal

The literal forces a new field to be given a value and the hostile-value check
forces that value to be hostile. Neither catches `None`, because
`skip_serializing_if` removes it from the serialised entry.

Naming every field closes it, and the `_` patterns go: a field can still be
classified wrongly on purpose, which is the bar, but no longer by omission.
