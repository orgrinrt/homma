# Topic: what the first Hand got wrong, and why the instruction was at fault

**Date:** 2026-08-14
**Phase:** TOPIC
**Scope:** two defects found by running a Hand rather than by reading the code
**Status:** settled

The first Hand was stood up and given a small real unit of work. It did the work
correctly and got two things wrong, and neither was the Hand's fault in any sense
that matters: nothing it had been given said otherwise.

## It did not know its own git identity

Asked what it commits as, it answered with the machine's global identity, which
belongs to the human. Every commit it had actually made carried the right author,
because the identity is set in that workspace's own git config, so nothing was
mis-attributed. What was wrong was the Hand's belief about itself.

The generated definition described who the Hand was and never said which git
identity was its. So when asked, the only identity it could see was the global
one, and it reported that.

**Fixed by generation:** the definition now states the identity's own name and
email and says plainly that the global one belongs to someone else.

## It committed to a trunk

Its first commit went to `main`. It had not pushed, so nothing was lost and the
commit moved onto a branch without incident.

The workspace forbids this everywhere and the standing instruction the definition
carries did not say so. It said where work happens and how to stage a commit and
not which branch may receive one.

**Fixed by generation:** the standing instruction now forbids committing to a
trunk and says to branch first.

## The general point, which is worth more than either fix

Both defects were in what the Hand was given rather than in what it did, and
neither was visible by reading the code. The tests all passed. The design was
satisfied. What found them was standing a Hand up and watching it work, which is
the only thing that could have.

That is an argument for the end-to-end run being the acceptance test for this
machinery rather than a demonstration after the fact, and for the next Hand's
standing instruction being reviewed by running it rather than by reading it.
