# src changelist

This changelist comes from `202611270329_topic.old-entrypoints-hand-on-and-the-parses-in-order.md`, the round's one topic, and carries out the locked doc changelist `202611270330_changelist.doc.lock.md`.

## CHANGE: `homma hook run` FROM passing having run nothing TO installing, handing the event to git-shook's dispatcher, and failing closed
File: `mock/crates/homma-engine/src/cmd/hook.rs`
Verification: `run_cmd` takes the config, finds the clone by `git rev-parse --show-toplevel`, reads the workspace's git hooks manifest and runs `hooks::install` there. It then runs `<common git dir>/shook/hooks/<event>` with git's arguments and its inherited stdin and exits as that does, passing where there is no dispatcher. A refusal of any of these prints `the <event> hook did not run:` with the reason, and the verb fails. The FIXME naming its removal stays. `cli.rs` documents it the same way.

## CHANGE: the tests of an old entrypoint FROM a pass that ran nothing TO a refusal where git-shook does not hold the path, and the hand-on where it does
File: `mock/crates/homma-engine/tests/hook_smoke.rs`
Verification: `an_older_entrypoint_where_git_shook_does_not_hold_the_path_fails_closed_and_runs_nothing` covers `pre-commit` and `pre-push`. With `GIT_SHOOK`, `an_older_entrypoint_installs_and_hands_the_event_to_git_shook` runs the workspace's check on the staged file and the gate with git's arguments and stdin, and `a_gate_that_refuses_refuses_the_push_after_the_hand_on` is its control. The retired table in the tests plants an invented program, `lintwhistle`, here and in `homma-core/src/config/retired_tests.rs`.

## CHANGE: `Config::parse` FROM two wraps in conflict TO the retired tables out first, then the probe for unread entries
File: `mock/crates/homma-core/src/config/retired.rs`
Verification: `parse` returns a strict parse that passes. Otherwise, where no retired table is present it hands the text to `unread::parse`; where one is, it blanks the table's lines with `unread::blank::blank`, hands that text to `unread::parse` and sets `retired`. `config.rs` calls `retired::parse` alone, and `unread::blank` is visible to the config module. Tests in `retired_tests.rs`: a retired table beside an unread entry names both, `hooks` never among the unread, and a refusal after a retired table keeps its line.
