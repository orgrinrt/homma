# SRC changelist: the precondition has no type

**Round:** the AbsPath round
**Phase:** IMPL

## CHANGE: mock/crates/homma-api/src/path.rs (new)

`AbsPath`, a path that cannot be relative. Built from an already-absolute path,
or by resolving one against a base, which is where the caller's intention lives
and what leaving it implicit cost.

## CHANGE: mock/crates/homma-api/src/git.rs

Every method takes `&AbsPath`. The precondition stops being a comment, then a
runtime check in one implementation out of seven, and becomes the signature.

## CHANGE: mock/crates/homma-api/tests/compile_fail/

A `trybuild` case asserting a relative path cannot reach the contract, with its
diagnostic recorded. Loosening any method back to `&Path` makes it compile and
the test fails. `harness-the-type-system.md`: a refusal nothing pins can be
deleted by accident.

## CHANGE: mock/crates/homma/src/cmd/stand.rs

**The defect.** `id.workspace` was used raw as a clone target, so a registry
saying `workspace = "hands/rel"` cloned into whatever directory the process was
in. It is now resolved against the workspace root, which is what a relative entry
always meant.

## CHANGE: mock/crates/homma-core/src/repo/git_impl.rs, homma-org/src/{workspace,provision,generate}.rs

Carry the type through. `enclosing_repo` drops its runtime refusal, which the
type now makes unreachable, and its walk terminates at the filesystem root.

## CHANGE: mock/crates/homma-core/src/testing.rs (new)

One `global_config_paths`. It existed in two crates, was fixed in one, and the
round that fixed it added a third; `cfg(test)` does not cross a crate boundary,
which is why copying looked like the only option.

## CHANGE: mock/crates/homma-org/src/remote.rs

Three more comparison defects, two failing open: `.git` stripped before a local
path is resolved, so a bare repository and the working tree beside it were one;
an IPv6 literal split on its first colon, so every address compared equal; and
the name not folded while the owner was, which refused a correct workspace.

## CHANGE: mock/crates/homma/tests/

`support` re-exports rather than redefining. A test for the relative-workspace
route, which no integration test could have caught because every one passed an
absolute path.
