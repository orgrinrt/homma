# what-a-review-of-the-test-fixtures-round-found

Extends round 202611251422-cqgk. A review of it found its decisions held narrower than they were
written, and two of its tests unable to fail where they claimed to.

## The scope of the invented names

That round's grep covered the tests of `cmd::what` and `cmd::ask`, and those are clean. Its
sentence about "the crate's tests" claimed more: other test modules of `homma-engine`, and live code,
still carry the names of the tree homma is developed in. Decision: this round states the scope as
the tests of `what` and `ask`; the rest of the class is a separate body of work, filed on its own.

## One way to plant a script a test runs

The decision that a test writes a script it will run from a child process was carried out for one
helper only. Every test of the binary forks, so a script written in the test process anywhere in it
can make a run elsewhere busy. Decision: one helper, `cmd::planted::script`, writes a script through
`sh` with its mode; every helper of the binary's tests that writes a script it then runs calls it.

## The cache question is checked without the caller's environment

The test of the root's git directory could fail only when the shell running the suite exported
`GIT_DIR`. Decision: the command that asks git is built by one function, and a test reads its
environment and finds both variables removed, whatever the caller's.

## A write in flight, and a write left behind

The sweep test's dot file was old, so the earlier sweep removed it for its age and never reached
the cap: nothing checked that a dot file is not counted. And an ask killed mid-write leaves its dot
file, which a sweep that never removes one keeps forever. Decision: a dot file is never counted
toward the cap, and is removed only once it is older than the expiry, long past any write in
flight. A test plants a fresh large dot file and an old one: the fresh one stays and does not push
an entry out, the old one goes.

## Small notes

A doc link the split turned into plain text is a link again, and the prefix test pins its stated
boundary with a four-letter case.
