# Src changelist: what a stranger cannot reach

## crates/homma-engine/src/cmd/util.rs

CHANGE: add `no_such_member`, the one error for a repository name that names no
member. It reports the workspace root it looked under and the members it found,
because membership is detected and the operator has no table to be told to fix.

## crates/homma-engine/src/cmd/repo.rs

CHANGE: `run` answers an unknown name through `no_such_member` instead of
telling the operator to declare it in a table the manifest refuses.

## crates/homma-engine/src/cmd/agent.rs

CHANGE: the two sites that answered an unknown name with the same sentence now
go through `no_such_member`. The `out.is_empty()` guard also stops calling
`unwrap` on the option it has just tested.

## crates/homma-engine/src/cmd/docs.rs

CHANGE: as above, one site.

## crates/homma-engine/src/cli.rs

CHANGE: seven argument doc comments say where a defaulted value comes from. The
answer is the clone's origin remote, not a table. These strings are printed by
`--help`.

## crates/homma-engine/src/cmd/archive.rs, cmd/migrate.rs, cmd/aggregate.rs

CHANGE: the same correction in three module and field doc comments.

## crates/homma-core/Cargo.toml

CHANGE: the two dependencies on another repository move from a branch to a
revision. A branch means the engine built from one pin is not the engine built
from the same pin a day later, and the build cache is keyed on this repository's
revision alone, so nothing notices.
