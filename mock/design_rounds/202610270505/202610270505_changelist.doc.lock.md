# doc changelist

Answers `202610270505_topic.what-the-surface-lines-ask-of-a-repo.md`.

## Current state

The status section says the agent surfaces are covered and says nothing of what a repository owes under them, so the check grew four demands the workspace rules do not make: a `.cargo` alias that the launcher retired, a `mock/agent/` directory that mockspace's builtin rules make optional, a literal `mock/` where the repository declares its own, and every surface of a repository that has no mockspace. The configs section reports a difference and gives no way out of it.

## Changes proposed

- One paragraph added after the "Covered:" paragraph in "What a status answers", stating what the agent surfaces ask of an adopted repository and that a repository without a `mockspace.toml` is not asked anything.
- One sentence added to the second paragraph of "Absence is acted on, difference never is", saying the reported line names the two ways out of a difference.

The three loose topics from earlier rounds stay open, and are not consumed here:

- `202610221816_topic.capture-answers-left-on-a-page.md`: the capture page, not the status.
- `202610221816_topic.what-a-stranger-cannot-reach.md`: what an outside reader reaches, not the status.

## CHANGE: section `What a status answers` FROM the paragraph ending "and nothing offline is left out for cost. Nothing here reaches the network, which is what makes it the command to run first." TO the same paragraph followed by a new one on what the agent surfaces ask

File: `mock/DESIGN.md.tmpl`

The existing paragraph stays as written. A paragraph follows it: "What the agent surfaces ask of a repository depends on whether it has adopted mockspace, which is whether it carries a `mockspace.toml`, at its root or under its mock directory. One that has not is not short of anything and is named as having no mockspace under `--full` and nowhere else. One that has is asked for its mock directory, as its `mockspace.toml` declares it with `mock` as the default, for the rendered `.claude/` and `.github/instructions/`, and for the wiring that makes its git hooks fire. It is not asked for a `mock/agent/` directory, because the builtin rules ship inside mockspace and that directory holds only what the repository adds, and it is not asked for a `cargo mock` alias, because the launcher answers that command from where it is installed. A line about a missing surface names `homma agent regen`, which renders them."
