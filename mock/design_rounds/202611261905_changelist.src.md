## CHANGE: the api FROM no way to list a type's keys TO `keys_of` and `Keys`
File: `mock/crates/homma-api/src/keys.rs` (new), `mock/crates/homma-api/src/lib.rs`, `mock/crates/homma-api/tests/keys.rs` (new)
Verification: `keys_of::<T>()` deserialises `T` from a probe that records each struct field serde names and descends into it, a map's keys as `*`, an array's elements under its name, an option by what it holds, and an enum by its first variant; a value read as any value is a key in `Keys::opaque` and is not descended into. A type whose own check refuses what the probe offered at a key is probed again with that key empty (no map entry, no array element, an option of none), keeping the keys the first pass found; a type that refuses even that refuses the probe. `Keys::graft` puts a type's keys under a key, or at the root, and drops an opaque key once a key lies under it or the grafted type reads it plainly. Tests: the keys of a type with every shape, the opaque ones apart, three grafts, a checked table probed twice (failing control: with the second pass off it fails), a type refusing every value refusing the probe, and a manifest of the listed keys parsing.

## CHANGE: the core FROM `READS`, a hand-kept list TO `config::keys`, derived from both parsers' types
File: `mock/crates/homma-core/src/config.rs`, `mock/crates/homma-core/src/config/keys.rs` (new), `mock/crates/homma-core/src/config/keys_tests.rs` (new), `mock/crates/homma-core/src/config/tests.rs`
Verification: `READS` and its test are gone. `keys()` is the probe of `Config`, grafted at the root with `Workspace` and under `search`, `summary` and `ask` with the api's tables. Tests: keys of both parsers are listed and no raw table whole; the opaque keys are exactly `deny` and `status.inject.tool`, each a value of two spellings (failing control: with the `search` graft taken out, `search` is opaque and `search.members` unlisted); the two keys of the live-defaults rollout parse and an unknown key under their table is refused.
