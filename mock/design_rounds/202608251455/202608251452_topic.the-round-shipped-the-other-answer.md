# The round shipped the other answer in three places

The membership round reasoned its way to an answer, wrote the reasoning into
its changelists, and then shipped something else in the three places a reader
looks: the rendered design document, the readme, and the code that reads a
remote.

## The design document is a render behind

`mock/DESIGN.md.tmpl` carries the membership paragraph. `docs/DESIGN.md` does
not, because the render did not run after the template landed. A reader of the
generated document is told nothing about how a member is found, and the
document says at the top that it is generated, so they have no reason to open
the template instead.

## The readme says the wrong root

It says a member is a directory beside the manifest. The code walks
`workspace.path`, which is the same directory only when the path is left at
its default. It also says nothing about a worktree, which carries a `.git`
file rather than a directory and is therefore not a second member; that is a
real property of the detection and a reader has no way to know it.

## The origin is read through a subprocess

The src changelist says the git trait supplies the URL and already does. The
code forks `git` once per directory under the root, on every configuration
load. Two costs, and the second is the one that matters: a machine with no
`git` on its path answers nothing for every member at once, which reads as a
workspace of clones that live nowhere rather than as a missing tool.

`GixGit` implements `origin_url` over gix in the same crate and is exported.
Threading it in makes the failure a fact about one repository rather than
about the environment.

## Three smaller things found with them

A warning fires for a forge profile nothing references, in a function whose
own comment twenty lines above says that is not a gap and that warning about
it would be noise. It contradicts itself and it fires permanently on a real
workspace.

Two accessors on the member type take the defaults and hand back a field of
them, ignoring the receiver entirely. A test asserts they do. Nothing about
either can fail, and the thing worth pinning is that a member line in the
status report carries the workspace default, which is a claim about code that
does something.

A closure in the remote reader re-derives a borrow it already holds, defended
by a comment about borrowing that is not true. Naming the first borrow is what
was meant.
