# Topic: the readme describes a repository that no longer exists

**Date:** 2026-08-14
**Phase:** TOPIC
**Scope:** the one public surface a stranger reads
**Status:** settled

The readme says homma is pre-implementation and lists what will land: a config
schema, git operations over `gix`, a forge trait, two forge clients, a CLI
parser, a migrate command, built-in lints. Every one of those shipped, and three
more crates landed since.

Worse for a stranger: the workspace moved under `mock/` and the readme never
says so, so `cargo build` at the repository root now fails with no explanation
anywhere they would look.

A stale status section is the cheapest kind of wrong and the most visible. Fixed
here rather than filed, because it is one paragraph and the review that found it
was right to call it blocking.

Also fixed: the one em-dash in `mockspace.toml`, against a rule with no
tolerance. Eight more sit in locked changelist headings and are not editable; the
recurrence stops here.
