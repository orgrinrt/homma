# Doc changelist: a declared feature set replaces all-features

**Date:** 2026-09-03
**Phase:** DOC
**Source topics:** `202609030755_topic.a-declared-feature-set-replaces-all-features.md`

## Current state

The table in `homma-core/DEEPDIVE_release.md.tmpl` gives lint as `cargo clippy --all-targets --all-features`, tests as `cargo test --all-features` then once per declared set, and docs as rustdoc coverage on nightly, and the paragraph under it says the sets are what a crate wants tested beyond `--all-features`.

## Changes proposed

### `homma-core/DEEPDIVE_release.md.tmpl` (modify)

The table's lint, tests and docs rows say each runs with all features where the crate declares no sets and once per set where it does. The paragraph on feature sets says a declared set is the whole of what the gate builds for that crate, that `--all-features` is never run for it, that a workspace's all-features runs exclude the declaring members, and that the docs number is the first set's.
