# Source changelist: what the fifth review found on the release

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609030005_changelist.doc.lock.md`

## `homma-core`

### `src/release/check.rs`, `check_tests.rs` (modify)

CHANGE: `reg.unpublished` is `Error` where the tag is the newest versioned one and `Warn` otherwise; `both.sameset` is `Error`. The other four ids stay `Warn` as the catalogue has them. The sort at the end uses `sort_by_key`. A test plants a newest tag with no published version and an older one, and asserts the severities differ; another plants differing jsr and npm sets and asserts the finding blocks.

### `src/release/plan.rs` (modify)

CHANGE: `plan` computes `next` as the last tag's version bumped at `level`; a manifest already at `next` is the release, a manifest at the last tag's version bumps, and any other manifest version returns a new `PlanError::OffLevel` naming the manifest version and the one the level makes. The test pinning the old behaviour asserts the refusal instead, and a test asserts a manifest already at the level's version is taken as is.

### `src/release/publish_tests.rs` (modify)

CHANGE: the `seen` field's type gets a `type` alias and the constant `format!` becomes a string literal, which are the two clippy findings the gate's own command raises there.

## `homma-engine`
