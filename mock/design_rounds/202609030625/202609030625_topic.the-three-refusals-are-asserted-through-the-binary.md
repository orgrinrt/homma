# The three refusals are asserted through the binary

**Date:** 2026-09-03
**Phase:** TOPIC
**Scope:** `homma-engine/src/cmd/release/mod.rs`, `homma-engine/tests/cli_release.rs`
**Source topics:** the third review of pull request 49, and `202609030610/202609030610_topic.every-hook-refusal-is-reported-not-thrown.md`

## The findings

The design says each refusal is a line and a non-zero exit, and no test drove the binary through any of the three; the core tests cover the variants and the engine's reporting of them rested on an unexercised arm. A smoke test plants each case and asserts the exit and the line. The remaining error arm matched everything else, so a fourth refusal added later would abort a sweep in silence; the git and io errors are named so a new variant is a compile error.

## What does not change

The refusals and the design.
