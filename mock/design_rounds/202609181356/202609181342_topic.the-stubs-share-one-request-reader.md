# the-stubs-share-one-request-reader

## What the review of the last round found

Two things, both on this branch and neither merged yet.

**Round `202609181236` closed on an empty source changelist.** Its
`202609181237_changelist.src.lock.md` holds the heading and nothing else. The
changelist's text was written into a second file,
`202609181236_changelist.src.md`, which was never locked, and the lock sealed
the empty one opened beside it. A locked changelist is not edited and a pushed
commit is not amended, so the repair is forward: this round's source changelist
carries the claims that one should have carried, verified again, and says the
unlocked draft in the closed round is the text they came from.

**The reader the fix added is now four copies.** Each stub in
`github_wire_tests.rs` and `forgejo_wire_tests.rs` parses the request line, the
headers and `Content-Length`, then drains the body, and the flake the last round
fixed was one copy that lacked the drain. A fifth stub, `renamed_private_repo`,
still does not drain, which is safe only while every request it serves is a
`GET`. Fixing one stub at a time leaves the next one written by copying to
repeat it.

## The call

One reader, in a test-only module beside the two wire test files, that reads a
whole request off a socket: the request line, the headers, and exactly
`Content-Length` bytes of body. Every stub calls it, `renamed_private_repo`
included, so no stub can answer before the request is off the wire and a new
stub gets the drain by calling the one function there is.

It has tests of its own, since it is now the thing the create tests stand on: a
request with a body, one without, a header spelled in another case, and a body
arriving in several writes.

## What stays open, and where it goes

A closed round holding an unlocked changelist, or a locked changelist with
nothing under its heading, is checkable, and nothing in the gate checked it.
That is a lint in the shared pack rather than a line here, filed as its own
work so it reaches every repository that runs rounds.
