# Src changelist: delete a test that cannot fail, pin what does not run

## CHANGE: `set_identity` takes a `CommitIdentity`

It took four consecutive `&str`, so any permutation of them compiled, and the
naming was already inconsistent between the two pairs. The read side already
returns the type; passing it both ways is symmetrical, removes the positional
hazard, and removes the two `type_complexity` warnings the five-tuple fakes
carried, because the doubles store the type instead.

## CHANGE: the control-character test stops comparing a function to itself

Both sides of its equality came from the same walker on the same value, so it
could not fail: deleting the array arm entirely left it green, and so did
excluding a named field.

The derived walk in `unsafe_strings` stays, because that part is real. What
replaces the assertion is a literal list of the eleven paths, checked in both
directions: every corrupted field is reported, and the entry's serialised strings
are exactly those eleven, enumerated by test-local code rather than by the
production walker. A field added later then fails loudly instead of being
absorbed.

## CHANGE: three live mechanisms get the tests they lacked

`Identity::committer_name` reached nothing: ignoring the registry field left the
suite green, which is the unread-plumbing shape U-3.1 exists to prevent.

`user.name` and `user.email` are written deliberately and deleting both failed
nothing.

## CHANGE: the read-back's empty filter is restored

Widening it silently dropped `.filter(|s| !s.is_empty())`, so a clone with empty
configured values returned four empty strings where it returned `None`, against a
trait doc that still says "if any".

## CHANGE: two comments

The summary line on `identity`, which the previous round's fix to `set_identity`
left describing a return type the method no longer has. And the rationale for
reading the local config rather than the merged view, deleted with the old body:
a merged read reports the machine's global identity as though it were the
repository's, which is the confusion the method exists to prevent.
