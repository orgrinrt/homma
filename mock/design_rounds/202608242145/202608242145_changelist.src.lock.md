**Date:** 2026-08-24

## CHANGE: `homma/src/cmd/aggregate.rs`, absolute is retired, not unvisited

RENAME `is_legacy_aggregated_command` to `is_retired_aggregated_command`, and
widen it: a managed command naming an absolute path joins the bash aggregator's
`imports/<repo>/` form as a shape nothing writes and no clone can use.

ADD test `an_absolute_managed_command_is_retired_whatever_repo_it_names`.

ADD test `a_placeholder_command_for_an_unvisited_repo_is_not_retired`: the
control that keeps the preservation rule alive, since a predicate that swept
both would pass the test above and undo the previous round.

ADD test `an_unmanaged_absolute_command_is_left_alone`: the second control. A
hand-authored user-level hook is absolute too, and sweeping it would be the
worst outcome available.

MODIFY test `merge_settings_keeps_entries_for_a_known_repo_this_run_did_not_visit`:
its preserved fixture already uses the placeholder form, and it gains an
absolute entry for the same unvisited repo that must not survive.
