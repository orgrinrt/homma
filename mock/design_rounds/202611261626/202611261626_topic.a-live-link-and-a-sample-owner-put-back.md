# a-live-link-and-a-sample-owner-put-back

Follows the closed round 202611261602, which replaced the names of a real tree in the tests.

## The install link of git-shook

The rename reached the message `hooks::shook` gives when git-shook is not installed, outside the
module's tests, and sent the reader to an owner that does not exist. git-shook is a real tool and
the link is where it is installed from. Decision: the link is put back as it was; the round
changes no other live text.

## The owner of the sample address

The agent lookup's sample in the design names its address's owner by a handle the fixtures do not
use: the fixtures plant the address under the handle `abe`. Decision: the sample names Abe, the
handle the tests plant.

## Planted hooks the code under test writes

`answers::hook::place` writes the hook it places in process, and its test then runs that file. The
write is the command's own, not a test helper's, so the round of planted scripts did not reach it.
Decision: none here; it is left for the round that moves the other in-process writers, since a
command writing a file it hands on to be run is a question of the command, not of a test.
