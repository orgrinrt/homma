# src changelist

Answers the topic filed in this round, `homma-what-finds-the-tool-that-does-a-thing`, and builds the section "Finding a tool" of `mock/DESIGN.md.tmpl`.

## Changes

- `crates/homma-engine/src/cli.rs`: the `what` command, with `--limit`, `--kind` and `--no-mock`.
- `crates/homma-engine/src/cmd/mod.rs`: the dispatch to it.
- `crates/homma-engine/src/cmd/what/`: the command. `text.rs` reduces words to stems and holds the filler list, the synonym groups and the edit distance. `rank.rs` scores the things read against a query and picks the related ones. `doc.rs` is what a source hands over. `sources/` reads each place: `tools.rs` (unix only), `scripts.rs` (the header block of an executable), `verbs.rs` (clap's own description of the command line), `mock.rs` (the listing `cargo mock tools` prints), `skills.rs` and `rules.rs` over the corpora homma already loads. `mod.rs` runs it and renders the answer.
- Tests beside each: the matcher on small word lists, each source on its own text, the parser of the mockspace listing on a verbatim sample of it, and the acceptance set in `what/accept_tests.rs`, which runs the queries against the workspace's real tools, scripts, skills and rules. The query that must return nothing is shown failing first: the test was written to expect an answer and run red against the matcher before the coverage rule went in.
- `README.md`: unchanged by this changelist, the row was part of the doc changelist.
