## Comparison to deprecated changelist

The deprecated source changelist (`202610271057_changelist.src.deprecated.md`) carried the command, its sources and the first round of review fixes. A second review found more, and this changelist is what changed from it:

- `sources/scripts.rs`: a script is runnable when it is executable or opens with a shebang, so libraries are left out, and so are tests (`_test`, `_fixture`, a `test_` prefix, a `test` runner, `tests` and `test` directories). `src` and `lib` count only for an executable. The command carries its interpreter, so `watch/index.py` answers as `python3 .shared/scripts/watch/index.py`. A scripts directory that is itself a link is a footer gap.
- `sources/mock.rs`: the time limit covers the reads as well as the wait, the listings answer over a channel, and an overrunning one has its whole process group ended. A workspace with no mockspace repository says so in the footer.
- `mod.rs`: the footer also reports a local config that cannot be read and a source left out by `--no-mock` or the kind filter.
- `text.rs`: the grades are no longer ordered by derive, the worth carries the order.
- Tests: the acceptance set runs with every source and gains `has op answered this before`, `what did op already answer` and `query the data with sql`. Three of the coordinator's added queries (`what did op say about storage`, `op's voice corpus`, `which canon rows carry a word`) are not answered well yet and are kept as ignored catalogue cases naming what should come first. The footer count for scripts without a header is planted with a bare executable, a bare shebang script, a test and a text file.
