# doc changelist

Answers the topic filed in this round, `homma-what-finds-the-tool-that-does-a-thing`, and replaces the doc changelist deprecated beside it.

## Comparison to deprecated changelist

The deprecated changelist (`202610271026_changelist.doc.deprecated.md`) named one section, "Finding a tool", and the README row. The section as first locked described six places a word is looked for, the related things as those sharing a tag, and a score without a weight for the kind of a thing. The matcher built against it needed more, and a review of it found more still, so the section is amended and this changelist records the amendments. The README row is unchanged.

## Changes proposed

- `mock/DESIGN.md.tmpl`, "Finding a tool", the matching: seven places a word is looked for, with the rest of a script's header the seventh; a rule's name counted as its summary; the weight of a kind (a skill four fifths, a rule three fifths); the score scaled by a factor between a half and one that grows with the share of the query's weight a thing matched; no word in two synonym groups once stemmed; a swap forgiven in a short word.
- The same section, the related things: chosen by the cosine of the weighted words of two things, at least 0.125, tools beside tools and advice beside advice, in place of a shared tag.
- The same section, the sources: a script is a file that is executable or carries a script extension, and a symbolic link is not followed; the mockspace listings run side by side with both pipes drained and the whole process group ended when one overruns, and are given up on after a minute; a skill's command is `/<name>`; `--limit` is never below one.
- The footer counts every script with no header, including the ones that are not executable, so the gap is visible where the tree has one.
