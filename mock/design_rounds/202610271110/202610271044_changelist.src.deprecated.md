# src changelist

Answers the topic filed in this round, `homma-what-finds-the-tool-that-does-a-thing`, and builds the section "Finding a tool" of `mock/DESIGN.md.tmpl`.

## Changes

- `crates/homma-engine/src/cli.rs`: the `what` command, with `--limit`, `--kind` and `--no-mock`.
- `crates/homma-engine/src/cmd/mod.rs`: the dispatch to it.
- `crates/homma-engine/src/cmd/what/`: the command. `text.rs` reduces words to stems and holds the filler list, the synonym groups, the grades of a match and the edit distance. `rank.rs` scores the things read against a query and picks the related ones. `doc.rs` is what a source hands over, with the kind weights. `mod.rs` runs it and renders the answer.
- `crates/homma-engine/src/cmd/what/sources/`: `tools.rs` (unix only), `scripts.rs` (the header block of an executable), `verbs.rs` (clap's own description of the command line), `mock.rs` (the listing `cargo mock tools` prints, a repository at a time, a minute at most), `corpora.rs` (the skills and rules homma already loads).
- Tests beside each. `text_tests.rs` and `rank_tests.rs` hold the matcher on small word lists. `sources_tests.rs` holds each source on its own text and on the real tree, and the mockspace parser on a verbatim sample of the listing. `accept_tests.rs` is the acceptance set: the queries a helper or the coordinator types, each with the real tool that must come first, run against the workspace the repository sits in and refused where there is none. The query that must return nothing was shown red with the coverage rule taken out (`required` answering 1), where `translate this document into french` answered with five things that mention a document, and green with the rule back. `tests/what_smoke.rs` runs the binary: the exit status, the filler, the json and `--kind`.

The suite for the area is green: `cargo test -p homma-engine --bin homma-engine what::` and the smoke test, with the readme test.

The doc changelist of this round was unlocked once, after the matcher ran against the real tree, and locked again unchanged in its name (a locked changelist is frozen, so the committed one stands as first locked). What the design section gained in that reopening: the seventh place a word is looked for (the rest of a script's header), the weight of a kind (a skill four fifths, a rule three fifths), the scaling by the share of the query's weight a thing matched, related things chosen by the closeness of their words, a swap forgiven in a short word, a rule's name counted as its summary, the four directories of scripts not read, and a mockspace listing given up on after a minute. The code follows the section as it now reads.
