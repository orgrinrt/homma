# Src changelist: refuse a root whose parent is missing, pin two live guards

## CHANGE: `Root::new` refuses a root whose own parent does not exist

`create_dir_all` on a path under a missing root creates every missing ancestor,
and the root's ancestors are above the root, so containment says nothing about
them. With a root under a home directory this created directories inside
`~/.claude/`, which the record forbids as deny item three.

The rule the refusal enforces: **homma creates the root, never the path to it.**
Creating the root is intended, and `content_repo = "local"` relies on it. Making
the road to it is not, and nothing asked for it.

## CHANGE: two live guards get the tests they never had

Both were found by deleting them and watching nothing fail, which is the only
method that has produced a right answer about this crate.

**The re-prove after `create_dir_all`.** Replacing the tail with `Ok(())` left
339 green, in the file whose own header sells that guard as turning a silent
escape into a loud one. Pinned by proving a path, then planting a symlink on it,
then creating.

**The definition-parent containment check.** Deleting it left 339 green. It sits
twenty lines below the guard the previous round pinned, in the round named for
pinning it.

carried forward.
