## CHANGE: `homma hook install` with no repository FROM refused for want of one TO a sweep of every member, silent where all are current
File: `mock/crates/homma-core/DEEPDIVE_release.md.tmpl`
Verification: The "Hooks" section says the sweep asks `git shook doctor --only homma`, with the workspace's name too. It also says the sweep checks the manifests in place byte for byte and checks for leftovers. It then says, for each member:
- a current one gets nothing written or printed;
- any other one is installed, with one line said;
- a refusal is said and the sweep goes on;
- the exit is non-zero for a refusal.

The section says a sweep with every member current prints nothing, and names the five things a sweep puts back. The surface row for `homma hook install [<repo>]` says the same.
