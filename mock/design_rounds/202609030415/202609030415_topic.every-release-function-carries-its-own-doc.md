**Date:** 2026-09-03
**Phase:** TOPIC
**Scope:** `homma-core/src/release/check.rs`, `homma-engine/src/cmd/release/mod.rs`
**Source topics:** the eleventh review of pull request 46, and `202609030405/202609030405_topic.the-release-errors-fit-the-gate-it-runs.md`

## The findings

The summary line of `is_adjacent` sits on `names_hotpatch`, which was inserted between the comment and its function, so one carries two summaries and the other none. The previous round fixed two instances of the same shape and did not grep for the class; this one did, over every public function in the release code, and found that one plus the engine's `run` entry, which has no doc at all. Both get theirs.

Four other findings of that pass are not taken here. Three are design silences and go to the lead designer through the workspace agenda: how a repo leaves `0.x`, since no level makes `1.0.0` while the gaps check accepts it; what running deno tests with the permissions `deno.json` declares means, since the code runs a `test` task or bare `deno test`; and rustdoc coverage on nightly where the ambient toolchain is stable. The fourth, `cli.rs` past the file-size line, predates the branch and is filed for a split of its own.
