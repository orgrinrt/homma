# src changelist

This changelist comes from `202611270540_topic.what-an-install-copies-where-a-seat-names-no-git-hooks-file.md`, the round's one topic, and carries out the locked doc changelist `202611270540_changelist.doc.lock.md`. The behaviour the design now states was already the source's; this changelist adds the tests that fail when it stops holding. The precondition on when a new manifest first runs is already tested by `an_older_chain_entry_installs_and_runs_the_gate_and_hands_nothing_on`.

## CHANGE: the install where the named file is not there FROM untested TO tested as leaving another manifest as it was
File: `mock/crates/homma-core/src/hooks/shook/tests.rs`
Verification: `a_workspace_with_no_manifest_leaves_another_manifest_in_the_member_as_it_was` installs with no workspace manifest into a member already holding a `prose` manifest: only the gate is registered, the manifests directory holds `homma.toml` and `prose.toml`, and `prose.toml` keeps its bytes. An install that takes out every other manifest fails it.

## CHANGE: where `git_hooks` is read FROM untested TO tested as the manifest's alone
File: `mock/crates/homma-core/src/local_tests.rs`
Verification: `a_paths_table_is_refused` parses a `homma.local.toml` carrying `[paths]` and gets an error. Dropping `deny_unknown_fields` from `Local` fails it.

## CHANGE: a clone's own file naming another git hooks file FROM untested TO tested as changing nothing
File: `mock/crates/homma-engine/tests/hook_smoke.rs`
Verification: `a_clones_own_file_does_not_change_where_the_git_hooks_are_declared` writes a root `shook.toml` named `prose` and a `homma.local.toml` setting `git_hooks` to a file that is not there; `homma hook doctor` still says the hooks are registered as `prose` and never names the other file. Reading `git_hooks` from the local file fails it.
