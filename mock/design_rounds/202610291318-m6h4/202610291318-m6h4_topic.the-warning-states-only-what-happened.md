# the-warning-states-only-what-happened

The pass-over warning said a message written twice across the cut "is taken again" on every run while the file stays cut, though a later run with a mark takes nothing again. The design now says the run counts the captures it passed over and that a message written twice across the cut may have been taken again, and the run's words say the same. The review's other findings are in the source and tests: `watermark` is used only by tests and goes, the end-to-end cut test asserts that the capture is written, and one assertion that could not fail goes.
