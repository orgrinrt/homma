# SRC changelist: the guard nothing tested

**Round:** the guard round
**Phase:** IMPL

## CHANGE: mock/crates/homma-org/src/remote.rs (new)

`same_repo` compares host, owner and name rather than the last path segment. A
local path is resolved and compared as a path.

Moved out of `provision.rs` because it is a pure function over strings with its
own table of cases, and `provision` is filesystem work.

## CHANGE: mock/crates/homma-org/src/provision.rs

Tests that construct `ProvisionError::WrongRemote`. Deleting the whole remote
check currently leaves the suite green, which is the defect this round is named
for.

The fake gains a per-path remote, since one that answers the same URL for every
path cannot enter the refusing arm.

## CHANGE: mock/crates/homma-api/src/git.rs, homma-core/src/repo/git_impl.rs

`enclosing_repo`, so `local` can refuse a directory inside another repository's
working tree instead of initialising a nested one there.

## CHANGE: mock/crates/homma/src/cmd/stand.rs

Resolve a symlinked registry before writing, so the write reaches the file the
link points at rather than replacing the link.

Refuse a `local` root that sits inside another repository.

## CHANGE: mock/crates/homma-core/src/repo/git_impl.rs

The global-config assertion requires that at least one candidate path **exists**,
not merely that the list is non-empty. `/etc/gitconfig` was pushed
unconditionally, so the list could never be empty and the test compared `[None]`
to `[None]`.

## CHANGE: mock/crates/homma-api/src/config.rs

Repair two comments a blind global replace corrupted, one of which is the comment
explaining the rename it was part of.

Silence the `type_complexity` warning the previous round introduced.

## CHANGE: mock/crates/homma/tests/cli_smoke.rs

Split. It crossed the file-size limit inside the previous round.

Tests for the symlinked registry and the nested-repository refusal.
