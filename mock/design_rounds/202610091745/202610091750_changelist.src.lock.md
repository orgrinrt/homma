## CHANGE: `capture::cut::ending` FROM any object with a non-parsing prefix TO a cut write only
File: `mock/crates/homma-engine/src/cmd/capture/cut.rs`
Returns nothing unless the line begins with `{`. Each `{` after the first byte is
tried with `serde::de::IgnoredAny`, which checks the syntax and builds nothing;
the first from which the rest of the line is one object is the candidate. The
bytes before it are then parsed the same way, and the object is taken only when
that fails with `Error::is_eof()`: the input ended with an object still open. A
prefix that parses, or fails for any other reason, returns nothing. Only the
chosen object is parsed into a `Value`.
Verification: `a_line_that_is_not_a_cut_write_is_refused_by_number` under
`src/cmd/capture/tests/cut.rs`, with the cases three whole lines run together,
a whole line then a cut write then a whole line, a cut write then two whole
lines, a whole line then text then a whole line, text before the object that is
not an object's start, and an object's start the parser refuses before it ends;
`every_recovered_line_is_reported_by_number_and_bytes`, whose one byte case is
now `{` before the object; and the tests that stay as they were.

## CHANGE: module `capture::ask` FROM absent TO present
File: `mock/crates/homma-engine/src/cmd/capture/ask.rs`
Takes `ASK` and the two helpers that find ask calls out of `transcript.rs`, which
is near the size limit, and adds what the design now says. `Calls` holds every
call the agent made, by the id its result names, and the subset that are asks.
`Calls::answering` classifies a user line's tool results as answering an ask
call, answering some other call, or answering a call no earlier line holds.
`shaped` is a `toolUseResult` carrying `questions` or `answers`. `Unasked` is a
line number and whether it was read, and prints as the note on stderr.
Verification: the tests under `src/cmd/capture/tests/unasked.rs`.

## CHANGE: `capture::transcript::read` FROM skipping a result whose call is unknown TO reading it by its shape
File: `mock/crates/homma-engine/src/cmd/capture/transcript.rs`
Every assistant line's calls are noted, not only the asks. A result naming an ask
call is read as before, strictly. A result naming another tool's call is not read.
A result naming a call no line holds, with a `toolUseResult` that is an object
carrying `questions` or `answers`, is read as a round when `round` accepts it,
and then lands in `Transcript::unasked` as read when it holds an answer or a note;
when `round` refuses it, nothing is read, no error is raised, and it lands there
as not read. Anything else passes as before.
Verification: `an_answer_whose_question_was_in_a_cut_write_is_read_by_its_shape`,
`an_unknown_call_is_said_on_the_note_whichever_way_it_went`,
`an_answer_that_cannot_be_read_is_said_not_refused`,
`a_result_of_an_unknown_call_that_is_not_a_round_passes_without_a_word` under
`src/cmd/capture/tests/unasked.rs`, and the changed assertions of
`a_result_answering_another_tools_call_is_never_a_round` in
`src/cmd/capture/tests/answers.rs`.

## CHANGE: `capture::run` FROM one note per recovered line TO that and one per unasked result
File: `mock/crates/homma-engine/src/cmd/capture/mod.rs`
The notes go to stderr in the same place, before anything is written.
Verification: `an_answer_without_its_question_is_said_on_stderr` in
`mock/crates/homma-engine/tests/capture_smoke.rs`, over the binary.

## NO CHANGE: `capture::typed`
File: `mock/crates/homma-engine/src/cmd/capture/typed.rs`
Still refuses a line that does not parse; its pin test stays.

## Verified

Red first. With only the types the tests compile against in place, and no
behaviour, `cargo test -p homma-engine` failed four of the new tests on their
assertions and the fifth through the binary:

- `a_line_that_is_not_a_cut_write_is_refused_by_number` read all six of its
  cases as the last object instead of refusing them.
- `an_answer_whose_question_was_in_a_cut_write_is_read_by_its_shape` found no
  round, `left: 0, right: 1`.
- `an_answer_that_cannot_be_read_is_said_not_refused` found nothing said,
  `left: []`.
- `an_unknown_call_is_said_on_the_note_whichever_way_it_went` found an empty
  note, `left: ""`.
- `an_answer_without_its_question_is_said_on_stderr`, over the binary, found no
  asked round on stdout and nothing on stderr.

The others passed from the start and pin what must not change:
`a_result_of_an_unknown_call_that_is_not_a_round_passes_without_a_word`, the
changed `a_result_answering_another_tools_call_is_never_a_round`, and the
one byte case, which is now `{` and passed both before and after.

Shown to fail by breaking the code and putting it back. With the end of input
check taken out of `ending`, five of the six refusal cases are read again, the
sixth, text before the object, staying refused by the line having to begin with
`{`. With `answering` made to call every result without an ask a result of an
unknown call, `a_result_answering_another_tools_call_is_never_a_round` fails.

`cargo test -p homma-engine` from `mock/`, with `GIT_CONFIG_COUNT=1`,
`GIT_CONFIG_KEY_0=init.defaultBranch` and `GIT_CONFIG_VALUE_0=main` set because
git on this machine creates `master` where `tests/cli_release.rs` expects
`main`: 464 passed, 0 failed, 1 ignored, 334 of them in the binary's own tests
and 10 in `capture_smoke`. `cargo clippy -p homma-engine --all-targets` reports
nothing.

Not measured: that the scan with `IgnoredAny` is cheaper than the one it
replaced. It builds nothing per candidate, which is the reason for it, and no
committed probe times it.
