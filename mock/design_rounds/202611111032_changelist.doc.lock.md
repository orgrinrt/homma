# doc changelist

Two paragraphs added to the tools section of homma's design: help lists the workspace's tools, and a refused name suggests the nearest. Descends from the topic file `202611111031_topic.homma-help-lists-the-tools.md`, the one open topic.

## What lands

- `mock/DESIGN.md.tmpl`, after the paragraph on a name that is no built-in and no promoted tool: the `Tools:` section of `homma --help` and `homma help`, and the suggestion in the refusal.
- `docs/`, rendered.

## Claims the source changelist will carry

- `homma --help` and `homma help` print a `Tools:` section naming each tool and its summary when the workspace has tools, and no section when it has none or none is found, and a broken descriptor is named in the section as broken. Help exits successfully in every case.
- A refused unknown name carries one "did you mean" suggestion when exactly one built-in command or tool name is close, and none when none or several are equally close.
- The homma-core publish test compares the ambient `CARGO_REGISTRY_TOKEN` before and after the call, so it holds wherever the variable is set and still fails if the call leaks the token into the process.
