# src changelist

This changelist comes from `202611270339_topic.an-older-git-shook-is-found-by-a-probe.md`, the round's one topic, and carries out the locked doc changelist `202611270340_changelist.doc.lock.md`.

## CHANGE: `registration` FROM taking git-shook's doctor at its word TO probing it first with a name no manifest has
File: `mock/crates/homma-core/src/hooks/shook.rs`
Verification: `PROBE` is `homma-no-such-manifest`. After the manifests and the leftovers are checked, `registration` runs `git shook doctor --only PROBE`. Where that answers 0, it adds `OLDER_SHOOK` and returns, so the member is not current, without asking doctor about the manifests. `OLDER_SHOOK` starts `git shook doctor:`, so `homma hook doctor <repo>` passes it on. Test: `a_doctor_that_takes_any_name_is_not_believed_and_the_member_is_not_current`, with the fake git-shook refusing the probe unless told to be older.

## CHANGE: the sweep FROM silent under an older git-shook TO saying so once and installing every member again
File: `mock/crates/homma-engine/src/cmd/hook.rs`
Verification: `sweep` adds `OLDER_SHOOK` to its lines once where a member's registration carries it, then installs that member. Test in `tests/hook_smoke.rs`: with `GIT_SHOOK_OLDER` naming git-shook 9315c61's script, `a_sweep_under_an_older_git_shook_puts_a_hand_edit_back_and_says_why` gets the hand-edited entry put back and the line said.
