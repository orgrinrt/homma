# homma-what-after-the-eighth-review

The eighth review found that a readme table row read as a sourcing line hid a real command, and two rules with no test that fails without them.

- `watch/README.md` has a row that begins with `source`, which put `parts.py` in the set of sourced files, so a runnable script with six verbs was never an answer. The design says another script sources it. The design now says what a script is there (executable, or opening with a shebang), and the code reads the sourcing lines of those files only.
- The rule that a header with a sentence beginning `Sourced` makes a library had no test of its own, since the sourced-by-name rule hid the same files. The design now says a line or a sentence, and a planted test holds both readings on a script nobody sources.
- Ending what a grandchild left holding the pipe was timed and not checked. The test now looks at the process.

No other topic filed earlier remains open for this work.
