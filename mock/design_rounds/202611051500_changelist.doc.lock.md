# doc changelist

One sentence of homma's release design amended and the documents rendered from it. Descends from the topic file `202611051459_topic.agent-reexport-replaces-the-text-scan.md`, the one open topic, and is everything that topic asks of the design.

## What lands

- `mock/crates/homma-core/DEEPDIVE_release.md.tmpl`, "What a release reaches": the sentence on the test over the crate's source says the agent type is re-exported from the one place that sets the roots and that any `ureq::Agent` written outside it is reported in whatever form, instead of naming an alias of it.
- `docs/`, rendered.

## Claims the source changelist will carry

- `tls.rs` holds `pub(crate) use ureq::Agent;` and the registry, GitHub and Forgejo code name the type through `crate::tls`.
- `Agent` is not on the list of what `tls_tests` lets outside code take from `ureq`, and the checks for `Agent::`, for a rename and for a type alias are gone.
- The control plants `pub type Plain = ureq::Agent;` and `type Plain=ureq::Agent;` and both are reported.
- The mutation script has a row for each of the two spellings and its log is the script's own output.
