# doc changelist: a clone's local file cannot stop the gates

## Current state

`What a clone is for` in `mock/DESIGN.md.tmpl` has the manifest's loader read
`homma.local.toml`, and a file that does not parse fail the load. It says
nothing about how `homma local set` writes.

## Changes proposed

Carries the topic `202609241635_topic.a-clone-local-file-cannot-stop-the-gates.md`
into the same section:

- The paragraph on loading is rewritten: the manifest's loader does not read the
  file, `status` and `local` read it themselves, and `status` reports a file it
  cannot parse as its own line and as `instance_error` in the document, beside a
  `null` instance.
- The paragraph on `homma local set` gains how it writes: under a lock beside
  the file, taken exclusively with a bounded retry, and through a temporary file
  renamed over the original.
- The paragraph on `homma status` names `instance_error`.
