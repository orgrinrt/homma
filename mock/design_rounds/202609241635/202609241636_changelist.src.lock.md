# src changelist: a clone's local file cannot stop the gates

Executes `202609241635_changelist.doc.lock.md`, the section `What a clone is
for` in `mock/DESIGN.md.tmpl`.

## CHANGE: field `Config::local` FROM `Option<Local>`, filled by `Config::from_path` TO absent
File: `mock/crates/homma-core/src/config.rs`
Verification: `grep -c "pub local: Option<crate::local::Local>" mock/crates/homma-core/src/config.rs` returns 0, and `a_malformed_file_does_not_stop_the_manifest_load` in `mock/crates/homma-core/src/local_tests.rs` passes over a missing key, bad syntax, an unknown field and a directory where the file should be.

## CHANGE: enum `ConfigError` FROM three variants TO two, dropping `Local(LocalError)`
File: `mock/crates/homma-core/src/config.rs`
Verification: `grep -c "Local(crate::local::LocalError)" mock/crates/homma-core/src/config.rs` returns 0.

## CHANGE: fn `status::run` FROM `(cfg, full, format)` TO `(cfg, local, full, format)`
File: `mock/crates/homma-engine/src/cmd/status.rs`, `mock/crates/homma-engine/src/cmd/mod.rs`
Verification: `grep -c "Local::load(&local::manifest_dir(&cli))" mock/crates/homma-engine/src/cmd/mod.rs` returns 1.

The dispatch reads the file from the manifest's directory, through the same
`manifest_dir` the `local` verbs use, now `pub(crate)`.

## CHANGE: field `StatusReport::instance_error` FROM absent TO `Option<String>`
File: `mock/crates/homma-engine/src/cmd/status.rs`
Verification: `a_broken_local_file_is_reported_rather_than_refused_or_ignored` and `a_good_or_absent_local_file_carries_no_error` pass.

Filled by `StatusReport::carry_local` with the error and its whole source
chain, so the parser's line and column reach the reader. The human output
prints `what this clone is for is unknown: <message>`.

## CHANGE: fn `cmd::local::set` FROM a plain write TO a lock and a rename
File: `mock/crates/homma-engine/src/cmd/local.rs`
Verification: `concurrent_writers_all_land_and_no_reader_sees_a_half`, `a_held_lock_refuses_after_the_wait_and_writes_nothing` and `set_leaves_neither_its_lock_nor_its_temporary_file` pass.

`Lock` creates `homma.local.toml.lock` with `create_new`, retries every 10ms
for `LOCK_WAIT` (5s) and removes it on drop; `set_waiting` takes the wait as
an argument so the test can hold the lock without waiting five seconds. The
result is written to `homma.local.toml.<pid>.tmp` and renamed over the file.
Controls run before locking: an in-place write beside the rename turned the
concurrency arm red in five runs of five, and so did removing the lock.
