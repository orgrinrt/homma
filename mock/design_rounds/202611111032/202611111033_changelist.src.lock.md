# src changelist

Help lists the workspace's tools, a refused name suggests the nearest, and the homma-core publish test holds where the token variable is set. Descends from the topic file `202611111031_topic.homma-help-lists-the-tools.md`, the one open topic, and the locked doc changelist `202611111032_changelist.doc.lock.md`.

## What lands

- `homma-engine` `cmd/tools/suggest.rs`: `nearest`, the one close name among a set, by prefix or edit distance.
- `cmd/tools/groups.rs`: `parse_from` gives the command line an `after_help` carrying the tools section when the arguments ask for help, the workspace read off `--dir` or `--config` the way `manifest_path` does.
- `cmd/tools/host.rs` and `refused.rs`: `help_section`, the `Tools:` text over `report`, and nothing off unix.
- `cmd/tools/dispatch.rs`: `plan` adds the suggestion to the refusal of an unknown name.
- `homma-core` `release/publish_tests.rs`: the publish test compares the variable before and after.
- Tests beside each: `suggest_tests.rs`, `groups_tests.rs`, `dispatch_tests.rs`, `tests.rs`.

## Claims

- `--help`, `-h` and `help` print the `Tools:` section when tools exist, a broken descriptor is named in it, and with no workspace the help is the same as before and succeeds.
- A suggestion is made only when one name is strictly closest, and a tool that is not promoted is suggested as `homma tools run <name>`.
- The publish test fails if the call sets the variable in this process and passes whatever the ambient value is.
