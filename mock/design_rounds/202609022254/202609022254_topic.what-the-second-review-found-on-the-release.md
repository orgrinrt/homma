# What the second review found on the release

**Date:** 2026-09-02
**Phase:** TOPIC
**Scope:** `homma-core/src/release/publish.rs`, `homma-engine/src/cmd/release/`, and the tests beside them, after round `202609022245` closed and the pull request was reviewed a second time
**Source topics:** the second review of pull request 46, and `202609022140/202609022115_topic.a-release-is-a-gated-merge-off-main.md`, which nothing here changes

## The four findings

The npm token is written to a user config at a predictable path under the temp directory, `homma-npmrc-<pid>`, and the file is opened with `create` rather than `create_new`. A symlink planted at that name ahead of the publish receives the token wherever the link points, and a file planted there keeps whatever mode it had, because the mode on open applies only to a file the open creates. The path gains a random component, the open refuses an existing path, and a planted link or file is a refusal rather than a write. The test that pinned the mode now also plants both.

`homma release badges` demanded a gate run on the tip of the release line, and runs are recorded for the checked-out head, which on a repo with a working trunk is the trunk, and after a release the release line's tip is a merge commit no gate measured. The deep dive says the badges come from the newest record and pins no branch, so the command reads the newest run recorded for the repo, whichever sha, and says which sha it came from.

The multi-repo release goes in name order where the deep dive asks for dependency order across repos. The gap stays, and it is catalogued as an ignored red test that asserts the dependency order, so it is a test that flips rather than a comment that fades.

The publishing module's documentation named jsr as the one tool whose token leaves the environment. The npm token reaches its tool through a file, so the doc names both.

## What does not change

The design. Every fix is the code doing what the deep dive already says, so the doc changelist of this round names no template.
