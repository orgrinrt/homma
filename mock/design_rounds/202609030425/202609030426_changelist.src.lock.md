# Source changelist: the hook gates every tip, and versions compare as semver

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609030425_changelist.doc.lock.md`

## `homma-api`

### `src/release.rs`, `release_tests.rs` (modify)

CHANGE: `Version`'s ordering compares prerelease identifiers the semver way, dot-separated, numeric ones numerically and below alphanumeric ones, a prefix below what it prefixes. The test covers `rc.9` against `rc.10`, `alpha` against `alpha.1`, and a numeric against an alphanumeric identifier.

## `homma-core`

### `src/release/gate.rs`, `gate_tests.rs` (modify)

CHANGE: `feature_sets` reads the root manifest and, where it declares none, each workspace member `publish::crate_dirs` lists, taking the first that declares any; a test plants a virtual root with a declaring member. `run_gate_at` runs the gate on a commit that is not the checkout's head by adding a detached worktree beside the store's scratch, running there, and removing it; the head runs in place. A test with the fake runner asserts the run carries the other commit's sha and the worktree is gone after.

### `src/release/git.rs` (modify)

CHANGE: `worktree_add_detached` and `worktree_remove`.

### `src/release/packages.rs`, `plan.rs`, `publish.rs` (modify)

CHANGE: `Published::get`, `Plan`, `PlanError` and `PublishError` carry summary lines.

## `homma-engine`

### `src/cmd/release/mod.rs` (modify)

CHANGE: with `--hook`, every distinct local sha the hook is handed on stdin is gated through `run_gate_at`, recorded and posted, and the report carries one summary per tip; a push of no refs still says there is nothing to gate. `pushing_head` becomes `pushed_tips`.
