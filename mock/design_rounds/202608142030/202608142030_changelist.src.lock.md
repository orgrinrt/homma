# Src changelist: prove containment on the write

## CHANGE: `homma-api` gains `Root` and `ContainedPath`

A `Root` is a workspace root with its resolved form remembered. Its only
interesting method mints a `ContainedPath` from an `AbsPath`, by resolving that
path against the filesystem and refusing it when the result does not sit under
the resolved root.

`ContainedPath` has no other constructor. That is the whole mechanism: holding
one is proof that the check ran, and the check cannot be skipped by a caller who
did not know it existed.

Resolution is against the filesystem rather than lexical because lexical is what
a symlink defeats, and a symlink inside the root is the reproduction this round
answers.

## CHANGE: `Layout` hands out only proven paths

Every accessor returns `Result<ContainedPath, Escapes>` instead of `AbsPath`, and
`Layout` holds a `Root` rather than a bare root path.

## CHANGE: `prepare` and `write_definitions` accept only proven paths

Which is the property being bought. A write computed from a path nobody checked
no longer type-checks.

Directory creation re-proves afterwards, because proving and then creating is a
window a symlink can be planted in. Closing the window entirely wants creating
each component and checking as it goes; re-proving turns a silent escape into a
loud one, which is the honest half and is what lands here.

## CHANGE: `stand` establishes the workspace before it initialises anything

`git.init(root)` ran before anything established that the workspace was not
inside another repository, so a refusal left a `.git` behind. The check moves
ahead of the initialisation.

## CHANGE: three false claims removed

The `stand` doc comment asserting every written path passes through one guard,
which was false when written and survived a round after being reported.

The comment on the join-clamp test claiming that loosening `join` fails nothing
else, which measurement contradicts: two tests fail.

The unreachable `is_absolute()` early return in `RelPath::new`. The components
loop already refuses a root component, so deleting it fails nothing, and dead
defence that reads as live defence is this branch's recurring defect.

## CHANGE: tests

A symlinked path under the root is refused rather than followed. A workspace
nested in a foreign repository leaves no `.git` behind. Both are the
reproductions, as tests, so the ninth round cannot reopen them quietly.
