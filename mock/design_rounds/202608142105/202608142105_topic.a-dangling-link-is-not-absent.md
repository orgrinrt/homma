# A dangling symlink is not an absent path, and every write follows one

Ninth review, ninth refusal. The type introduced last round is real and the
property it claims is real; the **predicate underneath it** is wrong, in a way
that was checkable from the module's own doc comment without running anything.

## The sentence that was false

`contained.rs` argued its own sufficiency in one line:

> a symlink that would redirect the write has to exist for the write to follow it

It does not. `AbsPath::resolved` finds the longest existing prefix with
`Path::exists()`, and **`exists()` follows the link**. A dangling symlink
therefore reports `false`, is popped off as absent, and is re-appended as
written. `fs::write` opens with `O_CREAT|O_WRONLY|O_TRUNC`, follows the link,
and creates the target.

Measured:

| Call on a dangling link | Answer |
|---|---|
| `Path::exists()` | `false` |
| `symlink_metadata().is_ok()` | `true` |
| `canonicalize()` | `Err(NotFound)` |

So a root containing `.claude/agents/r.md -> ../../../victim/r.md`, with the
target absent and its directory present, is proven contained, and `org up`
writes the definition into `victim/`. Exit 0. With an absolute target it reaches
another Hand's workspace, which is deny item two, or `~/.claude`, which is item
three.

## Why the fix is the walk and not the predicate

Swapping `exists()` for `symlink_metadata().is_ok()` is not enough on its own.
`canonicalize` still fails on a dangling link, and `AbsPath::canonical` maps
`NotFound` to the path as written, so the same hole reopens one layer down.

What resolution has to do is what the kernel does: walk the components, and
whenever one is a symlink, read it and re-anchor, whether or not its target
exists. `read_link` works on a dangling link, which is the whole reason this is
tractable.

## The tests were a sampled law

Both symlink tests instantiate one shape, the one where the target exists. The
broken shape is never named, so the suite reads as closing a class it covers half
of. The dangling case is written first, watched fail, and committed red before
anything is fixed.

## Three more, from the same review

`ContainedPath` implements `Deref<Target = Path>`, so `contained.join(x)` is
`Path::join`, unchecked, and an absolute `x` replaces the receiver outright. The
proof is silently voidable by anybody who does not know to avoid it, and the
branch's own code works around this by hand in one place with a comment
explaining why.

`link_memory` takes two `&Path`, and performs `remove_file` and `symlink` on
them, against the module's claim that such a write no longer compiles.

`stand.rs` says "Both sides resolved" of a comparison where one side is raw. It
is inert only because a caller upstream canonicalises first, and nothing pins
that.

## The pattern being corrected, stated plainly

Nine rounds have each shipped a guard plus a paragraph asserting the guard is
total. Every round the guard improved and every round the paragraph was still
false. **The paragraph is the recurring defect.** A sentence claiming
sufficiency is a claim like any other, and the ones here have been checkable in
three lines of `std` every single time.
