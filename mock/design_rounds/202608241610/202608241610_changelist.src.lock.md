# Source changelist: two holes the review found

**Date:** 2026-08-24
**Phase:** SRC
**Topic:** `202608241610_topic.two-holes-the-review-found.md`

## CHANGE: `mock/crates/homma-api/src/config.rs`

ADD `fn control_character_fields<T: Serialize>(entry: &T) -> Result<Vec<String>,
Unreadable>`, which is the per-entry half of `unsafe_strings` lifted out so the
serialisation failure has a name and a caller can be written for it. Generic
over `Serialize` rather than taking `Identity`, because the branch under test is
unreachable through `Identity` and a test that cannot reach it is not a test.

ADD `pub struct Unreadable`, the error it returns.

EDIT `Workspace::unsafe_strings` to fail closed: an entry that will not
serialise is reported as `<unserialisable>` on that handle rather than skipped.
Both callers already refuse on a non-empty result and render `` `handle`.field ``,
so neither changes.

DROP the FIXME and the comment claiming the failure surfaces at the write. There
is no write path and the claim was never true.

ADD tests: an entry that will not serialise is reported rather than cleared; the
control beside it, that a readable entry with a control character is still
reported by field; and the second control, that a readable clean entry is
reported not at all.

## CHANGE: `mock/crates/homma-api/src/git.rs`

EDIT `CommitIdentity` to hold its four parts privately.

ADD `CommitIdentity::same(name, email)` for one identity in both roles, and
`CommitIdentity::split(author_name, author_email, committer_name,
committer_email)` for the case where they differ. Both refuse an empty part.

ADD `pub enum Part` naming which of the four, and `pub struct EmptyPart` as the
refusal, so the caller learns which one rather than that something was empty.

ADD `author_name`, `author_email`, `committer_name`, `committer_email`
accessors returning `&str`.

ADD tests: each of the four parts refused on its own and named in the refusal,
`same` putting one pair in both roles, `split` keeping them apart, and the
control that a full identity is accepted.

## CHANGE: `mock/crates/homma-core/src/repo/git_impl.rs`

EDIT `identity` to build through `split`, which is where its empty filter now
lives: the author pair is required and the committer pair falls back to it, so
a value that survives the filter is non-empty by construction and the
constructor cannot refuse. EDIT the write path and its tests to read through the
accessors.

## CHANGE: `mock/crates/homma-org/src/provision.rs`, `mock/crates/homma-core/tests/reads_the_local_config.rs`

EDIT the construction sites to the constructors and the field reads to the
accessors.
