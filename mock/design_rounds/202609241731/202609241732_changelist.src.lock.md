# src changelist

## CHANGE: `homma-core/src/local.rs`, `ensure_ignored`

Appends `/homma.local.toml` and `/homma.local.toml.*`, each only where no line
already names it, so a `.gitignore` carrying the first gains the second.

## CHANGE: `homma-core/src/local_tests.rs`, the ignore lines

Every combination of the two lines being present or absent, the lines that only
resemble either, and one test asking `git check-ignore` which paths the written
lines ignore: the file, its lock and its temporary file at the root, and neither
the manifest, a longer name, nor the same names in a subdirectory. Unanchoring
the second line turned eight of them red.

## CHANGE: `homma-engine/src/cmd/local_tests.rs`, init and the lookup

`init` over a `.gitignore` carrying only the first line reports a change and adds
the second. The test deleted when the lookup left the config loader comes back
against `manifest_dir`: with `workspace.path` naming another directory holding
its own file, both `--config` and `--dir` find the one beside the manifest. A
relative `--config`, and none at all, resolve against the working directory.
