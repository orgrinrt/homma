## CHANGE: `mock/DESIGN.md.tmpl`, the `homma local init` paragraph

`init` adds `/homma.local.toml.*` beside `/homma.local.toml`, each where no line
names it yet, so the lock and the temporary file a dead `set` leaves behind are
ignored too. Where a `.gitignore` already names the file, the second line is
still added.
