# Two holes the review found: a check that fails open, and a guarantee with no perimeter

**Phase:** TOPIC
**Scope:** `homma-api` (`config.rs`, `git.rs`) and the `CommitIdentity` call sites

## The control-character check clears what it cannot read

`Workspace::unsafe_strings` exists to refuse registry strings that would inject
structure into generated output. A newline in a nickname writes an arbitrary
key into YAML frontmatter, which is how an entry could grant itself something
the design withholds. The check derives its field list from the serialised form
rather than from a hand-written list, which was the right correction: the
hand-written list had already missed two fields in two consecutive rounds.

What it does with an entry that will not serialise is `continue`. So an entry
the check cannot read is treated as an entry with nothing wrong, and the comment
beside it says the failure surfaces at the write instead. Nothing in the tree
writes a `Workspace` back to TOML, so that sentence describes a place that does
not exist.

**A check that cannot read a thing has not cleared it.** No field today can fail
to serialise, every optional one being skipped when absent, so the branch is
unreachable now and the fix is cheap now. Waiting until it is reachable means
fixing it under a field somebody added for another reason, which is the round
where nobody is looking at this.

So it fails closed: an entry that will not serialise is reported, and the
operator sees the entry named rather than nothing.

## Four public fields under an invariant one function establishes

`CommitIdentity` carries the author and committer that a clone stamps on a
commit. Reading one out of a clone's configuration is careful about emptiness:
an empty value is not a value, so `identity` filters them and answers `None`
where the author's pair is not both present.

The type then publishes all four fields, so that care covers exactly one way of
obtaining one. Anything may build a `CommitIdentity` with four empty strings and
hand it to `set_identity`, which writes six keys, and a clone configured with an
empty name commits as nobody.

The guarantee holds over the operations through which the type can be observed,
and the fields are the perimeter. So they close, construction goes through
something that refuses an empty part, and reading stays as cheap as it was.

Two shapes, because both are ordinary. One identity used for both roles is
every entry but one; a split pair is the case this branch exists for.
