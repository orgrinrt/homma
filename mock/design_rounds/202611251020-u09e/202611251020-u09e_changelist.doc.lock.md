# doc changelist

Descends from `202611251020-u09e_topic.skills-carry-effort-and-modes-and-principles-are-kinds.md`, the round's one topic. Its sections on effort, modes, principles, the gate, the configuration and the one generation path are the changes below; its tests section is source only.

## CHANGE: the skill corpus FROM a skill's host keys without `effort` and no modes TO `effort` a known key, modes a kind rendered into the skills tree, and the effort gate
File: `mock/DESIGN.md.tmpl`
Verification: `## The skill corpus` says `effort` is a known key taking `low`, `medium`, `high`, `xhigh` or `max` and passed through as written; a new `## The mode kind` says what a mode file holds, where its skill is written and under what name, the frontmatter built from it, the refusals (type against file name, body over the limit, a name an authored skill has), and that only `.md.tmpl` files are modes; a new `## The effort gate` says when `homma skills render --model <id>` keeps the effort keys and the mode skills, and that without it or where the gate fails every `effort` line is taken out and no mode skill is left.

## CHANGE: the rule corpus FROM one source directory TO the rules and a principles directory as a second source
File: `mock/DESIGN.md.tmpl`
Verification: a new `## The principle kind` says a principle is a rule's frontmatter and a card only, written as `<card prefix><name>.md` beside the rules' cards by the same renderer and session binding; an elaboration and a first heading other than `# <title prefix><name>` are refused; it is kept apart from the rules, `rules about` does not answer with it and `rules load` counts its card.

## CHANGE: the configuration of the surfaces FROM none TO the `[surfaces]` table
File: `mock/crates/homma-api/DESIGN.md.tmpl`
Verification: `## Where the files are` names `SurfacesConfig`, the `[surfaces]` table, with `ModesConfig`, `PrinciplesConfig` and `EffortGate`, their keys and defaults; and a new `## A skill's effort and a mode` names `Effort`, the host's five words, and `ModeMeta` with what `mode::parse` refuses.

## CHANGE: generation FROM a walk, render, write and unclaimed listing per corpus TO one generic path all four kinds go through
File: `mock/crates/homma-org/DESIGN.md.tmpl`
Verification: `## Generation` gains a paragraph saying the `Kind` trait states how a kind's sources sit and how one is read, and `surface::load`, `surface::unclaimed`, `surface::render` and `surface::write` are the one path the rules, principles, skills and modes go through, the personas' corpus moving onto it later.
