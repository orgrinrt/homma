# the-caller-names-the-kinds-and-the-verdict

Follows the closed rounds 202611251020-u09e, 202611251031-ky2j, 202611251034-l741 and
202611251044-dnk6. A review of the branch against its tickets found:

## A second home for the modes' and principles' settings

Round u09e put the modes' directory, skill prefix and body limit, and the principles' directory and
prefixes, in a `[surfaces]` table homma declares. The workspace already holds those values in
settings files of its own, so each now has two homes, and a manifest holding a tool's own table is
the layered configuration work, which is not this branch's. Decision: `[surfaces]` goes. The
caller names them as arguments: `homma skills render --modes <dir> --mode-prefix <prefix>
--mode-body-max <chars>` and `homma rules render`/`rules load` `--principles <dir>
--principle-prefix <prefix> --principle-title <prefix>`, each group all or none. Without the group
there are no modes, or no principles.

## The effort gate is the caller's

Round u09e had homma work the verdict out from a list of models, variables and an API host written
into it, and strip every `effort` line from a render told no model. Decision: `effort` passes
through as written, like `model`. The caller decides whether a change of effort keeps its cache;
`homma skills render --no-effort` is how it says one does not, and then every `effort` line is
taken out and no mode skill is left, one an earlier render wrote removed. homma keeps no model list
and no host.

## Two features that are not this branch's

The ask cache's expiry and cap (round ky2j) and the planted workspace of the `what` tests (rounds
l741 and dnk6's renames) are carried on branches of their own. Decision: they are taken out here,
code, tests and design text back to the trunk's, so each lands once.

## Engine tests

Decision: tests at the command layer, each shown red first: a mode whose skill name an authored
skill has is refused by `skills render`; `--no-effort` removes an earlier mode skill and keeps the
authored skills; `rules render` writes a principle's card from the named directory and `rules
load` counts it.
