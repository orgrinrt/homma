# Src changelist: delete the guard that cannot fail, pin the one that works

## CHANGE: the tautological containment check on the link body is deleted

`lands` was provably `target.as_abs().resolved()`, which `prepare` had proven one
frame earlier, so the check could not fail for any input. Measured twice by the
reviewer: asserting the equality never trips, and deleting the call leaves the
suite green.

The real argument replaces it in the comment, and it is short: both ends are
resolved before the body is computed, and two paths inside the root have a
relative path between them that ascends only to their common ancestor, which is
at or below the root. The parent check above is what makes "both ends inside"
true, and that is now stated where it is relied on rather than three functions
away.

## CHANGE: the parent check gets the test it never had

Replacing `root.contain(&parent)?` with a bare `create_dir_all` leaves all 338
tests green while opening a real escape, so the guard doing the work was pinned
by nothing while the guard doing nothing sat above it advertised.

The shape, which no existing test names: the parent chain leaves the root and the
final component points back inside. `contain` on the link follows the final
component and passes; the parent resolves outside.

## CHANGE: `Layout::root` is deleted

It returned an unproven `AbsPath` from a type whose documentation said every
accessor returns a proven path. A reviewer used it to compile a write that three
places in this crate claim does not compile.

It has no callers anywhere in the workspace, so the route closes by deletion
rather than by anything cleverer. `Layout::contained_root` remains and returns
the `Root`, which is the thing a caller actually wants.

## CHANGE: two false claims in source comments

`workspace.rs` and `contained.rs` both say a write computed from an unchecked
path does not compile. They say what holds instead: two functions take a proven
path, so those cannot be called without one, and `std::fs` will accept anything
`AsRef<Path>` from anybody who writes a new one.
