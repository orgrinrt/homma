# The test module had no imports of its own

The previous round dropped `use std::fs` and `use std::path::Path` from
`gates.rs` as orphaned by a signature change. Its src changelist recorded, as its
only claim about the test half: **"The test module keeps its own `Path`
import."**

It did not have one. `mod tests` carried no `use` items at all and reached both
through `use super::*`, which glob-imports the parent's private imports. Removing
them from the parent removed them from the tests.

So the round was correct about the non-test half, correct that the autofix would
re-apply the removal, and wrong about the one thing that decided whether the
suite still built. `cl-claim-sketch-discipline.md` requires a locked claim to
match source at lock time; this one did not, and nothing checked it.

## Why it was invisible

`cargo check -p homma` succeeds. `cargo check --tests -p homma` fails with
thirteen errors, `E0433` for `fs` and `E0425` for `Path`. A gate that builds
without `--tests` reads green, and eighty-five unit tests in that crate stop
being compiled at all while every surviving signal stays positive.

`cargo test` does fail loudly with a non-zero exit rather than silently, so the
exposure is narrower than "the suite went dark unnoticed": it is a build-only or
check-only gate, plus anybody reading a green build as evidence the tests ran.

## What this round does

Restores the two imports **inside `mod tests`**, where the uses are, rather than
at the file top where the previous round correctly found them dead.

It also carries three fixes to the same surface that were made while the phase
was `TOPIC` and therefore have no changelist of their own. Recording them here is
the audit trail they should have had; the commits stay as they are, because
history that has been pushed is not rewritten.

## The rounds this branch keeps

Every prior source edit on this branch sat inside an `IMPL` round with its src
changelist beside it. Three commits did not. The hooks were not installed in the
clone where they were authored, so nothing refused them, which is the difference
between a discipline failure and a gate defect. It is the first kind.
