# Doc changelist: the design still describes the resolution it deleted

## CHANGE: `homma-org/DESIGN.md.tmpl`, the resolution paragraph

It says a path "is resolved as far as it exists before anything walks it" and
that "what is resolved is the longest prefix that does, and the rest is
re-appended". That is the `Path::exists()`-prefix approach the ninth round
deleted, because `exists()` follows a link so a dangling one reads as absent.
The same document then says `resolved` follows a dangling link, so it
contradicts itself, and an implementer deriving from it rebuilds the bug.

## CHANGE: the deny list appears in the design at all

Nothing in the design mentions the absolute locations the record forbids,
because until this round nothing in the code did either. Containment is relative
to a root the operator names; the deny list is not relative to anything.
