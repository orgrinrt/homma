# doc changelist

Answers the topic filed in this round, `homma-what-after-the-seventh-review`, and amends the section "Finding a tool" of `mock/DESIGN.md.tmpl` that the closed round `202610271330` left.

## Current state

The section makes a library only a file with neither a bit nor a shebang or one whose header says `Sourced`, names the related cut as an eighth, and takes a header line that is only a script's name as its summary.

## Changes proposed

- Scripts: a file that is not executable and that another script sources or lists as a module is a library; a header line that is only the script's own name is skipped.
- Related things: the cut is 0.225, set on a catalogue of pairs kept in a test, with the nearest pair on each side recorded.
