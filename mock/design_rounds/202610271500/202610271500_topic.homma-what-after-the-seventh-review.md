# homma-what-after-the-seventh-review

The coordinator held the branch until a review pass finds nothing, and the seventh pass named four things the design leaves wrong for the real tree, and seven design rules with no test that fails without them.

- Eight libraries with a shebang were offered as commands, among them `retry.sh` and `bootstrap_workspace.sh`. The workspace says a file is a library by sourcing it from another script (`source`, `.`, a `shellcheck source=` line) or by listing it as a module in a `lib.nut`. The design now reads that, for a file that is not executable.
- The related cut was a bare number. It is set on a catalogue of pairs of the real workspace that must and must not be named together, kept in a test, and the design records the figure and the nearest pair on each side. The figure moves from 0.125 to 0.225, since at 0.125 `homma skills` and `homma rules` were named beside `stray-runs`.
- A header line that is only the script's name became the summary. It is skipped like a line of rules.
- Each of the seven rules without a test gets one: the `shellcheck` line, the skipped directories, `//` headers, `env` flags, the related cut, the swap allowance for three letters, and the builtins once.

No other topic filed earlier remains open for this work.
