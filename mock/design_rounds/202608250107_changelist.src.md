# SRC changelist: the publish flip, and what the launcher check actually reads

**Phase:** IMPL

Two things the audit trail is missing, plus the review findings on the launcher
tree.

## CHANGE: `homma/launcher/Cargo.toml` `publish` FROM `true` TO `false`

File: `launcher/Cargo.toml`
Verification: `grep '^publish = false' launcher/Cargo.toml` returns one match.

The previous round's locked changelist recorded the package as added with
`publish = true`. It shipped `false`, flipped after that round closed. A locked
changelist is frozen, so the correction is recorded here rather than edited into
the file that made the claim.

The reason is a fact about the world rather than a decision: the launcher depends
on the shared launcher machinery through a git reference, that crate is not on a
registry, and a registry rejects a git dependency outright. So `true` would be a
claim the manifest cannot honour, and `cargo deny check bans` reports it as a
wildcard dependency for exactly that reason. It goes back to `true` the day the
dependency publishes, in its own round.

## CHANGE: `engine_dir_holds_the_engine` FROM a substring scan TO a section read

File: `launcher/src/lib.rs`
Verification: `grep 'package_name(&manifest)' launcher/src/lib.rs` returns one
match, and `grep -c 'manifest.contains' launcher/src/lib.rs` returns zero.

The check read the manifest as text and looked for the engine's name anywhere in
it. Four manifests that are not the engine were accepted: a package under another
name declaring a `[[bin]]` under the engine's, a comment mentioning it, a renamed
dependency on it, and any of those in combination. Two manifests that are the
engine were refused, because TOML has three spellings of the same assignment and
the scan knew one.

`names_in_section` reads `name` from one named section, strips comments, and
takes either quote character. It already existed, in the test file next door,
where it was more careful than the check it sat beside.

## CHANGE: ADD `verify_engine_dir` to the descriptor's hooks

File: `launcher/src/lib.rs`
Verification: `grep 'verify_engine_dir: Some' launcher/src/lib.rs` returns one
match.

The engine sits well inside the tree, and the top of the tree is what anyone
reaches for. Without the hook that came back from cargo as a virtual-manifest
complaint naming neither the flag that caused it nor the directory that would
have worked.
