# two-test-files-cut-under-the-size-limit

Extends round 202611251443-nfvz. The ask's tests grew past the file-size limit with the cache tests
that round added, and the source tests of `what` stood past it already.

## The ask's tests

Decision: the tests of the cache, its expiry, its cap, the write in flight and where it sits, go to
a sibling file of their own beside the ask's other tests, with the helpers only they use. The shared
helper that makes a cache is reached from there.

## The source tests of `what`

Decision: the tests that parse a header from its text alone, with nothing planted, go to a sibling
file of their own; the tests that gather from a planted tree stay.

No test changes what it checks.
