# SRC changelist

## CHANGE: `.gitignore`

DROP the trailing slash from the six directory patterns covering generated
agent output, with a comment saying why.

WHY: `dir/` matches only a path that exists as a directory, so before the
generator has run every one of them reports unignored, and the assertion over
them fails on any fresh clone.

## CHANGE: `mock/crates/homma/tests/generated_paths_are_ignored.rs`

ADD `the_ignore_list_holds_before_anything_has_generated_into_it`: a temporary
git repository carrying this repository's own `.gitignore` and none of the
generated output, asserting every path is ignored there.

WHY a constructed repository rather than the real one: the existing test runs
where the directories are already present, which is the one condition under
which the defect is invisible. It could not have caught this and cannot catch
the next one.

ADD the control inside it: a path the ignore file does not name must come back
unignored from the same temporary repository, or the test passes for a
`check-ignore` that answers zero to everything.
