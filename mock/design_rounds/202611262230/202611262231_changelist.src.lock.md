## CHANGE: the marker's reading FROM a match on any line TO the two exact shapes

`crates/homma-engine/src/cmd/nudge/mod.rs`

- `marker_in` and `without_marker` are gone. `marked` reads a shell command as
  `Marked::Restated { call, reason }`, the `# <marker> <why>` comment on the last
  line with the call before it, or `Marked::Alone { reason }`, `: <marker> <why>`
  with none of `RUNS_MORE` in it, or as neither.
- A restated call answers only a stop whose text is the call exactly. Any other
  shape answers nothing, and the call meets the rows as written.

## CHANGE: the nudge tests FROM one file TO the decision, the marker and the wrappers

`crates/homma-engine/src/cmd/nudge/tests.rs`, `tests/marker.rs`, `tests/wrappers.rs`

- The wrapper tests move whole from `tests.rs` into `tests/wrappers.rs`.
- `tests/marker.rs`: both probes of the review, a different call before the
  marker, a marker on a line before the last, the `:` form with each of
  `RUNS_MORE`, each failing on the code before this round; and two sessions kept
  apart.
