## CHANGE: the test environment FROM inheriting the machine's template directory TO forcing an empty `GIT_TEMPLATE_DIR`
File: `.cargo/config.toml`
A new file carrying `[env]` with `GIT_TEMPLATE_DIR = { value = "", force = true }`. Cargo hands it to every test process and so to every `git` the tests spawn, from the repository root or from a member directory. The empty value outranks `init.templateDir`, and `force` makes it outrank a `GIT_TEMPLATE_DIR` the machine already exports. Verification: `hook_install_writes_one_entrypoint_per_event_and_says_how_git_reaches_them` passes on this container with the file in place, and the two tests below pass with the file in place and also with `GIT_TEMPLATE_DIR` exported to the container's real template directory.

## CHANGE: new test `a_repository_made_under_a_hostile_template_dir_has_no_hooks_and_commits`
File: `mock/crates/homma-core/tests/hostile_template_dir.rs`
Builds a template directory whose `commit-msg` and `pre-commit` hooks exit 1, a global configuration naming it as `init.templateDir`, and makes and commits a repository with `git init`, using a `git` that inherits the process environment as every test does. Verification: red with `.cargo/config.toml` moved aside (the repository carries the hostile hooks), green with it in place.

## CHANGE: new test `a_clone_made_under_a_hostile_template_dir_has_no_hooks_and_commits`
File: `mock/crates/homma-core/tests/hostile_template_dir.rs`
The same for a repository made by `git clone`, which copies the template directory too. Verification: red with the file moved aside, green with it in place.
