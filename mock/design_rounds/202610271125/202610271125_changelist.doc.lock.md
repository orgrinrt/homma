# doc changelist

Answers the topic filed in this round, `homma-what-after-the-second-review`, and amends the section "Finding a tool" of `mock/DESIGN.md.tmpl` that the closed round `202610271110` left.

## Current state

The section lets a shebang alone make a file a script, lists `ended` with `done`, gives a rule its `fires` line and topics, names the JSON key `matches`, and does not say which repository a project's mockspace tool runs in.

## Changes proposed

- Scripts: a header with a sentence that begins `Sourced` says the file is sourced by another and is a library, whatever its bit or shebang, the sentence the hygiene directory's convention already asks of such a file.
- Scripts: a usage line is a later line than the first prose line, and the first prose line is never one.
- The mockspace listing: a project tool's answer names the repository it comes from and its command is prefixed with `cd <repository> &&`, since it runs nowhere else; the builtins need none.
- Rules: the whole card is searched as the rest of the text.
- The synonyms: `end`, `ended`, `stop` are one group and `done`, `finished`, `complete` another.
- The JSON key is `matched`.
- The acceptance set is the set run with every source, and its report says which cases are unmet.
