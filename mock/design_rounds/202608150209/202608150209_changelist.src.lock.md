# Src changelist: make the test hostile, and write the names

## CHANGE: the exit test runs against a hostile global configuration

`GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` point at a file naming a different
author and committer for the duration of the test, so homma's values have to win
rather than merely coincide with the machine's. That also makes the test portable
off this machine, which it was not.

## CHANGE: `author.name` and `committer.name` are written

A global one overrides the local `user.name`, so without these a provisioned
workspace commits under a name homma did not configure while the read-back
reports success.

## CHANGE: `Identity` gains `committer_name`

U-3.2's Produces names a committer name and email. Only the email shipped.

## CHANGE: `Git::identity` reports the committer

The read-back guard compared the author and ignored the committer, so a write
that dropped the committer passed it. The write half was widened last round and
the read half was not.

## CHANGE: `unsafe_strings` is derived, not enumerated

The hand-written list is why `committer_email` slipped past the test written to
catch exactly that, one iteration after the comment explaining why the test
exists. Serialising the entry and scanning the result sees every field, including
the ones nobody has added yet.

## CHANGE: three comments that no longer describe their code

The trait's two doc blocks concatenated at the summary line; a paragraph about
test doubles orphaned from the test it described when a new one was inserted
between them; and a claim in `fake_git` that a test asserts the two identities
differ, when none in that crate does.
