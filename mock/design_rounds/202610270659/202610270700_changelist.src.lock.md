## CHANGE: the test environment FROM inheriting the machine's `init.templateDir` TO naming an empty `GIT_TEMPLATE_DIR`
File: `.cargo/config.toml`
A new file carrying `[env] GIT_TEMPLATE_DIR = ""`. Cargo hands it to every test process and so to every `git` the tests spawn, from the repository root or from a member directory, and the empty value outranks `init.templateDir`. Verification: the new test below fails with the file moved aside and passes with it in place, and `hook_install_writes_one_entrypoint_per_event_and_says_how_git_reaches_them` passes on this container with the pin and no per-site flag.

## CHANGE: test `hook_install_writes_one_entrypoint_per_event_and_says_how_git_reaches_them` FROM passing only where the per-site `--template=` of the first fix reached TO passing on the pin alone
File: `mock/crates/homma-engine/tests/support/mod.rs`
`clone_at` runs `git init -q -b main` again, the `--template=` the first fix added is dropped. Verification: `cargo test -p homma-engine --test cli_release` passes 10 of 10.

## CHANGE: the `repo()` helper of the install tests FROM `git init --template=` TO `git init` on the pin
File: `mock/crates/homma-core/src/hooks/install.rs`
The same drop. Verification: the `hooks` unit tests of `homma-core` pass.

## CHANGE: new test `a_repository_made_under_a_hostile_template_dir_has_no_hooks_and_commits`
File: `mock/crates/homma-core/tests/hostile_template_dir.rs`
Builds a template directory whose `commit-msg` and `pre-commit` hooks exit 1, a global configuration naming it as `init.templateDir`, and makes and commits a repository with a `git` that inherits the process environment, as every test does. Verification: red with `.cargo/config.toml` moved aside (the repository carries the hostile hooks), green with it in place.
