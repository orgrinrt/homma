# SRC changelist: absolute is not contained

**Round:** the containment round
**Phase:** IMPL

## CHANGE: mock/crates/homma-org/src/provision.rs

**The blocker.** Refuse a workspace that sits inside another repository, asking
`enclosing_repo` about the target rather than only about the root. Catches a
relative `..`, an absolute path into somebody's tree, and everything else that
reaches the same place, because the property is "not in another repository"
rather than "under the root".

Delete the fake's tautological assertion. It asserts what the parameter type
guarantees, and its comment describes a runtime check this round's predecessor
removed. `the-test-gate.md`: deleted outright, not repaired.

## CHANGE: mock/crates/homma/src/cmd/stand.rs

The same fake, the same deletion. Split, since it is 506 lines.

## CHANGE: mock/crates/homma-api/src/path.rs

`canonical()` distinguishes absence from failure. A symlink loop or a permission
error silently yielded an unresolved path, and that path is what the guard walks
from.

## CHANGE: mock/crates/homma-api/src/git.rs

The `origin_url` doc still teaches that the clone URL comes from the root's
remote because a configuration key would duplicate the fact. Op killed that in
round thirty-four and named it as the cause of a defect.

## CHANGE: mock/crates/homma/src/cmd/util.rs

`resolve_local_path` is a second, untyped copy of `AbsPath::resolve` with six
callers. Replaced by the type.

## CHANGE: mock/crates/homma/src/cmd/org.rs

`check_handle` runs when a registry is read, not only when `org add` writes one.
A hand-edited handle carrying `..` reached `Layout::home` unchecked, and the
registry is hand-editable on purpose.

## CHANGE: mock/crates/homma/tests/

A test for the `..` escape and for an absolute workspace inside another
repository. The security test asserts **why** it failed rather than only that it
did.
