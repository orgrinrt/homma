# a-message-written-twice-across-the-cut-is-shown-taken

The design says a message the harness wrote twice, with the first copy before the cut, reaches a cut file as its second copy and is taken. The only test for it passed with the boundary removed. The round adds the case end to end, a stored capture whose `through` is the lost first copy over a cut file holding the second, and the readme row for `homma capture` stops saying without exception that only what came after the last capture is taken.
