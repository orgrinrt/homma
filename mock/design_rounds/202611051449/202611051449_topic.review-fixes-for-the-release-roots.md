# review-fixes-for-the-release-roots

A review pass over the branch that makes `homma release` trust the roots of a container and find every clone (`ae2c89b`, three closed rounds) returned merge after fixes. This topic records what it found and what this round decides. The design in `DEEPDIVE_release.md.tmpl` and `mock/DESIGN.md.tmpl` stands in for a canon, since homma declares no `canon_paths`.

## What the review found

The scan that guards the one place every agent starts from can be got round by renaming the allowed type: `use ureq::Agent as Plain; Plain::new()` is never reported, since the head identifier is the allowed `Agent` and the text check looks only for `Agent::`. A mutant adding that line survived the committed mutation script, and the module doc claims a spelling nobody thought of is caught too, which is not so.

The message written to standard error for a store with no root in it is behaviour a user sees, and no design text mentions it. The last doc changelist said the finding changed tests and source and no design text, which is the mistake the round before it was written to correct.

The matrix of verb against whether a repository is named is sampled: `gate` with no repository, and `gate --hook`, which every pre-push runs, are not asserted, so a change that holds them to the scope would pass. One commit subject, `84c1b02`, says how the change came about and not what changed, and carries `fix` for a commit that only adds tests. Two doc comments describe the round that wrote them. Smaller matters: a test name differs from the one an earlier topic promised, `config.rs` is past 500 lines, and `ureq`'s `tls` feature still compiles in `webpki-roots` that nothing uses.

## What the round decides

The design gains the sentence about the text for an empty store. The scan reports an alias of `Agent` and a braced alias, the control plants both, and the module doc says what is enforced and no more. The "names none" test takes `gate` and `gate --hook`. The two doc comments say what the code does. The mutation script gains a row for the alias and for the `gate` hold, and its log is its own output.

The commit subject is fixed by recutting the branch under a new name with the message reworded, since a pushed message cannot be edited. The test name, the length of `config.rs` and the unused `webpki-roots` are not this round's: they are filed as tickets and carried forward.
