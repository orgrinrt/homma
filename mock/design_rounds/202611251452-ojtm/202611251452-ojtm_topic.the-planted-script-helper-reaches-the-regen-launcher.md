# the-planted-script-helper-reaches-the-regen-launcher

Extends round 202611251443-nfvz. A second review found two more test helpers that write a script in
the test process and then run it: the regen tests' stub launcher, in a file that round touched, and
the hook and wrapper the aggregate wrapper tests write and make executable, with their neighbours
in the aggregate, declared and dispatch tests.

## The regen stub launcher

Decision: it plants its script through `cmd::planted::script`, so no helper in the regen tests
writes a script of its own.

## The scope of the decision

That round said every helper of the binary's tests that writes a script it runs calls the one
helper. It holds for the helpers it names; the aggregate family writes its hooks and wrappers
through `make_executable` after a plain write, across several files and shapes. Decision: this
round states the scope as the helpers named in the two rounds' changelists, and the aggregate,
declared and dispatch tests move to the one helper as a separate piece of work, filed on its own.
