- CHANGE: `run` returns `(Option<i32>, String)` from `out.status.code()` rather
  than `(bool, String)` from `out.status.success()`. `None` is a signal death
  and is a failure wherever it arrives; nothing in this file kills the child, so
  it never should.
- CHANGE: the three existing arms assert the code. `Some(1)` where the check ran
  and found the repo owing a config, `Some(0)` in the two that expect a pass and
  in `init`.

  the split exists for. The workspace is built with a `homma.toml` carrying no
  `[workspace]` table, which is what the previous round's changelist recorded as
  failing to parse, and the assertion is `Some(2)` with `1` named in the message
  as the answer that would send somebody to `init` over a fault `init` shares.
- KEEP: every message assertion. The wording is asserted where it is built and
  this file's opening already says so; what changes is only that the code it
  claims to read is now read.
