# src changelist

Doc changelist: `202611230020_changelist.doc.lock.md`.

## mock/crates/homma-core

- `src/release/writes.rs`: `Merge` and `ReleaseForge::drop_branch` are gone; `ReleaseForge::land` takes no `how`, is the release pull request and always a merge commit; `ByRoute` asks `forge_route pr <root> <head> <base> <title> merge <sha>`, `ByClient` still refuses with `NoPullRequest`.
- `src/release/landing.rs`: `push_bump` pushes the trunk and returns the commit, a refusal stopping the run with git's words; `bump_branch`, `drop_squashed` and `squash_of` are gone; `Pending` loses `squashed`; `set_aside` takes only the clone's own bump one past the remote's tip, or the remote's tip itself; `resume_bump` pushes a `Local` bump and takes any other as it is.
- `src/release/run.rs`: `Left` is gone and `ReleaseError::NotLanded` carries the trunk's untagged `tip`; `step_bump` calls `push_bump` with no version.
- `src/release/run_pr_tests.rs`, `run_resume_tests.rs`, `run_tests.rs`: a refused `dev` stops the run with no pull request and no branch beside `dev`, by the client as by the route; the stop leaves the bump on `dev` and a rerun pushes that commit; the pull request the route opens is `dev` into `main` alone; a bump the trunk already holds is taken without a second push; a squash of the clone's bump on the remote is no landing of it; the squash, branch-deletion and trunk-interloper tests and their fakes are removed.

## mock/crates/homma-engine

- `src/cmd/release/record.rs`: `green_for`, the newest recorded run on a sha where it is green.
- `src/cmd/release/gating.rs`: the pre-push hook takes a tip's recorded green run instead of measuring the tip again; a gate run by hand measures.
