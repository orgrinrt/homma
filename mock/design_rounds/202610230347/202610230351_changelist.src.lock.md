## CHANGE: `homma_core::local::fill` and `parse_stored` FROM absent TO present
File: `mock/crates/homma-core/src/local.rs`
`fill` adds to a file's text every key a stored config has and the file lacks, returns the
dotted path of each, and changes no key the file has; lists are values and are not merged
into. `parse_stored` parses a stored config and refuses one whose `instance.work` is not its
name, through the new `LocalError::StoredWork`. `STORE_DIR` names `.shared/local`.
Verification: `fill_adds_every_key_the_file_lacks_and_names_each`,
`fill_never_changes_a_key_the_file_has`, `fill_keeps_what_a_tool_recorded_and_the_store_never_held`,
`fill_keeps_the_files_own_comments`, `fill_of_a_complete_file_adds_nothing_and_changes_no_byte`,
`fill_refuses_text_that_is_not_toml` and `a_stored_config_is_the_one_its_name_says` in
`mock/crates/homma-core/src/local_tests.rs`. Run against copies of the module with a stored
value overwriting an existing key (two tests failed) and with the work check removed (one failed).

## CHANGE: module `cmd::local` FROM init, show and set TO those and `list` and `install`
File: `mock/crates/homma-engine/src/cmd/local.rs`
`install` copies the stored file byte for byte where there is no file, under the lock `set`
takes and through a temporary file renamed into place, and ignores the file as `init` does.
Where a file for the same work exists it fills; for another work, a file that does not parse
or a link it refuses, and with `--replace` moves it to `homma.local.toml.replaced`, refusing
if that name is taken. A name outside letters, digits, `-` and `_` is refused, and an unknown
one is refused with the names there are. `list` returns the stored names sorted with their
titles, the reason for each unusable file, and the work the installed file has.
Verification: nineteen tests in the module's `tests`, among them
`install_copies_the_stored_config_byte_for_byte_where_there_is_no_file`,
`install_ignores_the_file_it_made`, `install_leaves_no_lock_or_temporary_file_behind`,
`what_a_tool_records_after_the_install_never_reaches_the_store`,
`a_link_does_not_survive_the_first_write_which_is_why_install_copies`,
`install_over_the_same_work_adds_what_is_missing_and_changes_nothing_else`,
`installing_twice_is_the_same_as_once`, `install_over_another_work_refuses_and_touches_nothing`,
`replace_moves_the_old_file_aside_whole_and_installs_the_stored_one`,
`replace_refuses_to_overwrite_an_earlier_replaced_file`,
`install_over_a_link_refuses_until_replace_and_then_leaves_the_target_alone`,
`a_name_that_could_leave_the_store_is_refused`, `list_names_the_stored_configs_sorted_and_marks_the_installed_one`
and `list_shows_an_unusable_stored_file_instead_of_hiding_it`; and five through the binary in
`mock/crates/homma-engine/tests/local_install_smoke.rs`. Each was run against a copy of the
source with the behaviour removed, and failed: the ignore line not written, any name accepted,
the same-work check always true, the aside overwrite allowed, the link refusal removed, the
sort reversed, the installed mark removed, a write made through the path instead of a renamed
temporary file, the install made a link, the install made by re-serialising (comments lost),
the fill skipped, the old file deleted instead of moved, `list` without a store exiting 0 and
the document's `installed` always false.
