# tests-read-claude-shook-s-registration-as-it-is-now

A review of git-shook's chain-3 had claude-shook's registration run the front by the absolute path the install
resolved, `f='<path>'; [ -x "$f" ] || f=$(command -v claude-shook) || { ... }; exec "$f" run <Event>`, in place
of `exec claude-shook run <Event>`, so a host whose `PATH` lacks the front still runs every guard.

Two of homma's tests spell the old command: the settings sweep keeps a claude-shook registration as somebody
else's, and the real-front smoke test finds claude-shook's registration by the words `exec claude-shook run`.
Decision: both read the shape as it is now. No design text names the command's words, so no document changes.
