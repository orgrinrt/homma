# src changelist

Answers the doc changelist `202610271153_changelist.doc.lock.md` of this round, topic `hooks-chain-through-git-shook-and-read-every-layer`.

## Current state before the round

`Config::from_path` read `[hooks]` and `[agent.hooks]` from `homma.toml` alone. `homma hook install` reported `Reach::Shook` as not reached where `core.hooksPath` was git-shook's, and the tracked `shook.toml` was the only registration, static, naming `pre-commit` and `pre-push`.

## Changes

- `homma-api`: `layers.rs` holds `Layers`, the validated ordered list of `homma.<name>.toml` overlay names, with `homma.local.toml` as the default. `Hooks::append` and `AgentHooks::append` add another layer's entries after the existing ones and replace none.
- `homma-core`: `layers.rs` reads an overlay for the two hooks tables, applies the named overlays in order, and surveys the root for files that are read, absent or never named. `Config` gains `layers`, `layer_errors` and `layers_dir`; `from_path` applies the layers, and a layer that cannot be read is carried on the config and does not stop the load. `Local` accepts `hooks` and `agent` untyped so `homma.local.toml` may carry them.
- `homma-core`: `hooks/shook.rs` generates `shook/manifests/homma.toml` in the common git directory from every event of the merged table, runs `git shook install --yes`, and reports each event as reached when homma's entry is registered. `hooks/install.rs` splits `Reach::Shook` into registered and `ShookUnregistered`, adds `Via` and `install_via`, and `HookError::Shook`.
- `homma-engine`: `homma hook install` takes `--shook`, a new `homma hook doctor [repo]` reports the overlay files read, absent and stray and, with a repository, how git reaches each event, and `hook install` and `hook run` refuse while a layer cannot be read.
- `shook.toml` and `README.md` follow the code.
