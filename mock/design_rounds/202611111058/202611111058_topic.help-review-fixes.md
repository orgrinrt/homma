# help-review-fixes

A reviewer of the help-lists-the-tools work returned merge after fixes. Findings: the rendered `docs/DESIGN.md` lacked the suggestion paragraph; a capitalised word of a name (`Status`) got no suggestion though the design says case is no difference; bare `homma` prints help but got no `Tools:` section; a test named for a tie used a word near nothing; the flag reader missed `-c=path` and `-cPATH` and took the first of repeated flags where clap takes the last.

## Changes proposed

- Bare `homma` with no arguments counts as asking for help.
- Only an exact match of the word with a name is no suggestion; a case difference still suggests.
- The flags `--config`, `--dir` and `-c` are read in the spellings clap accepts, and the last occurrence wins.
