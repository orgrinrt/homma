# Changelist: src — adopting mockspace

**Round:** 202608140100 adopting mockspace
**Phase:** IMPL
**Scope:** re-rooting the Cargo workspace under `mock/`

Nothing in this changelist edits a line of Rust. Every entry is a relocation, and
relocations pass through a source window because the gate reads a moved file as a
modified one, which is correct: a path that resolved before does not resolve
after.

## CHANGE: move the Cargo workspace under `mock/`

`crates/` becomes `mock/crates/`, `Cargo.toml` becomes `mock/Cargo.toml`, and
`Cargo.lock` becomes `mock/Cargo.lock`.

This is the shape every sibling repository in the workspace already has: the
repository root carries configuration, licence, readme and toolchain pin, and the
Cargo workspace lives under `mock/`. homma was the only member still holding its
crates at the root, which is the pre-adoption shape rather than a decision.

**Verification:** `mock/Cargo.toml` declares `members = ["crates/*"]`, which is
relative to its own manifest, so the member glob resolves unchanged and no
manifest edit is required. `cargo check` from `mock/` builds both crates.

## CHANGE: copy the toolchain pin to `mock/`

`rust-toolchain.toml` stays at the repository root and is copied to
`mock/rust-toolchain.toml`, because the Cargo workspace is now rooted there and a
toolchain pin governs from the directory a build starts in.

**Verification:** both files exist and carry the same channel.

## CHANGE: no source edits

**Verification, and the first form of this claim was false.** It said every path
in the changeset is a pure rename, which is not true of a changeset that also adds
templates and round files. The claim as it should have been written, and as it was
then checked:

```
$ git diff --cached -M --numstat | grep -E 'mock/crates|mock/Cargo' \
    | awk '$1!="0"||$2!="0"'
(no output)
$ git diff --cached -M --summary | grep -c '^ rename'
36
```

**36 files move and not one of them changes a line.** Everything else in the
changeset is a new file.

## CHANGE: mockspace appends its managed block to `.gitignore`

Generation appends a `target/` catch-all under a marked managed section. The
existing Cargo and editor entries are untouched.

**Verification:** `git diff --cached -M --numstat -- .gitignore` reports `6 0`,
six lines added and none removed.

## What this round does not do

The crate split is untouched. `homma-core` and `homma` keep exactly what they
held. Whether that split is right is the taxonomy round's subject, and the
`layers` key in `mockspace.toml` carries a placeholder that the taxonomy round
replaces.
