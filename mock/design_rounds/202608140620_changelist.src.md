# Changelist: src — the six blocking defects

**Round:** 202608140600 what the review found
**Phase:** IMPL
**Scope:** correctness fixes across all three new crates

Every verification below was run before this was written, and each is a command
whose output is quoted rather than a description of one.

## CHANGE: one file, one schema

`homma_core::Config` gains the fields `homma_api::Workspace` requires, so the two
parsers stop denying each other. `deny_unknown_fields` stays, because it is worth
having; what changes is that the fields are known.

**Verification:** `homma status` against a config carrying `content_repo`, `paths`
and `org`.

## CHANGE: refuse to stand up a role that owns no workspace

`Identity::missing()` reported nothing for a King, a consultant or a general, so
`stand_up` built one a definition and a twin. Under `op` that manufactured a
dispatchable agent for the human, holding the one handle that derives a ratified
standing.

Now `stand_up` refuses any role whose `has_workspace()` is false, and `prepare`
creates a memory directory only where `has_memory()` is true.

**Verification:** `homma org up op` refuses and names why; a general gets no
memory directory.

## CHANGE: registry strings cannot inject frontmatter

A newline in a nickname or a domain wrote arbitrary YAML keys into a generated
definition, which let a Hand grant its own twin `memory: project` by editing its
own entry. Registry strings are now rejected at parse if they carry a control
character.

**Verification:** a nickname containing a newline is refused by the parser, and a
test asserts the twin's rendering carries no memory key under an injection
attempt.

## CHANGE: a kind name cannot escape the store root

`Store::path_for` interpolated the name into a path and `create_dir_all` made
traversal succeed. A kind named `../../escaped` wrote two levels above the root.
Names carrying a separator or a parent component are refused.

**Verification:** a test asserts the traversal name is refused and that nothing is
written outside the root.

## CHANGE: an append-only kind cannot be contradicted by a duplicate id

`append` enforced no uniqueness, so a second record under an existing id was
accepted and the append-only guarantee could be bypassed without touching the
guard that refuses rewrites.

**Verification:** a test asserts the duplicate is refused for both mutabilities
and that the original is unchanged.

## CHANGE: a missing character is absence, not any error

`read_to_string(...).unwrap_or_default()` swallowed every failure. Only
`NotFound` is absence now; anything else propagates.

**Verification:** a test makes `character.md` a directory and asserts
`write_definitions` reports it rather than shipping a voiceless Hand.

## CHANGE: delete four tests that constrain nothing

Each passes with its subject deleted, which is the definition of a test that
lies about coverage. Two assert a constructor stored its argument; one compares
two path builders; one asserts a declaration against itself. Removed rather than
improved, because no test is better than one that inflates a count.


## The verifications, run

```
$ homma status                       # was: unknown field `content_repo`
workspace: clause-dev (/Users/orgrinrt/Dev/clause-dev)

$ homma org up op
error: `op` holds a role that owns no workspace, so there is nothing to stand
up. Generating one anyway would manufacture a dispatchable agent for someone
who is not one.
$ ls .claude/agents/op.md            # nothing written
no

$ # a TOML-legal escaped newline, which the parser accepts:
$ python3 -c "...";  nickname = "Paja\nmemory: project"
'Paja\nmemory: project'
$ homma org up paja
error: the registry carries control characters in `paja`.nickname
$ ls .claude/agents/paja-twin.md     # nothing written
no
```

The injection was checked against a form TOML **accepts**. The first attempt used
a raw newline, which TOML rejects on its own, and would have proved nothing about
this fix.

`cargo test --workspace`: 185 passing, and four tests removed rather than
improved because each passed with its subject deleted.
