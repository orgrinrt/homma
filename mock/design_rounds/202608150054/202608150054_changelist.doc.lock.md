# Doc changelist: two claims that are not true

## CHANGE: `homma-org/DESIGN.md.tmpl`, the workspace-refusal paragraph

It says the property that matters is "that creating one never writes into a tree
belonging to somebody else, which is what the deny list forbids and what a
relative `..` or a plainly absolute path both reach". A review produced the
counterexample using both spellings the sentence names.

Replaced with what the code enforces after this round, plus the case it still
does not: a workspace already sitting inside a home directory.

## CHANGE: `README.md`, the sentence about directories

"The directories, definitions and memory link it writes inside the workspace go
through a path proven against the filesystem" is a totality over directories, and
the gen pass creates directories inside the workspace with bare paths and
swallowed errors. The gen-pass surface was agreed out of scope conditional on
this sentence being honest, so it is made honest rather than the condition being
quietly dropped.
