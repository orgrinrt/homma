# the-agent-status-document-drops-its-two-deprecated-fields


The fourth fresh read of the branch found that the agent status document keeps `mock_agent_dir` and `cargo_mock_alias` as deprecated fields, and that this is the shape the rule on legacy shims before 1.0 forbids: the old shape is deleted, not deprecated. The design sentence that kept them, that the document grows fields rather than changing shape, was ranked above that rule by an agent and carries no ratification by the lead designer. The coordinator, asked with both options, ruled the other way: delete both fields from the document, the probes, the status fixture and the design sentence. No consumer of either field exists in the workspace's shared data, tools, scripts or rules.

Both fields go. The design paragraph no longer promises that the document only grows, and says what it holds.
