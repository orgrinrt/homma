# A partition kind has its own name

Found by the push gate on the branch of round `202610270410`: the `single-source/type` lint refuses `Kind` in `homma-core/src/milestone/range.rs` because `homma-api` already defines a `Kind`, and one name has one definition. The type is the milestone partition's source-or-document split. It is renamed `PartitionKind`. The design names no type here, only the prose word kind, so it needs no change.

The three older open topics are named in the changelists and need nothing from this round.
