# Doc changelist: stop describing a different program

## CHANGE: `README.md`

**Three advertised features do not exist.** Opening pull requests, applying
branch protections, and enforcing conventions on commit and PR text. `homma
--help` lists `status org verify repo forge agent docs migrate archive`, and a
grep for `pull_request`, `branch_protection`, `ruleset` and `protection` across
every crate returns nothing. This is the repository's public face and it is
wrong about what the program does.

**The changelog note about a previous version of this file comes out.** A
stranger landing here has no use for what an earlier draft said; the correction
is the current text.

**The aggregation paragraph is rewritten**, because the previous round's account
of it was wrong twice: it said the writes were refused where they were not, and
it said the central clone was unchecked where the code refused it.

"One required key names the content repository" is contradicted by this branch's
own change to the per-crate document, which says no key is required and `local`
is the default, and by the code, where a registry with no `content_repo` parses
and runs. The root template was never touched, **which is the case that hides
best**: a reader of the crate document sees the correction and a reader of the
workspace document does not.
