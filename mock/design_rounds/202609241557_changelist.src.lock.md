## CHANGE: module `homma_core::local` FROM absent TO `pub mod local`
File: `mock/crates/homma-core/src/local.rs`
Verification: `grep -c "^pub mod local;" mock/crates/homma-core/src/lib.rs` returns 1.

The module holds `LOCAL_FILE`, the types `Local` and `Instance`, `skeleton`,
`set`, `ensure_ignored` and the error `LocalError`. `Instance` types `work`
(required), `title`, `repos`, `state` and `goal`; `Local::tools` is a map of
untyped tables. Both deny unknown fields. `set` accepts `instance.<key>` and
`tools.<name>.<key>` only, edits through `toml_edit` so comments stay, and
refuses a result `Local::parse` rejects.
