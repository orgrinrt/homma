# doc changelist

Answers topic `202609242045_topic.capture-agent-fields-rounds-and-session.md`,
the only open topic.

## Current state

The capture paragraphs of `mock/DESIGN.md.tmpl` name the store as a fixed
directory overridable only per run, default to the newest transcript in the
workspace's project directory, read any tool result with `answers` as an ask
round, write the agent's one-line fields as they arrived, say nothing about a
capture's place beside the record store or its `tags`, and say nothing about how
a title becomes a file name.

## Changes proposed

- The store is `[paths] captures`, defaulting to `.data/op-responses/`, with
  `--into` for one run.
- The transcript is `--session`, else `CLAUDE_CODE_SESSION_ID`, else the newest.
  An id is looked for in the workspace's project directory and then in every
  other one, and an id found nowhere is refused.
- A tool result is an ask round only when its `tool_use_id` names an
  `AskUserQuestion` call on an earlier assistant line.
- The title, a header and a label are written with line breaks spelled `\n` and
  carriage returns `\r`.
- A capture is prose in a generated file, written for the voice tool, and not a
  record; the watermark is read back out of the files. `tags: [chat]` is named.
- The file name folds `ä` and `å` to `a` and `ö` to `o`.
