# Source changelist: the gate measures the commit it is given

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609030500_changelist.doc.lock.md`

## `homma-engine`

### `src/cmd/release/gating.rs` (modify), `tests/cli_release.rs` (modify)

CHANGE: `--sha` resolves the commit it names and gates it through `run_gate_at`, so a commit other than the head is measured in a worktree rather than refused; a commit that does not resolve is refused naming it. A smoke test asserts a sha the repo does not have is refused before anything runs.

## `homma-core`

### `src/release/run_tests.rs` (modify)

CHANGE: the release test asserts the forge release body is the block written to `CHANGELOG.md`, verbatim.

### `src/forge/github.rs`, `github_tests.rs` (modify), `github_wire_tests.rs` (new)

CHANGE: the tests that stand up a listener move to `github_wire_tests.rs`, and a test there posts a release through `create_release` and asserts the path, the credential and the tag, name and body fields.
