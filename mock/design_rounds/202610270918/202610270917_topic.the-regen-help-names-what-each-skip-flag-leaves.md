# the-regen-help-names-what-each-skip-flag-leaves

`homma agent regen --help` says `--skip-aggregate` just reruns `cargo mock` and `--skip-cargo-mock` only runs the workspace aggregation. The code runs three stages and each skip flag leaves the other two running: the shared tool configs are still placed under either flag, and `--skip-aggregate` also skips writing the commit gate, the declared hooks and the settings merge, which sit after the loop beside the aggregation. The design is silent on the flags, so the help text is the only place the claim lives.

The help is rewritten to say what each flag leaves, and the root readme row for `homma agent` says the shared configs are placed in every member on disk, not only the adopted ones.
