# what-readme-fix-first

A pr-reviewer pass over `work/what-answers-tool-questions` returned fix-first. Four findings reach the design or the code. The insertion of the readme paragraph into the tools source deleted "These exist on unix only," from the sentence that ends "since renki builds there only", so the clause dangled. The limits `readme` keeps, 80 usage lines and 24000 characters of prose per tool, were in the changelist and not in the design. The test meant to show that a command the descriptor declares is not read twice from the readme used a bare `msg` line, which the reader drops before it reaches the de-duplication, so the test passed without exercising it. The README's `homma what` row did not say tool readmes are read.

The design is amended to restore the sentence and state the limits, and the test declares `show` in the descriptor and uses `msg show  x` in the readme, which is the line the de-duplication meets. The closed round's topic file, still flat beside the open round, is moved into the round's directory.
