# release-gate-run-after-set-aside

Ticket `9c6f24448200`.

## What was found

- `homma release run` looks the gate run up by the local trunk's sha before the core runs. The core then sets
  aside a release bump a stopped run left on the local trunk, which can move the trunk to origin's tip, and step
  2 compares the run with the trunk as it is after that.
- With a leftover local bump on top of origin's tip, the lookup is keyed on the bump, finds nothing, and step 2
  refuses with no gate run on the tip, though `homma release gate` recorded a green run on that tip.

## What changes

- The core is given a source of gate runs by sha, not a run found beforehand, and asks it for the sha step 2
  measures, after the set-aside. The engine supplies the store-backed lookup, so the core stays free of the store.
- A run handed in directly still works for a caller that has one, and step 2 still compares the run's sha with the
  trunk's.
