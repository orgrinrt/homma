# Src changelist: a root declaring sets drops its members

## crates/homma-core/src/release/gate_tests.rs

- CHANGE: `a_root_declaring_sets_still_builds_its_members`, red and ignored with
  a `catalogue:` reason naming the gap and pointing at the topic. A workspace
  whose root is a package declaring two sets, with one member declaring none.
  The assertion is that the member is reached, by a `--workspace --exclude`
  run beside the per-set ones, which is the shape the `None` branch already
  emits. It states the intended behaviour rather than the present one, so it
  turns green if that reading is chosen and is deleted with a sentence if the
  other is.
- KEEP: `a_root_package_keeps_its_bare_runs_beside_a_declaring_member`, which is
  the mirror case, a root declaring nothing beside a member declaring sets, and
  passes. Having both beside each other is what shows the asymmetry is in the
  code rather than in the fixture.

## crates/homma-core/src/release/gate.rs

- CHANGE: a `FIXME` on the `Some((_, sets))` arm naming what it drops and
  pointing at the ignored test, per `mark-placeholders-fixme.md`. The prose
  above it describes the root and says nothing about members, so a reader
  arriving at the arm has nothing telling them the case is open.
- KEEP: the behaviour. Which of the two readings is right is not this round's to
  settle, and changing it quietly would be the same defect pointed the other
