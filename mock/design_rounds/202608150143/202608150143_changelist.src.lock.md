# Src changelist: two identities in one clone

## CHANGE: `Identity` gains `committer_email`

Optional. Absent means the committer is the author, which is every ordinary
entry; present means the two differ, which today is Vouti alone.

## CHANGE: `Git::set_identity` takes an author and a committer

`user.name`, `author.email` and `committer.email`, so one clone can carry two
identities. The gix implementation writes all three into the clone's own config.

## CHANGE: the test asserts the commit, not the config

A real commit is made in a provisioned workspace and read back for its author and
committer. Asserting the config would assert the mechanism; a config write that
never reaches a commit is the defect this unit exists to prevent, and that exact
defect shipped once already on the neighbouring branch.
