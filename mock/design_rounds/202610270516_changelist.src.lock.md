# src changelist

Answers `202610270505_topic.what-the-surface-lines-ask-of-a-repo.md`, through the locked doc changelist `202610270505_changelist.doc.lock.md`.

## Current state

The design now states what the agent surfaces ask of a repository and that the line reporting a config difference names its two ways out. The code asks for a `.cargo` alias and a `mock/agent/` directory, probes a literal `mock/`, reads only a root `mockspace.toml`, lists a repository with no mockspace as missing four directories, and reports a difference with no next step.

## Changes proposed

- `crates/homma-engine/src/cmd/agent.rs`: `Surfaces` loses `mock_agent_dir` and `cargo_mock_alias` and gains `mockspace_toml` and `mock_dir_name`. `probe` reads the mock directory the `mockspace.toml` declares, found at the root or under `mock/`. `roll_up` returns not configured for a repository with neither a `mockspace.toml` nor its mock directory, and asks an adopted one for the mock directory, `.claude/`, `.github/instructions/` and the hook wiring. `has_cargo_mock_alias` is deleted with its two tests, and the human render drops the two retired fields. The not-configured state is labelled "no mockspace".
- `crates/homma-engine/src/cmd/status.rs`: `render_agent` keeps a not-configured repository out of the summary and names it under `--full`, and prints `homma agent regen` after any line about a missing surface. `missing_surfaces` names the declared mock directory.
- `crates/homma-org/src/configs/mod.rs`: the `Differs` line names putting the shared copy back and adding a variant.
- Tests beside each: `agent.rs` gains seven over fixture repositories, `status.rs` three, `configs/tests.rs` one.
