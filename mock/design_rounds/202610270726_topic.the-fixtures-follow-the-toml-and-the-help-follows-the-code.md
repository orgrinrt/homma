fixtures that carry no `mockspace.toml`, so since the drift check applies only
to a repository with one they never reach what they claim to hold: the
git-shook hooks path comparison, and the legacy alias counting as the config
marker. Mutating either behaviour left the whole gate suite green. A third is
now the same assertion as the no-toml test. The fixtures get a toml with no pin.

directory and `mock/agent/` templates, and that regen has two stages. It says
what the code does now. Two comments say the toml is looked for under the mock
directory where the code looks under `mock/`, and the gate's awk guard that
stops at the first table has no test.

Left alone: `homma agent status` still prints the probed surfaces for a repo
not on disk and for one with no mockspace, where `homma status` names them. The
design speaks of the summary, so the detailed command is unchanged in this
round and noted for the next.
