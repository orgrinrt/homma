# doc changelist: what a carried hook is handed

## Current state

`mock/DESIGN.md.tmpl`, `## The agent hooks`, says where a call lands and that a
wrapper hands off to the hook, and is silent on where the hook then runs and
what it is handed. It calls an over-fire the cost of a process, which holds only
for a hook that observes. It says a runner is whatever precedes the hook's path,
with nothing on a runner that is a line of shell. It says nothing on a file path
that climbs.

## Changes proposed

### `mock/DESIGN.md.tmpl`, `## The agent hooks`

- A file path that climbs with `..` lands everywhere, as a command's piece does.
- An over-fire costs a process for a hook that observes and a false refusal for
  one that denies, with `echo engine` as the case.
- A new paragraph: a carried hook runs in the session's directory and is handed
  the payload as the host sent it, with the reason (a relative path in the
  payload is relative to that directory), and a hook scoping itself by its own
  working directory declines a call typed elsewhere whatever the wrapper did.
- A runner that is a line of shell, an assignment or a separator, is reported by
  path and not carried, with `cd dir && ...` as the case.
