# The release errors fit the gate it runs

**Date:** 2026-09-03
**Phase:** TOPIC
**Scope:** `homma-core/src/release/{plan,run,git}.rs` and their callers
**Source topics:** the tenth review of pull request 46, and `202609030350/202609030350_topic.a-failed-push-of-main-leaves-no-merge-behind.md`

## The findings

The gate runs clippy with warnings denied, and the release's own error types fail it: `PlanError::OffLevel` carries three versions inline, which makes every result carrying it larger than clippy allows, at nine sites in the files this branch wrote. The tool refuses to release its own repository at step two for want of a green run. The off-level payload moves behind a box, which is what clippy asks for and costs nothing on a path that ends the run.

The bound on `ls-remote` is a low-speed limit on http, and every remote in this workspace is ssh, so it bound nothing the tool takes. The call also carries an ssh command with a connect timeout and keepalives, where the caller's environment does not already name one, and the comment says which transport each covers.

A doc comment landed on the wrong function when `reset_hard` was inserted; each function carries its own.

The design.
