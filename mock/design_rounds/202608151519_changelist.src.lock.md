# Src changelist: ship the cheap half, pin the disjunct, fold correctly

## CHANGE: `mock/crates/homma/src/cmd/agent.rs`

**`regen` refuses a workspace whose `.claude` is the operator's own.** With
`workspace.path = $HOME` it wrote two mode-`0755` scripts into `$HOME/.claude/hooks/`
and rewrote `$HOME/.claude/settings.json` to register them as `PreToolUse` hooks,
at exit 0. Deny item three verbatim, installing code the harness then executes,
beside the credentials the record names.

Ten lines, before any repository is walked. **The workspace's own `.claude` is
what is checked**, not the workspace, because a workspace is allowed to be almost
anywhere and it is the aggregation target that must not be a home's. Both halves
of that are pinned: `regen_writes_smoke.rs` fails when the check is removed and
fails again when it is pointed at the workspace instead.

It was unpinned when first written, and the sweep is what caught it. Which is the
seventh time on this branch that a guard shipped with nothing holding it, and the
first where the sweep caught it before a reviewer did.

**The central-clone case is deliberately not checked here**, and the previous
round's error was bundling it with this one. Aggregating into a checkout is the
gen pass's purpose, `~/Dev/clause-dev/homma.toml` ships
`path = "/Users/orgrinrt/Dev/clause-dev"`, and refusing it forbids the tool its
purpose. That needs a decision about who homma is acting as, which is not
derivable here.

## CHANGE: `mock/crates/homma-api/src/denied.rs`

**Folding through uppercase and back**, replacing `to_lowercase`. Not a
refinement: `straße` against `STRASSE` and `Σigma` against `ςigma` are each one
directory on this filesystem and lowercasing alone answers no to both.

**The comparison goes from two disjuncts to one**, and that is the sweep's own
finding rather than the review's. The review reported the second disjunct as live
and unpinned. Mutating the **first** alone also left the suite green, which is a
different result: `folded` handles ASCII case too, so `eq_ignore_ascii_case` was a
fast path wearing a guard's clothes and no test could ever have failed for its
absence. It is deleted rather than pinned.

Both were missed because **a compound condition replaced wholesale is one
mutation, not two.** Mutating the whole `Normal` arm caught the arm and said
nothing about either half, and the claim that every guard was checked by deletion
was written from the arm's result.

The `FIXME` stays and is now true as written rather than approximately: NFC
against NFD is what remains.

## CHANGE: `mock/crates/homma-api/src/contained.rs`

`a_symlink_cycle_is_reported_rather_than_looped` is `let _ = root.contain(..)`.
The name says reported and the body passes whether it reports or returns `Ok`.
`contain` does return an error today, so the assertion was available and was not
written.

## CHANGE: `mock/crates/homma-api/src/path.rs`

`MAX_HOPS` is pinned, and it is the worse kind of unpinned: raising it to 100000
keeps the suite green, and **removing it hangs the suite rather than failing it**.
A guard whose absence hangs is undetectable on an unattended run, which is where
this work happens. The test asserts the error rather than the ceiling's value, so
the number stays tunable and its existence does not.
