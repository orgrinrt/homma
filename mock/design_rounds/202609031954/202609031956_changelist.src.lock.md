# Source changelist: the review's findings on the hooks table

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609031954_changelist.doc.lock.md`

## `homma-api`

### `src/hooks.rs` (modify)

CHANGE: `HookEntry` FROM public `run` and `paths` fields TO private fields
behind `HookEntry::new`, which refuses a glob that does not parse and a blank
command as `InvalidHooks::Glob` and `InvalidHooks::Empty`, with `run()` and
`paths()` accessors and the compiled globs kept beside the strings; the
manifest's deserialisation goes through it, so a bad row is refused naming
its event through serde's own path. `Hooks::new` checks events alone.
`STDIN_EVENTS` names the events git hands stdin to.
Verification: `grep -c "pub fn new" mock/crates/homma-api/src/hooks.rs` is
2; `grep -c "STDIN_EVENTS" mock/crates/homma-api/src/hooks.rs` is at least 2.

## `homma-core`

### `src/hooks/install.rs` (modify)

CHANGE: `Reach` FROM one verdict per install off the path's spelling TO one
per event, `Direct`, `Chained(file)`, `Missing(file)` or `Foreign(file)`,
decided by `reach(root, event)` off the file at `<core.hooksPath>/<event>`
carrying `MOCKSPACE_MARKER` in its first lines; `Installed` holds `Written`
rows of event, path and reach, and `reached()` is all of them.
`HookError::HooksPathTracked` and the tracked-directory check go. Tests pin
the per-event reach, a path spelled like mockspace's with nothing in it, a
relative path, and the foreign and missing cases through the install.
Verification: `grep -c HooksPathTracked mock/crates/homma-core/src/hooks/install.rs` is 0.

### `src/hooks/run.rs` (modify)

CHANGE: `touched` reads the index FOR `pre-commit` and `commit-msg` only,
nothing for `post-commit` and `pre-merge-commit`; the hand-rolled `pre-push`
replay test goes, its property held by the `pre-commit` case through `run`.

## `homma-engine`

### `src/cmd/hook.rs` (modify)

CHANGE: `install` prints one line per entrypoint with its reach and exits
non-zero where any is unreached; `run` reads stdin only for an event in
`STDIN_EVENTS`.

### `tests/cli_release.rs` (modify)

CHANGE: the install test drives the missing, foreign and mockspace cases
through files under the hooks path rather than the path's spelling.

### `README.md` (modify, not gated)

CHANGE: the command table names `homma hook <op>` and says what `status`
reports about hooks.
