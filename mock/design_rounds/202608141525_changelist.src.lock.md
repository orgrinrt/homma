# SRC changelist: join descends, resolve anchors

**Round:** the join round
**Phase:** IMPL

## CHANGE: mock/crates/homma-api/src/path.rs

`join` clamps a parent component at the receiver, so it cannot leave. `resolve`
is unchanged and may go anywhere, which is what a workspace field needs.

`RelPath`: relative, non-escaping, refused when the configuration is parsed.

`cwd` normalises and checks like every other constructor, closing the one hole in
the perimeter of the guarantee the type carries.

## CHANGE: mock/crates/homma-api/src/config.rs

`Paths` carries `RelPath`. An absolute or escaping value fails to parse.

## CHANGE: mock/crates/homma/src/cmd/stand.rs

Refuse a workspace under the root **before** anything is created, on the lexical
relationship, rather than after `git.init` has made it a repository. Stop citing
a deny-list item the record says was never written down.

## CHANGE: mock/crates/homma/tests/containment_smoke.rs

The configured-path escape, by `..` and by an absolute value, and a test that
nothing is created before a refusal.
