# Source changelist: a member's feature sets run against that member

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609030445_changelist.doc.lock.md`

## `homma-core`

### `src/release/gate.rs`, `gate_tests.rs` (modify)

CHANGE: `feature_sets` returns every declaration it finds, each with the package it came from where that is a workspace member and none where it is the root package. The tests step runs `--all-features` and `--no-default-features` workspace-wide, then each root set in place of the plain no-features run as before, and each member set as `cargo test -p <member> --no-default-features --features ...`. A test plants two members with different sets and asserts both run against their own crate and neither inherits the other's.

## `homma-api`

CHANGE: `Version`, its ordering, parsing, display and `NotAVersion` move to `version.rs`, re-exported at the same path, bringing `release.rs` under the size line. No item changes.

## `homma-engine`

### `src/cmd/release/mod.rs` (modify), `src/cmd/release/gating.rs` (new)
