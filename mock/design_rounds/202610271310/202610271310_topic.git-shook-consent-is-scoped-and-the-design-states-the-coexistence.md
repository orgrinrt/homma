# git-shook-consent-is-scoped-and-the-design-states-the-coexistence

A second review of the same branches, after round `202610271248`, found what the first did not.

## What the review found

1. `git shook install --yes` registers every manifest in the clone, not the caller's. Run from `homma hook install`, it also registered a tracked `shook.toml` that arrived through a merge, which is the case git-shook's consent model exists to stop. mockspace did the same on any `cargo mock` run whose registration was stale. git-shook gained `install --yes --only <name>`, which registers and prunes only the manifests of that name, and both callers pass their own.
2. The entrypoint homma wrote into git's own hooks directory before a repository moved to git-shook stays there, and mockspace's gate chains to it, so the table ran twice. The install removes it when it is exactly the text homma writes.
3. `homma hook doctor <repo>` counted an entrypoint as reached from the absence of a hooks path alone, and passed in a repository where nothing was installed.
4. A broken overlay's reason is dropped: `doctor`, `run`, `install` and `regen` print that the layer does not parse, and `homma local show` prints the line and column. The changelist of the first round promised the same words.
5. `doctor` lists a file that fails to parse as read and as an error.
6. `DESIGN.md.tmpl` says mockspace owns `core.hooksPath` and homma writes into git's hooks directory and nowhere else, and the release deep dive says the install writes one entrypoint per event. Under git-shook neither holds, and the order of the entries was not stated.

## What this round does

- The install states the consent: `--yes --only homma`, so running the verb is consent for homma's manifest and for nothing else.
- The install states that it removes its own stale entrypoint when it registers.
- The design states how homma, mockspace and git-shook coexist, and the order the entries run in: sorted by name, so mockspace's `00-mockspace` first, then homma's, with a hook git-shook kept as `00-existing` ahead of both.
- `doctor` with a repository fails where an event has no entrypoint, and names a file once.
- A layer's error keeps its cause.
