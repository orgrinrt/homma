# src changelist

Descends from `202611281607_changelist.doc.lock.md`, and through it from `202611281606_topic.a-member-on-a-version-line-of-its-own.md`.

## CHANGE: the release's lines FROM one per repo TO the repo's and each member's own, read off its `release.toml`
File: `mock/crates/homma-core/src/release/lines.rs`, `mock/crates/homma-core/src/release/lines_tests.rs`
Verification: `own` lists the members whose directory's `release.toml` says `shared-version = false` and no other; `tag` and `tag_version` name and read `<crate>-v<version>` and read no other crate's tag; `read` and `moving` give each own line's last own tag, its version there and now, its commits touching its directory and its block, refuse a changed own line that did not move (`OwnUnmoved`) and a move of more than a step; `strip` takes own lines out of a set's riders and names a primary declared so; `findings` reads `reg.orphan`, `reg.unpublished` and `man.current.forward` against the own tags. `lines_tests.rs` covers each, and the check's own tests there failed before the check read own lines.

## CHANGE: the plan FROM one repo version at a required target TO an aim, the repo's line at a target or the own lines alone, with every moving own line beside it
File: `mock/crates/homma-core/src/release/plan.rs`, `mock/crates/homma-core/src/release/plan_error.rs`, `mock/crates/homma-core/src/release/git.rs`
Verification: `Aim` is `Repo(Target)` or `OwnLines`, with `From` for a target, a level, a version and an optional target; the repo's commits are those touching anything outside the own lines' directories, through `git::subjects_touching`, which `subjects` and `subjects_to` now call; `Plan` carries `repo_moves` and `lines`, `name()` and `tags()`; `OwnLines` with commits on the repo's line refuses `RepoUnreleased`, and with no own line moving `Nothing`, and so does a target with nothing on the repo's line where the repo has own lines; the publishes order every moving own line at its own version and leave out the unmoved ones. `PlanError` and `OffLevel` moved whole into `plan_error.rs`, re-exported from `plan`.

## CHANGE: the run's bump, merge, tags and forge releases FROM the repo's version TO the release's name and every line's tag
File: `mock/crates/homma-core/src/release/run.rs`, `mock/crates/homma-core/src/release/landing.rs`, `mock/crates/homma-core/src/release/run_lines_tests.rs`
Verification: `write_bump` prepends each moving own line's block to its own `CHANGELOG.md` and leaves the repo's version and block alone where its line stays; the bump is `chore: release <name>`, the merge `release: <name>`, the bump branch the name with spaces and commas made `-`; each of `Plan::tags` is made and held on the one merge, the repo's first; `step_forge_release` makes one release per tag from its own block; `Pending` carries the release's name and `subject_name` reads it back, so a stopped release of own lines alone is taken back and not bumped twice. `run_lines_tests.rs` covers the run alone and riding a level, the resume and the name; reading the name as a version only, and tagging the first tag alone, each failed three of its four tests.

## CHANGE: the check FROM the repo's tags alone TO each own line against its own, and `main` against the newest tag of any line
File: `mock/crates/homma-core/src/release/check.rs`, `mock/crates/homma-core/src/release/hygiene.rs`
Verification: the check strips own lines from the riders and pushes `man.primary` for a primary declared so; `newest_on` reads `main.unreleased` against the closest tag of any line on `main` where the repo has own lines, and the newest version tag as before where it has none; own lines are left out of the repo-tag `reg.orphan` and `reg.unpublished` and of the highest published version; `hygiene` passes over an own line's tag in `tag.stray`. `the_check_reads_an_own_line_against_its_own_tags_and_no_own_tag_is_stray` failed before these and passes after.

## CHANGE: the engine's target FROM required TO optional for a named repo

Verification: `TargetArgs` takes at most one of `--level` and `--version`; `aimed` makes `Aim::OwnLines` of neither for a named repo and refuses a run over every repo with neither; a finished run says the release's name and every tag it made. `a_release_takes_a_level_or_a_version_at_most_one_and_neither_is_none` replaces the test that required one, and `a_named_repo_with_no_level_releases_its_own_lines_and_a_sweep_names_a_level` covers `aimed`.
