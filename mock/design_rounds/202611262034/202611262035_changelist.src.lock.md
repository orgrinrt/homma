## CHANGE: the vocabulary FROM a re-read manifest and a gap TO `[what]` read from the loaded configuration, refused where it does not read
File: `mock/crates/homma-engine/src/cmd/what/vocab.rs`, `mock/crates/homma-engine/src/cmd/what/mod.rs`, `mock/crates/homma-engine/src/cmd/mod.rs`
`Vocabulary::of(cfg: Option<&Config>)` reads `cfg.what` through `WhatConfig` with the context "reading `[what]`", the way `search_config` reads `[search]`, and `Vocabulary::of_manifest` and its gap are gone. `what::run` takes the configuration and reads the vocabulary first, so a `[what]` that does not read fails the verb before anything is gathered. The dispatch loads the configuration where the manifest is there and passes none where it is not, keeping the compiled-only path.
