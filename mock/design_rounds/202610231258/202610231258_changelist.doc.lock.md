## Changes proposed

- `install` enters a table whether the file writes it as a `[table]` or inline, and reports a key added inside an inline table like any other.
- `--replace` writes the stored file beside the old one and then moves the old one aside, so a write that fails leaves the old file where it was.
- `list` shows as unusable a file whose name `install` would refuse and a file whose name is not UTF-8, as well as one whose content is refused, and its document is an empty list where there is no store, with the exit status still `1`.
