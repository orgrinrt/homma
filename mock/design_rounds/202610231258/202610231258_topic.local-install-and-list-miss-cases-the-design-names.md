# local-install-and-list-miss-cases-the-design-names

A review of the pull request that added `homma local install` and `homma local list` found three places where the behaviour is short of what `mock/DESIGN.md.tmpl` says, and a few smaller ones.

The design says `install`, where a file for the same work exists, "adds the keys it lacks and changes none it has". `fill` in `homma-core` enters a table only where both sides write it as a `[table]`. A stored `[tools.goal]` with an `objective` and an installed file that writes `goal = { active = "true" }` under `[tools]` is the case: the inline table is a table to a reader of the file, and `fill` neither enters it nor reports the key, so `objective` never arrives and `install` answers that the file already holds everything. A key under an inline table is a key like any other, and the dotted path it is reported by is the same.

The design says `list` "shows a stored file that cannot be installed with the reason instead of leaving it out". `list` accepts any file stem, while `install` refuses a name outside letters, digits, `-` and `_`. A stored `a.b.toml` is therefore listed as usable and `install a.b` is refused. The reason belongs on the entry, which is where `list` already carries a file that does not parse or is for another work.

The root `README.md`, in the row for `homma local`, runs two sentences together: the one on `install` ends without a full stop before the one that begins with `homma status`.

Three smaller things, each cheap. `list --output json` with no store prints the human line, where every other path of the verb prints a document; the document is an empty list and the exit status stays `1`. `install --replace` moves the old file aside before it writes the new one, so a failed write leaves neither under the name; the new text is written to its temporary file first and the old file moved aside only once that has succeeded. `list` skips a stored file whose name is not UTF-8, which is a file in the store that the verb says nothing about; it is shown with that as its reason.

They are filed again flat after this round closes.
