# Forgejo writes are tested on the wire too

**Date:** 2026-09-03
**Phase:** TOPIC
**Scope:** `homma-core/src/forge/forgejo.rs` and its tests
**Source topics:** the sixteenth review of pull request 46, and `202609030510/202609030510_topic.post-names-a-commit-the-way-sha-does.md`

## The findings

The design says the status write is the same shape on GitHub and Forgejo, and the GitHub client's status post and release creation are asserted against a recording listener while Forgejo's are not tested at all. Forgejo composes its path through its own `repo_path`, so that is exactly where a wrong path would go unseen. The same listener covers both writes on Forgejo, plus the not-found mapping.

## What does not change

The design and the code under test.
