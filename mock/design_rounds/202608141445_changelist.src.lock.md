# SRC changelist: containment is a property of the filesystem

**Round:** the filesystem round
**Phase:** IMPL

## CHANGE: mock/crates/homma-core/src/repo/git_impl.rs

`enclosing_repo` resolves the path as far as it exists before walking, so a
symlink cannot hide an ancestor. It recognises a bare repository, which has no
`.git` and which `exists()` therefore never saw.

## CHANGE: mock/crates/homma/src/cmd/stand.rs

Check the **root** as well as the workspace. The root is where `prepare` and
`write_definitions` write, and moving the check off it put the original defect
back there. One helper, so a third writer cannot skip it.

## CHANGE: mock/crates/homma/src/cmd/mod.rs

Resolve the root before it is used, not only for display.

## CHANGE: mock/crates/homma/tests/containment_smoke.rs

The three routes the sixth review named: a root inside another repository, a
symlink in the chain, and a bare repository as the ancestor. Plus a test that the
symlink case is refused for the right reason rather than by accident.
