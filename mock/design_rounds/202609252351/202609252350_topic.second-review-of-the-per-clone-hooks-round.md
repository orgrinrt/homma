# second-review-of-the-per-clone-hooks-round

What the second pass over pull request 70 found once round `202609252212` had
answered the first. Every earlier finding was resolved; these are what the
fixes left, and one design gap they exposed.

## The design says whose a registration is by what it names, and not how

`mock/DESIGN.md.tmpl` says a registration of homma's found in the shared
`settings.json` is swept whichever member it names. The code decides "homma's"
by shape: a command running `.claude/hooks/<repo>--<rest>`, with something on
both sides of the separator, unless a file under that name exists and homma
did not write it. So a hand-written hook named in that shape whose file this
clone lacks is swept from the shared file. That is now the ordinary state of a
hand-written hook, since `.claude/hooks/` is ignored and nothing puts one
there. No such hook exists today: every command under `.claude/hooks/` in the
workspace's shared file is homma's, and its one hand-written hook lives under
`scripts/`.

The design gains the sentence that settles it: the `<repo>--<rest>` shape under
`.claude/hooks/` is homma's namespace, and a hand-written hook takes another
name or another directory. The alternative, keeping any registration whose file
is absent, would leave every stale registration of homma's in the shared file of
a clone that never held the member, which is the case the round started from.
A test pins it.

## Smaller

- The persona value check takes only a space before `#` as a comment; YAML
  takes any whitespace, so a tab there is read into the value.
- A value that starts and ends with a quote but holds a comment between, such
  as `"a" # b "`, passes as quoted whole. It is quoted whole only where the
  quote does not recur inside.
- The folded-block fixture puts its indented line after the body rather than
  inside the frontmatter, so it does not look like what it tests.
- `docs/DESIGN.md` was not regenerated after round `202609252212` changed the
  template; it regenerates on the lifebook in this round.

  merge.
