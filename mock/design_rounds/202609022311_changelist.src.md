# Source changelist: what the third review found on the release

**Date:** 2026-09-02
**Phase:** IMPL
**Doc changelist:** `202609022310_changelist.doc.lock.md`

## `homma-core`

### `src/release/git.rs` (modify)

CHANGE: `first_parent_touching(cwd, rev, path)` lists the shas on `rev`'s first-parent walk whose diff against their first parent touches `path`, newest first.

### `src/release/check.rs`, `check_tests.rs` (modify)

CHANGE: `tag.bump.tagged` at `Error`: every commit on the release line's first-parent walk whose manifest version differs from its first parent's carries a versioned tag pointing at it. The test plants a bump commit on `main` and a bump merged in from `dev`, asserts the finding on each, and asserts it gone once each is tagged.

### `src/release/publish.rs` (modify)

CHANGE: `publish_npm` refuses with `PublishError::Io` where the user config path is not UTF-8, instead of handing npm an empty config name.

## `homma-engine`

### `src/cmd/release/mod.rs` (modify)

CHANGE: `sibling_dependency(root, siblings)` reads a member's `Cargo.toml` dependency tables and `deno.json` imports for a git url or a name naming another member, and `run_cmd` without a repo refuses when any candidate has one, naming the pair and the order to release them in. The FIXME on `release_order` names the ordering as what is left, and the ignore marker names the agenda action `homma-release-orders-repos-by-dependency`. Tests cover the refusal helper on a git dependency, a name match, a deno import and none.
