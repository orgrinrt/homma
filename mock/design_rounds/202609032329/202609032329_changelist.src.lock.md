# Source changelist: the engine workspace is clean under clippy

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609032329_changelist.doc.lock.md`

## `homma-core`

### `src/forge/github.rs`, `src/forge/forgejo.rs` (modify)

CHANGE: `get`, `post_json`, `patch_json` and `delete` FROM returning
`Result<ureq::Response, ureq::Error>` TO `Result<ureq::Response, Box<ureq::Error>>`,
with every caller unboxing before matching on a status or handing the error
to `map_ureq_error`. Nothing a caller returns changes.
Verification: `cargo clippy --workspace --all-targets -- -D warnings` from
`mock/` reports no `result_large_err`; the wire tests in
`github_wire_tests.rs` and the forgejo tests are green unchanged, which is
what says the status arms still match.

### `src/forge/github_wire_tests.rs` (modify)

CHANGE: two `assert_eq!` against a literal bool TO `assert!`, the message
kept.

### `src/config/tests.rs` (modify)

CHANGE: the inner module `tests` FROM that name TO `workspace_path_tests`,
named for what it asserts like the two beside it.

## `homma-engine`

### `src/cmd/aggregate.rs` (modify)

CHANGE: the doc comment on `is_aggregated_command` FROM two comments run
together, the first describing a function that no longer exists, TO one
comment saying what the function matches and naming
`is_retired_aggregated_command` for the shape it does not.
Verification: `grep -c "fn is_aggregated_entry" mock/crates/homma-engine/src/cmd/aggregate.rs`
is 0, and clippy reports no `doc_lazy_continuation`.
