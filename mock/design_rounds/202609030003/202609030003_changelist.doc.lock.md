# Doc changelist: a check that could not run says so

## mock/DESIGN.md.tmpl

The command surface paragraph says `homma repo config check` "exits non-zero
when something is missing that the repository is meant to have", which is now
half of what it does.

- CHANGE: state the three codes where that sentence is, since the exit code is
  the interface the gate reads and a caller cannot ask for it any other way.
  Zero is nothing to say, `1` is ran and reported, `2` is could not run. Say
  that the split belongs to the binary rather than to this command, because it
  does, and a reader who learns it here should not think it is local.
- KEEP: everything else in that paragraph, including the two-commands-not-one
  reasoning, which is unchanged.

The gate paragraph below it says the hook "refuses the same way, naming the
command that fixes it".

- CHANGE: add that it names the command only when there is one, and says the
  check could not run when there is not. A refusal pointing at a command that
  fails identically is the defect this round closes, and the design should not
  keep describing the shape that produced it.

owe which, and says nothing about exit codes; the contract being split lives at
the command surface rather than in the org design.
