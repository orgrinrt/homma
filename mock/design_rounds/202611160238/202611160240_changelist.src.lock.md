# src changelist

Topic: `202611160237_topic.release-a-virtual-workspace.md`. Doc changelist: `202611160238_changelist.doc.lock.md`.

## mock/crates/homma-api

- `src/release.rs`: `Target`, a `Level` or a `Version` named outright, with `next_from` and `From` both ways.
- `src/version.rs`: `Version::is_one_step`, a level's step from a release or the step onto `1.0.0`, a pre-release of either, and from a pre-release a later one of the same version or its release.

## mock/crates/homma-core

- `src/release/workspace.rs`: `Layout`, `Member`, `NoPrimary`; `layout` reads a virtual workspace's primary (the member named as the root's directory, else the one publishable member) and riders; `version_at`, `version_in_tree`, `write_version` over a member's manifest.
- `src/release/packages.rs`: `members`, every publishable member with its manifest path; `crate_names` reads through it.
- `src/release/plan.rs`: `plan` takes a `Target`; `Plan` carries the `layout`, the `riders` as `Ride` and each publish's version; a rider publishes only when its manifest moved since the last tag; a named version one step off is `PlanError::NotOneStep`, a set with no primary `PlanError::Layout`; `OffLevel` carries the target. Tests moved to `plan_tests.rs`.
- `src/release/changelog.rs`: `name_the_moves`, the riders that move under `crates`.
- `src/release/check.rs`: `Inputs::target`; `tag.bump.tagged` takes a tag naming the version on the bump or on a commit after it, and walks the primary's own manifest and each rider's; `man.version.matches` reads the primary through its manifest; the working version and `man.current.forward` per crate; the riders through `riders::findings`; `semver.gaps` through `Version::is_one_step`.
- `src/release/riders.rs`: `findings`, each rider against its own versions: `tag.bump.tagged` against the versions release tags carry, `man.current.forward`, `reg.orphan`, and `reg.unpublished` at the newest tag.
- `src/release/run.rs`: `release` and `step_check` take a `Target`; `step_bump` writes the primary's manifest of a set; `step_publish` publishes each at its own version.
- Tests: `workspace_tests.rs` (a fixture set of three crates: the check per crate, a rider's untagged bump and unpublished tag, the plan publishing only what moved, a set with no primary, an explicit pre-release, the whole release of a set); `check_tests.rs` `a_pre_release_of_the_next_version_is_one_step_and_so_is_its_release`, `a_bump_whose_version_was_tagged_on_a_later_commit_is_tagged`. Shown red before the source: the new tests did not compile against the old surface (no `Target`, no `NotOneStep`, no `Layout`).

## mock/crates/homma-engine

- `src/cli.rs`: `TargetArgs`, `--level` or `--version`, exactly one, on `release plan` and `release run`; test `a_release_takes_a_level_or_a_version_and_exactly_one`.
- `src/cmd/release/mod.rs`: the commands take the target; `badges` reads a set's primary version.
- `tests/cli_release.rs`: the publish line carries the version.
