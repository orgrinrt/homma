# the-readme-prose-cap-cuts-inside-a-line

The one review pass over the fixed branch found that the prose cap of a tool's readme was checked before a line was added, so one long line went in whole, and that it counted bytes where the design says characters. A readme that is a single megabyte line was kept entirely.

The design now says the cut falls inside a line: the prose stops at the 24000th character wherever that is. The code counts characters and cuts inside the line, and a test for each limit, the 80 usage lines and the prose, shows the cap holding.
