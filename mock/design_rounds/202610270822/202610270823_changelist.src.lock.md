# src changelist

Answers the topic filed in this round, `the-gate-reads-homma-on-stdout-and-the-pin-is-a-string`.

## Changes

- `crates/homma-engine/src/cmd/gates.rs`: the gate reads the status document from stdout alone and drops stderr, which it fetches by running the command again only when the answer failed, to say what went wrong. The early exit for the mockspace tool repository, keyed on its package name, is deleted, so that repository is held to the shared config check as any other. A test of stderr noise on a successful run was red before the change.
- `crates/homma-engine/src/cmd/agent.rs`: a launcher pin is a `mockspace_*` key at the top level of the toml with a string value, the only value the launcher reads. The test of the pin gained the non-string cases and was red before.
- `crates/homma-engine/src/cmd/gates/tests.rs`: new tests for stderr noise, for answers that are not the report, and for a pin alone being one surface of three, which was shown red with the pin not counted toward adoption. The two tests with identical bodies lose one, the tests that only exercised the toml crate through the stub and the two that ran a copied `case` statement instead of the gate are deleted, and the `AliasShape` parameter of the fixture goes with the alias.
- `crates/homma-engine/src/cmd/agent/status/tests.rs`: a probe test of the literal-string mock directory and of a key under an indented table, which the deleted gate tests had been holding.
- `crates/homma-engine/src/cmd/agent/status/tests.rs`, `agent/regen/tests.rs`: the copyright header the other source files carry.
- `.gitignore`: the comment no longer says the render comes from `mock/agent/`.

The design changes in the doc changelist. The suite is green, 598 tests.

Left: the status tests inline in `status.rs`, and a test of the mockspace tool repository being checked, which the stub runner does not yet take a repository name for.

The three flat topics from earlier rounds stay open and are named in the doc changelist.
