# the-gate-reads-homma-on-stdout-and-the-pin-is-a-string


Sent back by the sixth fresh read of the branch. The gate captures `homma agent status` with its stderr folded in and then parses the whole as JSON. In production `homma` is the launcher, which writes a line to stderr on a successful run when it is offline past its cache, when it builds the engine for a moved pin, and when it updates itself, so any of those makes the gate refuse every commit in every member repository, including ones with no mockspace. The old awk reader never asked homma, so this is new on the branch. The JSON is read from stdout alone and stderr is kept apart for the error text.

The gate's early exit for the mockspace tool repository, keyed on its package name, was licensed by that repository always scoring partial adoption. Adoption is the toml now, that repository has none, and the design says the shared config check still applies to a repository that has not adopted. The exit goes.

The launcher reads a pin only where its value is a string, so `mockspace_branch = 3` passes the gate and `cargo mock` refuses it. The probe counts a pin only as a string. No test held the pin counting toward adoption: a toml with only a pin, no mock directory and no hooks path, must be refused. Some gate tests no longer test anything of their own: two have identical bodies, three now only exercise the toml crate through the stub and duplicate the probe tests, and two run a copied `case` statement rather than the gate. Those go, with the `AliasShape` fixture parameter that carried the alias. The two new test files under `agent/` lack the copyright header every other source file carries. `.gitignore` still says the render comes from `mock/agent/`.

For the lead designer, not this round: the launcher locates its config by scanning the root and every immediate subdirectory and treats two as an error, where homma looks at the root and `mock/` and lets the root win; and the status tells a pinless adopted repository to run `homma agent regen` while the design says regen cannot run `cargo mock` without a pin. Both are added to the open question in the design.
