# The mechanism was built and never wired

**Phase:** TOPIC
**Scope:** `homma-api`, `homma-core`, `homma-org`, `homma`

A review of the previous round found that `provision`, the function that clones a
content repository into a workspace and sets the git identity in that clone, has
no caller. `stand_up` creates directories, links memory, writes two definitions
and returns. `homma org up` on a complete entry exits 0, and the workspace it
names does not exist.

Reproduced before acting on the report:

```
$ homma org up fresh
fresh ./.shared/hands/fresh
  definition ./.claude/agents/fresh.md
up exit=0
$ ls -d $T/ws/fresh
No such file or directory
```

**Three things make this worse than an unfinished feature.**

The design document was edited in the same round to assert the behaviour: "after
standing up, that clone reports the identity's own email". Nothing after standing
up reports anything. A design describing a shape the code never had is drift in
the tier that governs, and it conceals the gap rather than leaving it findable.

The generated definition tells every Hand "You commit as `<name> <email>`, set in
this workspace's own git config and nowhere else." No such config is written, so
the Hand commits under whoever owns the machine while holding a document that
says it does not.

And that inverts the rule the previous rounds established. A generated definition
states every constraint the system enforces, because a mechanism nobody is told
about works and misleads. Here the definition states a constraint the system does
**not** enforce, which is the same failure pointed the other way and is strictly
worse: the first misleads by silence, this one by assertion.

**The pattern is the one the first end-to-end run found, reproduced in the round
that was written to prevent it.** Mechanism correct, tests green, belief wrong.
Every test of `provision` passed, because they call `provision`.

## What the round does

**Wires it, and resolves the one thing that made wiring non-obvious.** A content
repository has a name in the configuration and not a URL. It does not need one:
homma runs inside a clone of the content repository, so `origin` on the workspace
root is the URL, and taking it from there means no second place for it to be
wrong. Where the root is not a repository, standing up is refused rather than
guessing.

**Asserts what the test claimed and did not check.** A test named "written to the
local config file and nowhere else" read the local file and made no statement
about the global one. "Never globally" is the whole content of the requirement,
so the test now points a global config at a file of its own and asserts it stays
empty.

**Makes the registry append survive a short write.** It appends directly to the
file, so a partial write leaves a truncated table and every later invocation fails
to parse a registry with no backup. The store crate beside it already writes
beside and renames; this uses the same shape, and re-parses afterwards, because a
file homma writes and cannot read is worse than one it refuses to write.

**Closes the injection hole `org add` made reachable.** The control-character
check covers the fields that reach frontmatter and not `workspace` or `repos`,
which were unreachable from the command line until this surface existed.

**Renames `Standing` to `Staffing`.** The vocabulary crate already uses *standing*
for what a reference derives, and `Rung::Mapped` already exists meaning something
unrelated. One word for two concepts in the one crate whose only job is vocabulary
is a defect in that crate's job.

## What this round does not do

It does not add a configuration key for the content repository's URL. That would
be a second place for the same fact to live and disagree.
