# SRC changelist: the mechanism was built and never wired

**Round:** the wiring round
**Phase:** IMPL

## CHANGE: mock/crates/homma-api/src/git.rs

Add `origin_url`, so the clone URL comes from the workspace root's own remote
rather than a configuration key.

## CHANGE: mock/crates/homma-api/src/config.rs

Rename `Standing` to `Staffing`, since `standing` already names what a reference
derives in this same crate and `Rung::Mapped` already exists meaning something
unrelated. One word for two concepts in the vocabulary crate is a defect in that
crate's only job.

Extend the control-character check to `workspace` and `repos`. Those fields were
unreachable from the command line until `org add` existed and are reachable now.

Delete the `assert!(!id.staffed)` line whose subject is a constructor literal
asserted against itself. The serde default it claims to cover is covered by the
TOML fixture beside it.

## CHANGE: mock/crates/homma-core/src/repo/git_impl.rs

Implement `origin_url`. **Assert that setting an identity does not write a global
config**, by pointing one at a file of its own and asserting it stays empty. The
test claiming "nowhere else" read the local file and made no statement about the
global one, and "never globally" is the whole content of the requirement.

## CHANGE: mock/crates/homma-org/src/provision.rs (new)

Move `provision` and its error out of `workspace.rs`, which crossed the file-size
limit in the previous round.

## CHANGE: mock/crates/homma-org/src/workspace.rs

Remove what moved.

## CHANGE: mock/crates/homma/src/cmd/org.rs

**Wire `provision` into `stand_up`**, which is the defect. `stand_up` takes the
git implementation, derives the content repository's URL from the workspace
root's `origin`, clones when the target is absent, and sets the identity.

Refuse when the root is not a repository, rather than standing up a workspace
whose clone silently did not happen.

Write the registry through a temporary file and rename, then re-parse: a short
write currently leaves a truncated table and a registry no later invocation can
read. `homma-store` already owns this shape.

Correct `add`'s documentation, which describes a return value it does not have.

Tests: standing up clones and sets the identity; standing up twice does not clone
over an existing workspace; a root that is not a repository is refused; a
truncated write leaves the original registry readable.
