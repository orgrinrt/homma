# Doc changelist: stop claiming the check is total

## CHANGE: `homma-org/DESIGN.md.tmpl`, the paragraph claiming one check covers everything

Currently:

> **Every path written to is checked, not the one a reproduction pointed at.**
> ... The check therefore lives in one place that all of them pass through.

False when written and false now. Ten review rounds have each shipped a guard
plus a sentence asserting the guard was total, and the tenth found the escape in
the one thing the sentence did not consider a path: the bytes written into a
symlink, which the kernel follows exactly like any other.

The replacement says what is actually true, which is narrower and more useful:
which surfaces are proven, by what, and what remains open. A design document that
overstates a guarantee is worse than one that understates it, because the
overstatement is what a later round reasons from.
