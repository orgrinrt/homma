# doc changelist

Answers the topic filed in this round, `homma-what-after-the-third-review`, and amends the section "Finding a tool" of `mock/DESIGN.md.tmpl` that the closed round `202610271125` left.

## Current state

The section prints a tool's bare command when no verb matched, reads a usage verb after a column gap, does not say that `//` headers, `shellcheck` lines, an em-dash separator and the `.git` directory are handled, says an unreadable local config widens nothing, and stems an `ed` or `ing` root differently bare and plural.

## Changes proposed

- Tools: where no verb matched and the tool has verbs but none named for itself, the command is followed by its verbs in angle brackets.
- Scripts: a usage verb is set off from the name by a single space; `//` lines are a header spelling; an em-dash may follow the name; a `shellcheck` line is not part of the block; `.git` is not read.
- Footer: a local config that does not parse is read as naming no repository, and the footer says so.
- Query: a plural comes off first, then `ing` or `ed`; the filler is dropped as it is or once stemmed.
