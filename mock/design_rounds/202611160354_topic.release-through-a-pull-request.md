# release-through-a-pull-request

Ticket `b9eeed3833e7`. `homma release run renki --version 0.0.5-rc.2` stopped at step 4: the push of `dev`
was refused by the forge, `GH013: Repository rule violations found for refs/heads/dev. - Changes must be made
through a pull request.` The bump commit stayed on the local `dev`, one ahead of the remote. The same ruleset
on `main` refuses the push of the release merge at step 5, which the operator's reference names as a gap.

## What changes

- A push of the trunk or of the release line that the forge refuses outright, git's `[remote rejected]`, is
  landed through a pull request instead. The workspace landing reads the same words the same way.
- The pull request goes through the workspace's `forge_route`, one more verb beside `tag` and `release`:
  `forge_route pr <repo root> <head> <base> <title> <squash|merge> <sha>`. It takes the open pull request from
  the head into the base or opens one with no body, and has the forge merge it at that head sha with the title
  as the subject and an empty message. The landing scripts' own pull request fallback goes through the same
  functions, so there is one copy of it.
- Step 4: the bump commit is pushed as `release/<repo>-<version>` and squashed into the trunk, the title
  `chore: release <version>`. The clone's trunk then takes the forge's commit.
- Step 5: the pull request is the trunk into the release line, merged with a merge commit titled
  `release: <version>`, which is the release pull request the workspace's flow names. The clone's release line
  takes the forge's merge commit, and the tag goes on it.
- `ByClient` has no pull request, so where no route is named the refusal stands with its reason.
- A run that stopped after step 4 made its commit resumes it. A trunk one commit past the remote's, that commit
  `chore: release <version>` on the remote's tip, is set aside before the check and the plan run on the commit
  the gate measured, and step 4 takes it back instead of writing a second one. A plan for another version than
  the one it carries refuses, and the commit is put back.
