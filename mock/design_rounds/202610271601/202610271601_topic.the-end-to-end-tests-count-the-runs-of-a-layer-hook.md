# the-end-to-end-tests-count-the-runs-of-a-layer-hook

An eleventh review found that the engine's layer-only end-to-end test asserts the layer's output appears in a real commit, which would still pass if the hook ran twice. The doubled run is the failure the branch exists to prevent, and a git-shook chain meeting a gate that holds the key first can produce it. The assertion counts the occurrences and expects one. The core crate's matching test already compares the whole log of calls against a single line, so it counts already.
