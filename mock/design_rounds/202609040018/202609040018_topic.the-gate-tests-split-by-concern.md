# the-gate-tests-split-by-concern

## What was found

`homma-core/src/release/gate_tests.rs` is 719 lines, 643 of them code, and
the file-size lint names it on every commit to the crate. It carries three
things: the feature-set matrix, which sets a crate or a workspace member is
built under and which runs each step makes; the steps one at a time, a
failing call, docs reporting, deny and notices behind their config files,
the deno half and the description step; and the whole gate, a dirty tree,
the verdict, a tree with no manifest and a content-only repository. The
table-answering runner and the two fixture builders at the top serve all
three.

## What changes

The file becomes a directory: `gate_tests/mod.rs` holds the runner and the
fixture builders and declares three modules, `features`, `steps` and
`whole`, each holding the tests named above unchanged. `gate.rs` includes
the directory's `mod.rs` behind the same `#[path]`. No test moves crate,
none is rewritten, and the count stays what it was.
