# Source changelist: the sweep is tested, and both.sameset compares per package

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609030305_changelist.doc.lock.md`

## `homma-core`

### `src/release/check.rs`, `check_tests.rs` (modify)

CHANGE: `both.sameset` is raised per jsr package against the npm package of the same bare name, the segment after the last `/`, and the message names the package; a jsr package with no npm counterpart raises nothing. A test plants two jsr packages and one npm package and asserts the finding names only the mismatched pair. `manifest_version_at` writes its scratch manifest through `publish::write_private` and returns the write error instead of swallowing it.

### `src/release/git.rs` (modify)

CHANGE: `GitError` gains `Scratch(std::io::Error)`, the write of a scratch file a read needed failing, with its display line.

### `src/release/plan.rs` (modify)

CHANGE: `PlanError::OffLevel` carries the last tag's version; the message offers a level only where the manifest is above the tag, and below it says the manifest is behind the tag and to set it to the tag's version or the level's. The test covers both.

## `homma-engine`

### `src/cmd/release/order.rs` (modify)

CHANGE: the self-named member test is renamed for what it asserts, that the repo matches its own member unless its name is left out of the slice.

### `tests/cli_smoke.rs` (modify)

CHANGE: a workspace-wide `release run --dry-run` over a repo with nothing unreleased and a repo with no manifest prints a line for each naming why it was passed over and exits clean; over a repo whose manifest is off the level it refuses, naming the repo and both versions, before touching any registry.
