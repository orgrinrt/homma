## CHANGE: `crates/homma-engine/tests/the_readme_examples_are_real.rs`

The manifest check reads every toml block in the readme rather than the first,
and refuses to run at all if it finds none.

It read one because there was one, and asserted the count so that a second
would fail loudly rather than be skipped. That assertion did its job the moment
the readme grew a second block, and the fix it asked for is the one made here:
read them all.

A block naming a workspace is the manifest. Every other block is a fragment of
one and cannot stand alone, so each is folded into the manifest's own keys and
the result parsed as a manifest. That is what checks a fragment names a real
key carrying a value of the right shape, which parsing it in isolation cannot,
since a fragment is missing everything a manifest requires.

Verified by misspelling the readme's own `deny` and watching the check name the
key and list the ones it expected instead.
