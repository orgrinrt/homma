# the-install-wording-names-the-only-flag-it-passes

A tenth review found that `homma hook install --help` and two source comments and one error say the install runs `git shook install --yes`, while the code runs `git shook install --yes --only homma`. The difference is what the consent covers: the `--only` is what keeps the operator's yes from reaching a tracked `shook.toml` that arrived through a merge and was never looked at. The deep dive already says it right; the help text and the error do not.

The wording is corrected in the three places that name the command, so the help says what the verb consents to and the refusal names the command that was run. No template changes, since the design already states the flag.
