# Doc changelist: a content repo's gate summary says so

**Date:** 2026-09-03
**Phase:** DOC
**Source topics:** `202609031625_topic.a-content-repo-s-gate-summary-says-so.md`

## Current state

The gate section of `homma-core/DEEPDIVE_release.md.tmpl` says what a run records and that a content repository runs a gate of skipped steps and passes, and says nothing about how a run is summarised, so a run of nothing summarises as nothing.

## Changes proposed

### `homma-core/DEEPDIVE_release.md.tmpl` (modify)

The paragraph on what a run records gains the summary: one line naming the steps that ran and how each went, which is also the commit status description, and a run in which every step was skipped summarises as nothing to run with the reason, so a green status on a content repository never reads as a check that happened.
