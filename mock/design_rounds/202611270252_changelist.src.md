# src changelist

This changelist comes from `202611270248_topic.agent-hooks-on-one-call-per-event.md`, the round's one topic, and carries out the locked doc changelist `202611270250_changelist.doc.lock.md`.

## CHANGE: the agent hooks FROM registrations and wrappers homma writes TO rows of one manifest claude-shook registers
File: `mock/crates/homma-engine/src/cmd/agent_shook.rs`
Verification: New module. `Row` holds a row's event, name, argument list, matcher, `paths`, whether it runs at the root, its timeout and whether it runs through the notice filter. `manifest` writes the rows as `.claude/shook/manifests/homma.toml`, one array per event in the order the rows came, the filter in front of a filtered row only where the workspace has it. `numbered` gives a second row under one name at one event `-2`. `front` finds `claude-shook` on `PATH`. `install` writes the manifest and runs `claude-shook install --root <root>`, putting the manifest back as it was on a refusal. `DEFAULT_TIMEOUT` is 600. Tests in `agent_shook_tests.rs`.

## CHANGE: `homma agent regen`'s hooks stage FROM merging registrations TO asking for the front first, installing, then sweeping
File: `mock/crates/homma-engine/src/cmd/agent.rs`
Verification: `regen` asks `agent_shook::front` before the member loop. Where there is none, each member's aggregate is skipped, nothing under `.claude/` is written, and the run fails with one line. After the loop, every member the loop did not aggregate is read as it stands on disk, so a `--repo` run, a failed `cargo mock` or a stop still carries every member; one that cannot be read leaves the hooks as they were. The rows are the gate's, the members', the declared rows and the nudges, and `hook::sweep_row`, numbered. `agent_shook::install` runs first; only after it do `aggregate::retire_wrappers` and `aggregate::merge_settings` run. A failure is one `(agent hooks)` result.

## CHANGE: a member's hook FROM a wrapper and a registration TO a row per registration, run by `{root}`
File: `mock/crates/homma-engine/src/cmd/aggregate.rs`
Verification: `aggregate_repo` writes and removes nothing under `.claude/hooks/`, keeping the sweep of retired rule copies. `aggregate_hooks` makes one `Row` per registration: named `<repo>--<hook>` through `row_name`, running `program_words`, `{root}/<repo>/.claude/hooks/<hook>` and `argument_words`, with the repo under `paths`, the registration's `timeout` or 600, and the filter. `program_words` refuses a line of shell, now including quotes and `$`, and `argument_words` refuses arguments that would not split into what the host was handed. `registrations` yields each hook's timeout as well, and is the one walk. `retire_wrappers` removes every marked `<a>--<b>` file under `.claude/hooks/` except the gate's script. `HookEntry`, `one_runner`, the per-repo wrapper sweep and the registration of homma's own are gone. Tests in `aggregate_chains_tests.rs`, `aggregate_registration_tests.rs`, `aggregate_tests.rs` and the new `aggregate_words_tests.rs`.

## CHANGE: the wrapper template and its scope check FROM homma's TO gone, the front's `paths` in their place
File: `mock/crates/homma-engine/src/cmd/aggregate_call.rs`
Verification: Renamed from `aggregate_wrapper.rs`. It keeps `HookCall`, `hook_call`, `hook_file_named` and `sh_single_quote_escape`. `wrapper_script`, `LANDS_IN_SH` and `one_runner` are gone, and so are `aggregate_wrapper_tests.rs` and `aggregate_wrapper_handoff_tests.rs`, which tested the wrapper's own bash; the narrowing's cases are the front's tests now.

## CHANGE: the settings merge FROM writing registrations TO sweeping homma's own from both files
File: `mock/crates/homma-engine/src/cmd/aggregate_settings.rs`
Verification: `merge_settings(root, known_repos)` sweeps every registration of homma's shape from `settings.local.json` and `settings.json`, visited member or not, keeping a name whose file is somebody's, and writes a file only where it swept something. Both are read and swept before either is written. Tests in `aggregate_settings_tests.rs` and `aggregate_settings_shared_tests.rs`, the unvisited-member test inverted.

## CHANGE: the declared rows FROM wrappers TO rows
File: `mock/crates/homma-engine/src/cmd/declared.rs`
Verification: `declared_rows` makes one `Row` per declared row, `_declared--<slug>`, running `{root}/<run>` with its repositories under `paths`, scope rules as before, then appends `nudge::rows`. It writes nothing. `is_declared_command` stays, to recognise an older homma's wrappers. Tests in `declared_tests.rs`.

## CHANGE: the nudges FROM a wrapper per event TO a row per event
File: `mock/crates/homma-engine/src/cmd/nudge/row.rs`
Verification: Renamed from `wrapper.rs`. `rows` gives one `_nudges` row per event, running `homma agent nudge <Event>` at the root, unfiltered, its matcher the rows' tools joined. `NUDGES_PREFIX` stays for the sweep. Tests in `nudge/tests/rows.rs`, renamed from `wrappers.rs`.

## CHANGE: the workspace gate FROM a registration TO a row running its script
File: `mock/crates/homma-engine/src/cmd/gates.rs`
Verification: `install_workspace_gate` still writes the gate script and returns `gate_row`, `PreToolUse` for `Bash` running `{root}/.claude/hooks/_workspace--mockspace-gate.sh`. `GATE_SCRIPT_NAME` is `pub(crate)`, so the sweep leaves the script. Test in `gates/tests.rs`.

## CHANGE: the git hooks' sweep FROM the workspace's own session-start hook TO homma's `_git-hooks` row
File: `mock/crates/homma-engine/src/cmd/hook.rs`
Verification: `sweep_row` is the `SessionStart` row `_git-hooks` running `homma hook install` at the root.

## CHANGE: the docs that named the wrappers FROM wrappers TO rows
File: `mock/crates/homma-engine/src/cli.rs`
Verification: The `agent nudge` and `--skip-surfaces` docs name the row and the agent hooks. `cmd/util.rs`, the `hooks_not_carried` doc in `cmd/agent.rs`, `homma-core/src/config.rs` and `homma-api/src/agent_hooks.rs` say the same; the last no longer names a git hooks table homma no longer has.

## CHANGE: a stand-in front for tests FROM none TO `homma_fixture::front_on_path`
File: `mock/crates/homma-fixture/src/lib.rs`
Verification: `front_on_path` plants a `claude-shook` that takes every install and returns a `PATH` with it in front. `tests/regen_writes_smoke.rs` runs its regens that reach the write with it.

## CHANGE: the move end to end FROM untested TO `tests/agent_hooks_move_smoke.rs`
File: `mock/crates/homma-engine/tests/agent_hooks_move_smoke.rs`
Verification: Without a front the regen refuses in one line and writes and removes nothing, the gate's script included. A front that refuses leaves the old wrapper, the settings and no manifest. A front that takes them gets the gate first, the member's row with its `paths`, and `_git-hooks` at the root, with the old wrapper and registration swept and what somebody wrote kept. A `--repo` regen still carries every member. With `CLAUDE_SHOOK` naming the real front, one call runs the member's hook for an edit in it and not for one elsewhere.
