# src changelist

Doc changelist: `202609241924_changelist.doc.lock.md`.

## Changes

- `mock/crates/homma-engine/src/cmd/capture/transcript.rs`: an `Event` carries
  the `uuid` of its line and its position; `read` stops before a last line with
  no newline, drops the later of a queued twin over the whole transcript, and
  reports the uuid of the last complete line; `Answer` carries the chosen labels
  and the typed remainder together, parsed labels first, longest first, quoted
  or bare.
- `store.rs`: the watermark is a uuid, and the latest capture for a session is
  the one whose uuid sits latest in the transcript; an unknown uuid is an error.
  The workspace root is canonicalised before it is escaped.
- `mod.rs`: `make` filters by position after the watermark, then by `--since`;
  `--session` as a path needs no `HOME`; the file is written with create-new.
- `render.rs`: `through` is the uuid; a question renders its labels, then the
  typed part quoted, then the notes.
- `README.md`: the `homma capture` row without the second person.
- Tests for each, and the vacuous ones removed.
