## CHANGE: module `cmd::tools::descriptor` FROM its own reading of the descriptor format TO renki's
File: `mock/crates/homma-engine/src/cmd/tools/descriptor.rs`
`Tool`, `Verb` and the private `Source` are gone. An entry is a `renki::extension::Descriptor` or the
reason one cannot be used, and `parse` is `Descriptor::parse` followed by the two checks renki does not make:
the name is the directory's and a verb is named once. The refusals of an empty summary, of a verb name that
is not lowercase letters, digits, `.`, `_` and `-`, and of a `run` starting with `./` are dropped with the
copy that made them, since renki does not refuse them and the design does not say they are refused. A reason
is put on one line.
Verification: `descriptor_tests.rs`, which holds a sixteen digit `rev`, a `--upload-pack` url or `rev`, an
absolute or climbing `run` or `source.path`, and a `file://` url refused, `./show` accepted, and both homma
checks, each run against a copy with the check removed.

## CHANGE: module `cmd::tools::dispatch` FROM `Plan` and a copy of the command builder TO renki's `locate` and `command`
File: `mock/crates/homma-engine/src/cmd/tools/dispatch.rs`
`plan` chooses the verb as before and returns the `std::process::Command` renki's `command` builds, found by
`locate` against `REGISTRY`, renki's own `local` and `git` rows. The refusal of a backend other than `local`
is gone. The words after the verb are appended to the command as the caller's own `OsString`s, since renki
takes text. A file that is not executable is refused, which renki does not check. `exec` takes the command.
renki is unix only, so the `cfg(not(unix))` arm of `exec` goes with the rest.
Verification: `dispatch_tests.rs`: a symlink out of the tool refused and one inside it accepted, `source.path`
honoured and its absence named, `HOMMA_TOOL_ROOT` and `HOMMA_WORKSPACE` set, a git tool run from the cache
where renki's `cache_key` puts it, the cache asked for only by a backend that keeps one, an unknown backend
refused with `local, git` listed, a word that is not text kept; each run against a copy with the behaviour
removed.

## CHANGE: module `cmd::tools::cache` FROM absent TO present
File: `mock/crates/homma-engine/src/cmd/tools/cache.rs`
The cache root a `git` tool is fetched into, `HOMMA_CACHE`, then the XDG cache directory with `homma` under
it, then the platform default, through `renki-dirs`, which is how the launcher resolves the same root.
Verification: `cache_tests.rs`.

## CHANGE: module `cmd::tools::groups` FROM absent TO present
File: `mock/crates/homma-engine/src/cmd/tools/groups.rs`, `mock/crates/homma-engine/src/main.rs`
`groups` reads off the command line which built-in commands take verbs, `tools` excepted, and `command` lets
each take a word it has no verb for. `parse` returns either the `Cli` or the word handed on with the global
options given. `RulesOp::External` and the constant `MERGED` are gone, so no group is named in code and a
tool named `skills` or `release` is reached the way `rules` is.
Verification: `tests.rs`, which holds the list of groups to the design's and every group to handing a word on
with its flags and `--dir`, `-v` kept, and `tests/tools_dispatch.rs`, which runs a tool named for each of the
eleven through the binary.

## CHANGE: module `cmd` FROM `config_path` over a `Cli` TO `manifest_path` over the two flags
File: `mock/crates/homma-engine/src/cmd/mod.rs`
A handed word has no `Cli`, so the manifest's path is computed from `--config` and `--dir` themselves, and
`config_path` calls it.
Verification: the existing `config_path_tests`.

## CHANGE: dependencies of `homma-engine` FROM none of renki TO `renki`, `renki-dirs` and `notko`
File: `mock/crates/homma-engine/Cargo.toml`
`rust-version` is 1.88 for the engine, the floor `renki` declares and the launcher already states.
Verification: the build, and `mock/Cargo.lock`, which already held all three.

## CHANGE: integration tests FROM a local tool only TO the tools renki's api reaches
File: `mock/crates/homma-engine/tests/tools_dispatch.rs`
Eight tests added through the binary, each failing before the change: a symlink out of the tool refused
and never run, descriptors renki refuses listed as broken with the reason, `./` run accepted, a tool run from
its `source`, `HOMMA_TOOL_ROOT`, a git tool listed without a fetch and run from the cache, an unknown
backend refused with the known ones named, and a tool for each built-in group.

## Upstream

renki 0.0.3 lacks four things homma had to work round, reported for a renki change rather than copied here:
the host's cache root is not public (`cache_root` is `pub(crate)`, so `renki-dirs` is read directly);
`extension::command` takes its arguments as `String` and so cannot carry a word that is not text;
it does not check that the file is executable; and `Descriptor::parse` returns its toml error with the
source excerpt across lines.
