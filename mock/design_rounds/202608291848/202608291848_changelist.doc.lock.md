# Doc changelist: the write and the read were on one thread

## README.md

No change. The manifest section documents what a `[[status.inject]]` entry may
carry and how the pieces relate, and none of that moves: the keys are the same,
the ordering is the same, and a failing tool still does not take the command
down.

What changes is that a `format` reading all of a large input now returns instead
of hanging, which is the behaviour the section already implies. Documenting the
old behaviour was never on the table, and documenting that it is fixed would be
a changelog entry in a reference section.

## docs/

No change, for the same reason as the round this follows: nothing under `docs/`
describes a manifest key.
