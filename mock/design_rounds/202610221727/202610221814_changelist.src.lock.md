## CHANGE: module `cmd::stray_targets` FROM absent TO present
File: `mock/crates/homma-engine/src/cmd/stray_targets.rs`
`collect` walks the workspace root six levels down and returns every directory called
`target` that holds a `CACHEDIR.TAG`, a `.rustc_info.json`, or a `debug` or `release`
directory, other than the root's own `target`, each with its size in bytes and sorted
by path. It does not enter a build directory it found, `.git` or `node_modules`, and
follows no link. `human` writes a size in binary units.
Verification: the eight unit tests in the module's `tests`:
`the_workspaces_own_target_alone_is_nothing`,
`a_worktrees_and_a_nested_build_directory_are_listed_in_path_order`,
`a_source_directory_called_target_is_not_a_build_directory`,
`the_size_counts_every_file_below_it`, `git_and_node_modules_are_not_entered`,
`a_build_directory_past_the_depth_is_not_found_and_one_at_it_is`,
`a_link_to_a_build_directory_is_not_followed` and `sizes_are_written_in_binary_units`.
Each was run against a copy of the module with the behaviour removed: the root
directory counted, every `target` counted, a depth of seven, `.git` entered.

## CHANGE: `StatusReport` FROM no stray build directories TO a `stray_targets` list
File: `mock/crates/homma-engine/src/cmd/status.rs`
The report carries `stray_targets`, filled by `run` from the workspace path, empty
from `build_report`. The human rendering prints the section after the working trees
only where the list is not empty.
Verification: `a_worktrees_own_target_is_listed_with_its_size`,
`the_document_carries_them_too` and `the_workspaces_one_target_alone_prints_nothing_about_it`
in `mock/crates/homma-engine/tests/status_lists_stray_targets.rs`, through the binary.
Run against copies of `status.rs` with the call to `collect` removed and with the
render call removed.
