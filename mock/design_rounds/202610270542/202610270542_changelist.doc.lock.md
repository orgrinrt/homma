# doc changelist

Answers `202610270542_topic.adoption-is-the-toml-and-the-document-keeps-its-fields.md`.

## Current state

The status section says a repository has adopted mockspace if it carries a `mockspace.toml` or has its mock directory, so a mock directory with no toml is asked for surfaces and sent to a command that cannot run there. The same section promises the machine-readable document only grows, and the agent status document lost two fields. The configs section tells a reader to put the shared copy back, which drops what a copy that is a superset carries.

## Changes proposed

- `mock/DESIGN.md.tmpl`, "What a status answers": the paragraph on the agent surfaces says adoption is the `mockspace.toml` alone, that a mock directory without one is no mockspace and is named so under `--full`, and that `homma agent regen` leaves such a repository alone.
- `mock/DESIGN.md.tmpl`, "What a status answers": the paragraph on the machine-readable document says the agent status document keeps `mock_agent_dir` and `cargo_mock_alias`, deprecated, carrying their probe values.
- `mock/crates/homma-org/DESIGN.md.tmpl`, "Absence is acted on, difference never is": the reported line names restoring the shared copy where the difference is drift and adding a variant where the copy carries something the shared one lacks.

The three loose topics from earlier rounds stay open, and are not consumed here:

- `202610221816_topic.capture-answers-left-on-a-page.md`: the capture page, not the status.
- `202610221816_topic.what-a-stranger-cannot-reach.md`: what an outside reader reaches, not the status.
