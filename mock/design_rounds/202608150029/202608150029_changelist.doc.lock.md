# Doc changelist: delete an argument that was wrong, and a totality claim

## CHANGE: `homma-org/DESIGN.md.tmpl`, the "what is closed" paragraph

It argued that creating a directory cannot make a prefix outside the root. The
argument holds for prefixes below the root and `create_dir_all` does not stop
there: when the root itself is missing, it creates the root's ancestors too.

Replaced by the rule the code now enforces, which is narrower and true: homma
creates the root, never the path to it.

## CHANGE: `README.md`, the sentence added last round

"Everything that writes does so under a path proven to resolve inside the
workspace root." False, and false in a way this branch's own tests assert: the
workspace clone is required to be outside the root and is created with a bare
path.

It is the same totality claim three rounds removed from three source files, put
back on the page a stranger lands on first. What replaces it says which surface
is proven.
