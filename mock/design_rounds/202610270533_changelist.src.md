## Current state

The source reads stand-ins in every file but documents, reads a line starting `*` as a comment, calls any failing `git merge-base` unrelated, reads `base` from the working tree's record, and takes a `merge-tree` that exits 1 without a tree for a conflict. The tests that name the `unreadable` path and the diff driver cannot fail on them.

## Changes proposed

- `milestone/range.rs`: `is_read` names the places stand-ins are not read (under `mock/research/` or `mock/design_rounds/`, a `.patch`, a `.history`, a document); the continuation anchor is `* ` followed by text.
- `milestone/branches.rs`: `related` classifies the exit of `git merge-base`, so only exit 1 is `unrelated` and any other failure is `unreadable` with git's words; `merged` reads an exit 1 with no tree on its first line as git refusing, not as a conflict; `read` and `merged` are crate-visible so the tests reach them.
- `milestone/record.rs`: `trunk_marks` reads the record from the trunk's tree and `base` uses it; `marks` stays the working tree's, which `mark` appends to.
- `milestone/tests.rs` and `tests/cli_milestone.rs`: tests for the exit classification with a synthetic 128 and no exit, a tip git cannot read, a merge git refuses, the read-set by path and through a diff, the continuation anchor, a `diff.external` that cannot run, `base` from a clone on another branch, and a `git` shim on the binary's path that fails `merge-base` so the `reason` is shown; the two weak tests are replaced.
- `milestone/tests.rs` is split by report into `tests/range.rs` and `tests/branches.rs`, keeping the record tests and the fixture, because it passed 500 lines.
- `docs/` is regenerated.

The three older open topics need nothing from this round, as the doc changelist says; each stays open and none is consumed here.
