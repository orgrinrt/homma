# Source changelist: the hook takes git's arguments and runs from a worktree

**Date:** 2026-09-03
**Phase:** IMPL
**Doc changelist:** `202609030650_changelist.doc.lock.md`

## `homma-engine`

### `src/cli.rs` (modify)

CHANGE: `Gate` accepts trailing positionals after the repo, hidden from help, which are what git hands a pre-push hook; a parse test feeds `gate --hook origin git@github.com:o/r.git` and asserts it parses with `hook` set.

### `src/cmd/release/gating.rs` (modify)

CHANGE: with `--hook`, the positional is git's remote name and is not read as a repo; the repo is the one the working directory is in.

### `src/cmd/release/mod.rs` (modify)

CHANGE: `resolve_repo` falls back, where no repo's root contains the working directory, to the clone `git rev-parse --git-common-dir` names from there, so a worktree beside the clones resolves to its clone.

### `tests/cli_release.rs` (modify)

CHANGE: `release plan` run with a worktree of a member as the working directory, and no repo named, resolves the member and prints its plan.
