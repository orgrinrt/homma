# the-summarising-call-fails-loudly-and-runs-bounded-once

Follows the closed rounds `202611241355-edoa`, which made the summarising pass, and
`202611241445-jfkk`, which made `homma ask` on it. A review of the first found the pass taking
answers it should refuse, calls made where there is nothing to read, and the bounded run of a
child written twice in the engine.

## The question

What does the pass count as a failed call, when does it make no call at all, and where does the
engine keep the one way it runs a child it may have to end?

## What is settled

- **An answer with no summary in it is a failed call.** An answer empty once trimmed, or one with no
  line starting `- `, says nothing the reader can use, and taken as a summary it would replace the
  output with nothing. It fails the pass like any other failed call: the output is whole and the
  reason says which of the two it was. The same holds for the answering call of `homma ask`, which
  also needs its `Answer:` line; such an answer is a failed call and is not kept.
- **Nothing to read, no call.** Empty text given to the pass, a search with no hits asked to
  summarise them, and a command whose output is empty asked a question make no call. The pass says
  there was nothing to summarise; the ask says there was nothing to answer from.
- **The brief goes by file.** The rules and the brief are written to a file outside the call's
  empty run directory and handed over with `--system-prompt-file`, so they are not in the
  command's arguments, which any process on the machine can read.
- **One bounded run.** Running a child in a process group of its own, feeding it, reading both
  pipes on threads, waiting at most a limit for it to exit and then a short grace for the pipes,
  and ending the whole group past either, is one helper of the engine's shared utilities. The
  summarising call, `homma ask`'s run of the command and the listing of a repo's mock commands use
  it, and the release gate's poster takes its process group from it. The group is ended by a
  signal to the group sent from the engine, never by running whatever `kill` is on `PATH`.
- **A claim in `202611241355-edoa`'s topic is withdrawn.** Its "Tried in a container on 24
  November: such a call costs about 1.4k tokens over its own prompt and answers in about two
  seconds" rests on no committed probe or bench, and nothing is built on it. The closed round is
  not edited; this line withdraws it.
