# auth-flow-ports

The landing gate refused branch `work/nutshell-arc` for `#[allow(clippy::too_many_arguments)]` on
`flow::fix_token`, which takes seven parameters. A gate is never quieted; the code changes.

## What the design says

`DEEPDIVE_release.md.tmpl`, Credentials, describes the verbs and their order (paste, prove, store) and names
no signature: the store, the probe and the prompt are not named there.

## Where the source diverges

`flow::fix_token`, `flow::fix` and `flow::all` each take the same three injected capabilities, `store`,
`probe` and `prompt`, as separate parameters, and pass them on to one another.

## Decision

Op's instruction: group the three into one struct the flow takes by reference, used by every function in
`release/auth/` that takes all three, so there is one shape. `check`, `status` and `diagnose` take `store` and
`probe` only, never a prompt, and keep their parameters. The `allow` is removed; no other is added.
