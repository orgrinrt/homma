# The one line in the merge that git could not finish

**Phase:** TOPIC
**Scope:** `homma-api`, the crate root's re-export block

Merging `dev` into `feat/the-author-and-committer-split` stages fifty-five
files. Fifty-four of them are the merge's own work and the gate now says so:
the excuse added upstream compares the staged bytes against each parent, and
where that fails it reproduces the three-way merge for that one path and
compares again. This merge is the first real one it has been asked about, and
it answered on every file but one.

The one it held is `crates/homma-api/src/lib.rs`, and it was right to.

Both sides edited the re-export block. This branch widened the `git` line to
carry `CommitIdentity` beside `Git`. Trunk widened the `denied` line above it
to carry `NoHome` and `Standing`. Two different lines, two different reasons,
and nothing in conflict between them, but they sit next to each other, so git
sees one hunk changed twice and stops.

```
pub use denied::{Denied, Forbidden, NoHome, Standing};   # from trunk
pub use git::{CommitIdentity, Git};                      # from here
```

That is the whole resolution. It takes both, because both belong, and it is
still an authored change: it matches neither parent and `git merge-file` exits
one on it rather than producing it. So the gate reports it and this round is
what carries it, which is the design working rather than the design getting in
the way.

Worth writing down because the shape recurs. A re-export block, a use list, a
match arm table, a field list: anywhere the file is a column of one-line
entries, two unrelated additions land adjacent and git cannot separate them.
The resolution is mechanical every time and it is authored every time, so the
line the excuse draws holds, and the cost of it is one round per merge that
touches such a block on both sides.

The alternative would be to widen the excuse to cover a resolution that is the
union of both sides. That is rejected here. Union is not a property git can
check, and an excuse that guesses at intent is an excuse that eventually
excuses something nobody meant.
