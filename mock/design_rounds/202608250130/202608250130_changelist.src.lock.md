# SRC changelist: the notice goes on every source file

**Phase:** IMPL

One mechanical change over the tree, with no behaviour in it.

## CHANGE: ADD a copyright notice to every Rust file `ante.toml` names

Files: `launcher/src/**/*.rs`, `launcher/tests/**/*.rs`,
`mock/crates/*/src/**/*.rs`, `mock/crates/*/tests/*.rs`, less the trybuild
fixtures.

Verification: `ante check` reports zero failures, and
`git ls-files '*.rs' | xargs grep -L 'SPDX-License-Identifier'` returns only the
excluded fixtures.

Sixty-three of the seventy-four files in scope carried no notice. The eleven
that did are the launcher package.

The notice is generated rather than typed: the licence identifier, the
maintainer address and the contributor list all come from `ante.toml` and from
git, so the next change to any of them is a re-run.

Nothing else in any file moves. The header is four comment lines and a blank
line at the top, above whatever was already there, including a crate root's
inner attributes.

## What is not touched

The trybuild fixtures under `mock/crates/homma-api/tests/compile_fail/` and
their `.stderr` files. Each expectation pins the line its diagnostic lands on,
so a header shifts all of them at once and the suite goes red until they are
regenerated. The fixtures are never distributed and exist only to fail to
compile in a particular way.

## Verification of the whole

`cargo test --workspace` in `mock` and `cargo test` in `launcher`, both green
after the pass, and `cargo clippy --all-targets -- -D warnings` clean. A header
cannot change behaviour, so what those actually check is that nothing landed
inside a file rather than above it.
