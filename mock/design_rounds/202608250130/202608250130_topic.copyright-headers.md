# Copyright headers on every source file

## The state

Sixty-six of homma's seventy-seven Rust files carry no copyright notice. The
eleven that do are the launcher package, which got them when it was written.
Every crate under `mock/crates` is bare.

The workspace's other repos run `ante` for this: a config file names the licence
identifier, the maintainer address and which paths are in scope, and the tool
derives the contributor list from git rather than from a list somebody keeps
current by hand. A year rolling over is a re-run instead of an edit of every
file.

## What this round does

Adds `ante.toml` at the repository root and puts the notice on every Rust file
the config names.

## What it leaves out, and why

The trybuild fixtures under `mock/crates/homma-api/tests/compile_fail/` are
excluded. Each one is paired with a `.stderr` file that pins the line number the
diagnostic lands on, so inserting a header shifts every one of them and the
suite goes red until somebody regenerates the expectations. That is a trap with
no upside: the fixtures exist to fail to compile in a specific way, they are
never distributed, and a notice on them buys nothing while making the next
header change break the tests silently.

`mock/agent` templates and the generated `.claude` and `.github` trees are also
out of scope. Those are markdown, and the generated ones are rewritten from
templates on every run.

## The tool version

`ante` reads a file beginning `#![no_std]` as a shebang, because both start with
`#!`, and puts the notice on the second line where nothing can find it again.
Every crate root here starts with an inner attribute, so the fix has to be in
the tool before this round can run. That fix is upstream in ante, with the
tests, and this round uses a build carrying it.
