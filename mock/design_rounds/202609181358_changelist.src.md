# src changelist: the stubs share one request reader

Carries `202609181342_topic.the-stubs-share-one-request-reader.md`.

## CHANGE: fn `read_request` and struct `Request` FROM absent TO the one reader every stub calls
File: `mock/crates/homma-core/src/forge/wire_stub.rs`
File: `mock/crates/homma-core/src/forge/mod.rs`
Verification: `wire_stub` is declared under `cfg(test)` in `forge/mod.rs`.
`read_request` reads the head up to the blank line and then exactly the
`Content-Length` bytes; `Request` answers `line`, `carries`, `body` and
`text`. Six tests in its own module: a request with a body read whole, one with
no length and no body, a header found in either case, a header that only ends
in the name not taken for it, the request line not read as a header, and a body
arriving in three writes waited for.

## CHANGE: the five stub servers FROM parsing the request each for itself TO calling `read_request`
File: `mock/crates/homma-core/src/forge/github_wire_tests.rs`
File: `mock/crates/homma-core/src/forge/forgejo_wire_tests.rs`
Verification: `grep -c read_line` over both files returns zero, and
`renamed_private_repo`, both `recording_server`s and both `status_by_path`s
read through `read_request`, so the one that did not drain now does.
`cargo test -p homma-core --lib forge` from `mock/`: 97 passed, ten runs of ten.
`cargo test -p homma-core`: 309 passed, 3 ignored.

Negative controls, run by hand and reverted: with the body length forced to
zero, ten tests went red, both `the_stub_reads_a_large_body_before_it_answers`
among them; with the request line counted among the headers,
`the_request_line_is_not_read_as_a_header` went red.

nothing else; its text is the unlocked `202609181236_changelist.src.md` beside
