# Src changelist: withdraw the claim, widen the law, pin the double

## CHANGE: `mock/crates/homma-api/src/config.rs`

**Withdraw the compile-time closure claim above
`every_field_is_classified_as_free_form_or_not`.** The commentary asserts that a
field "can no longer be omitted", and it can: bound as `field: _` and given
`None` in the literal, it leaves 373 passing with zero warnings, and so does `..`
in place of the binding. `#[deny(unused_variables)]` does not reach either,
because neither produces an unused variable.

The rewrite says what the three mechanisms do and what none of them does, names
`unsafe_strings` as the guarantee that actually covers an unknown field, and
records that `E0027`'s own suggested remedies are two thirds an escape hatch. The
`#[deny]` stays: it closes the case where a field is bound and then classified
nowhere, which is a real omission and was a real round.

**Widen the hostile-value law past `\n`.** Every hostile value in the suite is a
newline, so narrowing the walker's `is_control()` to `== '\n'` leaves it green.
The corruption fixture gains `\r`, `\t`, `\0` and `\x1b`, one per free-form
field where the field count allows, so the assertion covers the classes of
control character rather than one character. `\x1b` is the one with an
independent reason: `stand.rs:96` interpolates these into terminal output.

The module's lifecycle sentence says "set the git identity in that clone's own

## CHANGE: `mock/crates/homma/src/cmd/stand.rs`

Two things, and the first was not in the review.

**A third instance of the class**, found by re-grepping by property rather than
by extension: `stand.rs:53` carries the same lifecycle sentence as
`workspace.rs:3`. Three rounds looked for this class in `*.md` and `*.tmpl`
only, and a doc comment is a rendered surface too.

**The fixture at `:363` gains a committer.** Without one, the four-field
assertion at `:365` compares two fields and skips two, which is what made the
unpinned double below invisible. Its committer is deliberately distinct from its
author, so a double that substitutes one for the other fails.

## CHANGE: `mock/crates/homma/tests/fake_git.rs`

The double can return the author's values for the committer and nothing fails.
Its comment claims the committer path "is asserted in `homma-org`", and
`homma-org` carries its own separate `FakeGit`, so this one's committer path was
asserted nowhere. The comment is corrected to name where it is now pinned rather
than where it is not.
