# src changelist: the readme test asks the binary that answers

## CHANGE: `mock/crates/homma-engine/Cargo.toml`

A path dev-dependency on the launcher crate, `homma`, so the engine's readme
test can read which commands the launcher answers off `homma::TOOL`.

## CHANGE: `mock/crates/homma-engine/tests/the_readme_examples_are_real.rs`

- `the_launchers_commands` answers `TOOL.commands`' names, plus `config` where
  `TOOL.settings` is non-empty, which is the condition renki answers `config`
  on. The word is written again under a `FIXME:` because renki keeps it
  `pub(crate)`.
- `commands_the_readme_names` leaves out a span whose first word is one of
  those. The parse it did is now `commands_the_readme_writes`, which every span
  goes through.
- `only_the_launchers_commands_are_left_to_the_launcher` asserts the list holds
  `workspace` and `config`, that the engine's own help lists neither, and that
  every span left out starts with one of them.

Verified: 8 of 8 pass, where `dev` fails `every_command_the_readme_names_runs_as_written`
on `homma workspace` and then on `homma config`. Two controls, each run and
reverted: a skip that also drops `verify` fails the new test at "was left out of
the engine's check and the launcher does not answer it", and a launcher list
claiming `verify` fails it at "the engine takes it too".

## CHANGE: `launcher/tests/the_readme_names_the_launchers_commands.rs`

New. Every command the launcher answers has a row in the readme's table; every
backticked form in the `homma workspace` row parses with `Ask::parse`, read once
with its optional groups dropped and once with them filled; and a control arm
pins that reading and that four wrong forms are refused.

Verified: 3 of 3 pass. Control, run and reverted: requiring a `prune` form fails
at "the row no longer writes a form for `prune`".
