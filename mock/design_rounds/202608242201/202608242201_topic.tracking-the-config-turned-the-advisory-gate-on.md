# Tracking `deny.toml` turned the advisory gate on, and it found three

**Date:** 2026-08-24
**Phase:** TOPIC
**Scope:** `homma-core` (the `gix` dependency)

## What happened

`deny.toml` has been arriving in this repo from the shared configs and never
being tracked. It failed the pre-push gate on a licence, and the response for
several pushes was to move the file aside, which skips the check entirely
because cargo-deny has nothing to read.

The licence turned out to be fine on inspection: `webpki-roots` is Mozilla's CA
root bundle and CDLA-Permissive-2.0 is a data agreement whose section 3.1
disclaims any obligation on results. That is a named exception in the tracked
file now.

With the file present and the licence arm passing, the advisory arm ran for the
first time and reported three, all through `gix` 0.66:

- RUSTSEC-2025-0140, `gix-date` builds a non-utf8 `String` in `TimeBuf::as_str`.
  Fixed in `gix-date` 0.12.
- RUSTSEC-2025-0021, `gix-features` does not detect SHA-1 collision attacks.
  Fixed in `gix-features` 0.41.
- RUSTSEC-2025-0001, `gix-worktree-state` checks out executable files
  world-writable on a nonexclusive checkout. Fixed in `gix-worktree-state` 0.17.

None of the three is new. They have been in this repo for as long as the pin has,
and nothing said so, because the file that would have said so was never tracked
and got moved out of the way whenever it spoke.

## Why the answer is the bump and not an ignore list

The advisory arm is doing exactly its job. `deny.toml` has an `ignore` list and
reaching for it here would restore the silence that let three advisories sit
unreported, which is the failure this round is about rather than a way out of it.

Two of the three are reachable in normal use. `homma` clones repositories, so
`gix-worktree-state`'s checkout permissions are on the path every `homma repo`
clone takes, and `gix-features`' object hashing is on every read of a cloned
repo. The `gix-date` one is narrower and is a soundness hole regardless.

## What the bump costs

`gix` 0.66 to 0.87, which is twenty-one minor versions of a crate that moves
fast. The surface here is small: 58 lines across eleven files, concentrated in
`homma-core/src/repo/gix_impl.rs`, and it is mostly `open`, `init`, the two
`prepare_clone` shapes, a remote fetch, and config file reads.

If the surface has moved more than the adaptation is worth, the honest outcome
is a deprecated changelist saying so and a decision put to op, not an ignore
entry written quietly.
