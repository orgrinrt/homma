# Src changelist: bump `gix` past the three advisories

**Date:** 2026-08-24
**Phase:** IMPL
**Source topic:** `202608242201_topic.tracking-the-config-turned-the-advisory-gate-on.md`
**Doc changelist:** `202608242201_changelist.doc.lock.md`

## CHANGE: `homma-core/Cargo.toml`, the pin

MODIFY the `gix` requirement from `0.66` to a version whose tree carries
`gix-date` >= 0.12, `gix-features` >= 0.41 and `gix-worktree-state` >= 0.17.
The feature list is kept as it is unless a feature was renamed, in which case
the rename is recorded here.

## CHANGE: `homma-core/src/repo/gix_impl.rs` and the other call sites

MODIFY whatever the bump breaks. The surface is `gix::open`, `gix::init`,
`gix::prepare_clone` and `prepare_clone_bare`, `gix::config::File` reads,
`gix::remote::Direction::Fetch`, `gix::ObjectId` and `gix::Repository`.

No behaviour change is intended. A place where the new API cannot express what
the old one did is a finding for the topic rather than a quiet substitution.

## CHANGE: tests

The existing `repo_smoke.rs` covers clone, open and the worktree state it is
about to change permissions on. It is the control for this round: if it passes
before and after, the bump preserved behaviour, and if it does not, the
difference is the thing to look at rather than to work around.
