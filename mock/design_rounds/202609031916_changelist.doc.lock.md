# Doc changelist: one entrypoint per git event, from a hooks table

**Date:** 2026-09-03
**Phase:** DOC
**Source topics:** `202609031913_topic.one-entrypoint-per-git-event-from-a-hooks-table.md`

## Current state

The release deep dive's "The hook" section describes one fixed `pre-push`
hook, `homma release hook install`, refusing a `core.hooksPath` outside the
repository as the mockspace case and calling such a repository gated at
release time only until mockspace's pre-push delegates to homma. The root
design says the config check lives in a workspace-level hook rather than a
per-repository one because mockspace owns `core.hooksPath`. The homma-core
backlog carries the same wait under "The gate through mockspace's own hooks".
mockspace has since chained its gate to the repository's own `.git/hooks/`,
so every one of those three rests on a state that no longer holds, and
nothing in the design lets a second hook, the prose check the voice tool
wants on `pre-commit`, in.

No other flat topic is open on this branch. The round `202608251651` that
`origin/main` still carries flat is closed on `dev` under its own directory
and needs nothing here.

## Changes proposed

### `homma-core/DEEPDIVE_release.md.tmpl` (modify)

"The hook" becomes "Hooks": a `[hooks]` table in `homma.toml`, one array of
entries per git event, each a `run` and optional `paths` globs, with the
release gate the row every workspace has on `pre-push` without writing it and
which a written table cannot drop; `homma hook install <repo>` writing one
entrypoint per event into git's own hooks directory whatever `core.hooksPath`
says, saying how git reaches it there, and refusing a tracked hooks directory
and a foreign hook as before; `homma hook run <event>` capturing stdin,
deriving what the event touches, running the matching entries in order with
`{paths}` expanded, and stopping at the first refusal. The surface lists the
two `homma hook` verbs and drops `homma release hook install`.

### `homma-core/BACKLOG.md.tmpl` (modify)

"The gate through mockspace's own hooks" goes: it is what this round ships.

### `mock/DESIGN.md.tmpl` (modify, not gated)

The paragraph saying the check cannot live in a per-repository hook because
mockspace owns `core.hooksPath` now says the per-repository half is homma's
entrypoint in git's own directory, reached through mockspace's chain, and
that homma never contends for the path.
