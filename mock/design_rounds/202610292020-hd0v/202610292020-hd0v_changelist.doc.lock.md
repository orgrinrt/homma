CHANGE mock/DESIGN.md.tmpl, section "The rule corpus": a paragraph after the one on the meta, saying that a card is for a session and not for every session. The meta has two more optional keys, `roles` (a list of `coordinator` and `helper`, absent meaning every role) and `where` (`cloud` or `local`, absent meaning both). The session is the role in `~/.config/clause-dev/role` and the place from `CLAUSE_CLOUD` being `1`, each overridden by an explicit option; an absent role file is a local session of the person's own and takes every role; a role file holding anything else is refused by name. A card the session excludes is not written, and one an earlier pass wrote for an authored rule that this session excludes is removed, which is not the unclaimed case. Discovery (`rules about`, `rules show`) answers for every rule whatever the session.
