# src changelist

Implements the doc changelist of round 202610292020-hd0v.

CREATE mock/crates/homma-api/src/session.rs: `SessionRole` (`Coordinator`, `Helper`) and `Place` (`Cloud`, `Local`), each with a `FromStr` that refuses any other word by name, `Display`, and an `ALL` const; `Session { role: Option<SessionRole>, place: Place }` with `Session::every(place)`, `Session::from_parts(role_file: Option<&str>, cloud: Option<&str>)` (the role file's trimmed content, an absent file meaning no role and so every role; cloud exactly when the variable is `1`) and `Session::admits(&RuleMeta)`; the consts `ROLE_FILE` (`.config/clause-dev/role`) and `CLOUD_VAR` (`CLAUSE_CLOUD`); every function that can be `const fn` is one
CHANGE mock/crates/homma-api/src/lib.rs: the `session` module and its exports
CHANGE mock/crates/homma-api/src/rule.rs: `roles` and `where` join `KNOWN`; `RuleMeta` carries `roles: Vec<SessionRole>` (empty meaning every role) and `place: Option<Place>`; `parse` reads both and names a bad word with its key
CREATE mock/crates/homma-api/tests/session.rs: the role file read for each role, for none, for an empty file and for a misspelt word (refused, naming the word); `CLAUSE_CLOUD` of `1`, `0`, empty and absent; `admits` for every cell of roles by place, with the controls that a rule with neither key is admitted by every session and that a session with no role is admitted by a rule naming any role
CHANGE mock/crates/homma-api/tests/rule_meta.rs: `roles` and `where` read; absent they are empty and `None`; a word that is neither role, a `where` that is neither place, and a duplicated key are refused
CHANGE mock/crates/homma-org/src/rules.rs: `Corpus::render_cards` takes the `Session`, writes only the cards it admits, and removes a card an earlier pass wrote for an authored rule the session now excludes; the card's text (paths block and rendered card) is one function used by the writing and by the size; `Corpus::withheld(&Session)` names the excluded rules and `Corpus::card_bytes(&Rule)` gives a card's size; `unclaimed` is unchanged and still reports and keeps a card no rule claims
CHANGE mock/crates/homma-org/tests/rules_corpus.rs: the existing renders pass a session that admits every rule; a coordinator's card is not written for a helper and is for a coordinator; a session with no role file gets all; a card written for one role is removed when the next render is for the other; a card no rule claims is still kept and reported under a restricting session; `withheld` and `card_bytes` agree with what is written
CHANGE mock/crates/homma-engine/src/cli.rs: `homma rules render` takes `--role` and `--place` overriding what the environment says; `homma rules load` is added with the same two options and `--all`
CHANGE mock/crates/homma-engine/src/cmd/rules.rs: the session is resolved from the options, then `$HOME/.config/clause-dev/role` and `CLAUSE_CLOUD`; `render` reports the withheld rules beside the cards written; `load` prints a session's cards with their bytes, and with `--all` the count and bytes for no role, coordinator and helper in each place
CHANGE mock/crates/homma-engine/src/cmd/mod.rs: `RulesOp::Load` is routed
CREATE mock/crates/homma-engine/tests/rules_session_smoke.rs: the binary on a scratch workspace holding rules tagged `roles: [coordinator]`, `roles: [helper]`, `where: local` and untagged, run with `HOME` and `CLAUSE_CLOUD` set for each role: the generated cards are those of that session; no role file gives every card, with the control that a role file naming one role gives fewer; a role file with a misspelt word exits nonzero naming it; `rules about` still finds a withheld rule; `rules load --all` prints the counts and bytes the generated tree then holds
