# doc changelist

One paragraph added to the agent hooks section of homma's design, saying every generated wrapper runs its hook through the workspace's dedup tool when it is there. Descends from the topic file `202611060952_topic.hook-wrappers-run-through-hookdedup.md`, the one open topic.

## What lands

- `mock/DESIGN.md.tmpl`, "The agent hooks": the paragraph on running every wrapper's hook through `tools/hookdedup/hookdedup run` when that file is executable.
- `docs/`, rendered.

## Claims the source changelist will carry

- The wrapper of a declared hook and the wrapper of an aggregated hook both start `DEDUP` as the tool's `run` when `$WS/tools/hookdedup/hookdedup` is executable, and as nothing otherwise.
- Every `exec` of the hook in both wrappers is `exec ${DEDUP[@]+"${DEDUP[@]}"} <runner><hook>`.
- A generated wrapper run in a workspace with the tool prints a hook's repeated line once, and in one without it prints it every time; the second is the control.
