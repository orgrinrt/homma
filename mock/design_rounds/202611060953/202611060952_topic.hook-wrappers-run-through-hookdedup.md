# hook-wrappers-run-through-hookdedup

A hook that prints the same notice on every call costs the session its tokens each time. The workspace has one layer that says a line once per session and TTL (`tools/hookdedup`, clause-dev #4986), and it must cover every hook registration homma generates, not two shimmed ones.

## Current state

The wrappers written by `declared.rs` and `aggregate_wrapper.rs` end in a plain `exec` of the hook, so a hook's notice reaches the session on every call.

## Changes proposed

Both wrappers run the hook through `$WS/tools/hookdedup/hookdedup run` when that file is executable, and as before when it is not (a workspace without the tool). The hook's exit status, stderr and any block or deny are the tool's to leave alone. No manifest key: the presence of the tool is the switch.
