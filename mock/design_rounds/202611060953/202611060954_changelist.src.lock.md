# src changelist

Every generated hook wrapper runs its hook through the workspace's dedup tool when that file is executable. Descends from the topic file `202611060952_topic.hook-wrappers-run-through-hookdedup.md`, the one open topic, and the locked doc changelist `202611060953_changelist.doc.lock.md`.

## What lands

- `declared.rs`: `declared_wrapper` sets `DEDUP` to the tool's `run` when `$WS/tools/hookdedup/hookdedup` is executable, and all three of its `exec` lines go through it.
- `aggregate_wrapper.rs`: the same `DEDUP` line, and both `exec` lines of the wrapper go through it, the `jq`-less hand-off included.
- Tests: `a_declared_wrapper_runs_its_hook_through_the_dedup_tool_when_the_workspace_has_it` for a row with no repositories and a row narrowed to one, and `a_wrapper_runs_its_hook_through_the_dedup_tool_when_the_workspace_has_it` for the aggregated one. Each runs the wrapper without the tool first (the control: the hook runs, nothing reaches a tool) and then with a stand-in tool that records it was called with `run`.

## Claims

- `DEDUP` is an empty array without the tool, so a workspace without it runs the hook as before, status and arguments intact (`${DEDUP[@]+...}` is safe under `set -u`).
- No wrapper `exec`s its hook except through `DEDUP`.
