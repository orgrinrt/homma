# src changelist

Source for the doc changelist `202611030733_changelist.doc.lock.md`, round `202611030733_topic.release-reaches-the-registries-and-every-clone-of-the-workspace.md`. The two findings of the topic, the registry indexes refused under a trust store the system adds to, and a release verb that could not find a clone outside the container's scope, each get a change and a test that fails first.

CHANGE mock/crates/homma-core/Cargo.toml: `ureq` takes the `native-certs` feature beside `tls`, so the root store is the system's and the files `SSL_CERT_FILE` and `SSL_CERT_DIR` name, read through `rustls_native_certs`, and not only the roots compiled into the binary
CHANGE mock/crates/homma-core/src/release/registry.rs: `published_versions` asks through one `agent` that names the user agent `homma/<version>` and a fifteen second timeout, so the registry check is built in one place and the trust store it uses is the one the feature selects
CHANGE mock/crates/homma-core/src/config.rs: `Config::from_path` keeps loading under the scope `homma.local.toml` names, and a new `Config::from_path_whole` loads the same file under `Scope::everything`; the two share one `load_in_scope` that takes the scope as a function of the directory beside the file
CHANGE mock/crates/homma-engine/src/cmd/mod.rs: `load_config_whole` beside `load_config`, the same lookup of the config path and the same errors, through `Config::from_path_whole`
CHANGE mock/crates/homma-engine/src/cmd/release/mod.rs: `config_for` picks the load per verb, the scoped one for `release run` with no repository named and the whole one for every other verb, a repository named or the one the working directory sits in; `run` calls it
CHANGE mock/crates/homma-core/src/release/registry_tls_tests.rs: a new test file, `a_request_trusts_the_roots_ssl_cert_file_names_and_only_those`: the test binary re-executed as a child that asks a local `openssl s_server` presenting a self-signed leaf certificate (`CA:FALSE`, `subjectAltName` the loopback address); the child reads `ok 200` with `SSL_CERT_FILE` naming that certificate and an `invalid peer certificate` refusal without it (the library reports `BadSignature` for a self-signed leaf no root vouches for, so the test asserts the refusal and not the variant), and the test fails when the `native-certs` feature is taken out
CHANGE mock/crates/homma-core/src/config/tests.rs: a new `whole_load_tests` module, three tests over two clones and a local file that names one: `the_scoped_load_holds_only_the_clone_the_local_file_names` is the control, `the_whole_load_holds_every_clone_whatever_the_local_file_names`, and `the_whole_load_reports_a_scope_that_admits_what_it_holds`
CHANGE mock/crates/homma-engine/src/cmd/release/config_tests.rs: a new test file over the load a release command line gets, three tests: `a_verb_that_names_a_repository_finds_it_outside_the_scope`, `a_verb_that_names_none_but_a_directory_finds_every_clone`, and the control `the_sweep_that_names_no_repository_stays_in_the_scope`
