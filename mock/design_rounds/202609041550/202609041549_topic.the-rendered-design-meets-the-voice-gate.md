# the-rendered-design-meets-the-voice-gate

A fix round, standing alone the way a defect found and fixed does. The round
`202609041520` amended the root design template and the review sweep asked
why nothing under `docs/` moved with it. Rendering the document answered:
the render commit is refused by the pre-commit voice gate, on a sentence the
template has carried since the status round, the one saying what the plain
status gets somebody, in the wording of a purchase. A cost metaphor, which the
writing rules name as one of the tells, and it went unrendered for as long
as nobody ran the render after locking that template, so the gate never saw
it. Quoting the sentence here trips the same gate once the round is archived,
which is why it is described instead.

So the sentence changes in the template, the document is rendered, and both
land together. Nothing else in the template moves, and no source moves at
all; the source changelist says so and exists so the round can close.
