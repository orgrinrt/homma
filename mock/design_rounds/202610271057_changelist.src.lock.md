# src changelist

Answers the topic filed in this round, `homma-what-finds-the-tool-that-does-a-thing`, and builds the section "Finding a tool" of `mock/DESIGN.md.tmpl` as the doc changelist `202610271057_changelist.doc.lock.md` leaves it.

## Comparison to deprecated changelist

The deprecated source changelist (`202610271044_changelist.src.deprecated.md`) listed the command, its sources, its tests and the readme. A review of that work found faults, and this changelist is what changed from it:

- `sources/scripts.rs`: the walk reads the type of an entry without following a link, so a link to a directory is not walked and a link out of the workspace is not read. A script is a file that is executable or has a script extension, so the non-executable ones with a header are found and the ones without are counted in the footer.
- `sources/mock.rs`: the listings run side by side, one thread for each repository, with both pipes drained on their own threads, and an overrunning one has its whole process group ended.
- `text.rs`: `ended` and `over` are out of the group for finishing and `ended` is in the group for stopping, so no word is in two groups once stemmed.
- `rank.rs`: the closeness for related things is 0.125, as the design says, and the module says seven places.
- `sources/corpora.rs`: a skill's command is `/<name>`.
- `cli.rs`, `cmd/mod.rs`: `--limit` is never below one.
- `docs/DESIGN.md`: regenerated.
- Tests: the footer is tested on a planted tree holding scripts with and without a header, the cut on a thing under it and a thing over it, the grades on their worth, the edit distance on exact pairs, and the synonym groups on their overlap. A link loop, a link out of the workspace, a listing over a pipe's capacity and a listing that overruns each have a test, and the last was shown red with the group kill taken out, where the sleeping child outlived the listing. The acceptance set gains the query for stale or merged branches, three queries the matcher does not answer well (`is this branch landed`, `open a design round`, `tell the coordinator i am blocked`) are kept as ignored cases naming what should come first, and the default path, `cargo mock tools` included, has a test beside the rest.
