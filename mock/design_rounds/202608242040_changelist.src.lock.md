# SRC changelist

## CHANGE: `mock/crates/homma/src/cmd/verify.rs`

CHANGE the offline `forge_token_unset` / `forge_token_empty` checks to fire only
where `token_env` is the sole declared source.

WHY: a profile naming a `token_cmd` has said where its credential comes from,
so an unset variable is the ordinary case rather than a gap. Against the
workspace's own manifest the old check warned that mutating operations would
fail unauthorized on a forge that `--forge` then authenticated to successfully,
in the same run.

WHY it stays offline: `check` is pure and worth keeping so. It does not need to
run anything to say the useful thing, and `--forge` already reports a command
that produces nothing, with the command named.

ADD three cases: a variable-only profile with the variable unset still warns, a
profile declaring a command does not, and the empty-variable arm behaves the
same way. The first is the control on the second.
