# src changelist

Answers the doc changelist `202610271248_changelist.doc.lock.md` of this round, topic `hook-install-takes-no-flag-and-regen-refuses-a-broken-layer`.

## Current state before the round

`homma hook install` took `--shook`, which forced `git shook install` whatever `core.hooksPath` was and so took the key from the tool that held it. `homma agent regen` rendered from the merged table without checking that every named layer had been read. The test named for the forced path never called it. The command listing in the release deep dive lacked `homma hook doctor`.

## Changes

- `homma-core`: `hooks/install.rs` drops `Via` and `install_via`; `install` registers with git-shook where `core.hooksPath` is its directory and writes entrypoints otherwise. `hooks/mod.rs` stops exporting them. The test of the entrypoint path is renamed to what it asserts and names an event so its assertion is not vacuous.
- `homma-engine`: `cli.rs` drops the `--shook` flag; `cmd/hook.rs` follows; `cmd/agent.rs` makes `regen` refuse, naming the file, while a layer cannot be read and the aggregate stage is on. The smoke test of a broken layer covers `agent regen` and its control.
- `README.md`: the hook row no longer names the flag.
