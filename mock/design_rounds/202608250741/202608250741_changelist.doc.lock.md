# Doc changelist: the readme, ahead of the first release

**Date:** 2026-08-25
**Round:** 202608250741
**Source topic:** `202608250741_topic.readme-for-the-first-release.md`

The readme is authored directly rather than rendered, so this changelist names

## CHANGE: `README.md`

Install line moves from a git url on a branch to `cargo install homma`, and the
badge block gains the Crates.io and docs.rs badges the convention asks for.

The status section drops to a plain statement of what works and what has not
settled. The implementation narrative it had grown (path proving, symlink
defeat, what the aggregation pass writes and where it refuses to) comes out
entirely; it is a description of mechanism and belongs beside the mechanism.

A table of what the commands are for goes in, plus a usage block and a manifest
example. The manifest example is written against the real schema:
`[workspace] name`, and `local_path` on a repo entry.

The output flag is named as `--output json`, which is what the cli takes. It
had said `--json`, which this cli has never taken.

The one place the assistant-configuration surface is mentioned gets its own
section carrying the standing notice, rather than sitting in the status section
as though it were a headline.
