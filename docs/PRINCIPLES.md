# Principles

## Small, and delegating

homma does the cross-repository work and nothing else. Where a member repository
has its own tooling, homma drives that tooling rather than reimplementing what it
does. A workspace orchestrator that grows its own opinion about how a crate should
be built has stopped being an orchestrator.

## General before convenient

homma runs against any workspace, not only the one it was written in. What it
requires is stated in configuration; what it assumes has a default and an
override. Nothing about the workspace it was born in is hardcoded, and the
defaults it ships are the ones that workspace arrived at by using them.

## Configuration is explicit, discovery is a convenience

Where homma can discover something it may, but a discovered fact is never the only
route to it. Anything load-bearing can be stated outright, because a workspace
that behaves differently on a machine where discovery failed is worse than one
that refuses until it is told.

## Exit codes carry the finding

A command that fails says what failed in a form a script can act on. Structured
findings and a non-zero exit, not prose and a zero.

## Responsible tooling

- Never use a coding agent unless you know what you are doing, and be aware of the
  environmental and social implications of large-scale model inference. Be
  responsible and minimise the use of agents where not needed.
- Prefer agents as assistants over autonomous agents. A human in the loop catches
  mistakes, provides context, and takes responsibility. Autonomous agents should
  be the exception, not the norm.
- The `Co-Authored-By` byline marks autonomous agent work: work produced with no
  human in the conversational loop at the time of writing. In those cases the
  agent is the author and the byline is mandatory transparency.
- For agent-as-assistant work, where a human is reading output and redirecting
  choices, there is no byline regardless of how much the agent produced. The
  human's direction is what makes it their commit.
- When unsure, skip the byline.
